DataFrame::fromCsv()

DataFrame::fromCsv(    mixed $file,    array|string $types = [],    string $delimiter = ',',    array $na = ['', 'NA'],    mixed ...$options,): DataFrame

Read delimited text like readr::read_csv(): a path (“.gz” is decompressed), an http:// or https:// URL (downloaded to a temporary file first), or an open stream. Types are guessed from up to guessMax rows; “” and “NA” are NA. More readr options go as named arguments; see Phibble\Io\CsvOptions (colNames, select, skip, nMax, quote, comment, trimWs, skipEmptyRows, guessMax, nameRepair, decimalMark, groupingMark, escapeDouble, escapeBackslash).

Problems (unparseable values, ragged rows) raise one E_USER_WARNING; the data is still returned, with NA where values failed.

DataFrame::fromCsvChunked()

DataFrame::fromCsvChunked(    mixed $file,    callable $callback,    int $chunkSize = 10000,    array|string $types = [],    string $delimiter = ',',    array $na = ['', 'NA'],    mixed ...$options,): void

Read delimited text in chunks, as readr::read_delim_chunked(): each chunk of at most $chunkSize rows is passed to $callback with the 1-based index of its first row. Returning false from the callback stops reading. Memory follows the chunk size, not the file’s.

Types not given are guessed from the first chunk (guessMax defaults to the chunk size, as in readr) and every later chunk is parsed as those types. Give types, for example [‘.default’ => ‘c’], to skip guessing. Factors without levels take their levels from each chunk. Each chunk’s problems raise their own warning, with rows numbered from the start of the file. Options are those of fromCsv(), and $file may be a URL as there. With phit 0.2.0 or later loaded, the chunks are read natively by Phit\CsvReader.

$callback callable(DataFrame, int): (bool|null|void)
$chunkSize int 10000
$types string|array<int|string, mixed> []
$delimiter string ‘,’
$na list<string> [’‘, ’NA’]
...$options mixed

DataFrame::tibble()

DataFrame::tibble(    array $columns,    string $nameRepair = 'check_unique',): DataFrame

Build a DataFrame column by column, as tibble’s tibble().

  • A list is a column; a scalar (or null) is repeated to the common length. Only length-1 values are recycled.
  • A closure receives the DataFrame built so far and returns a list or a scalar, so columns can be computed from earlier ones.
  • A Table under an integer key is spliced in column by column.
Parameter Type Default Description
$columns array<string|int, mixed>
