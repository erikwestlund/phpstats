Join another table, with dplyr 1.1 semantics.

Parameter Type Default Description

$by list<string|array{0: string, 1: string}>
$type string ‘inner’ inner, left, right, full, semi, anti, or cross.
$suffix array{0: string, 1: string} [‘.x’, ‘.y’]
$keep bool|null null Keep both tables’ key columns.
$naMatches bool true Whether NA keys match each other.
$multiple string ‘all’ all, any, first, or last match per x row.
$relationship string|null null one-to-one, one-to-many, many-to-one, or many-to-many; a violation throws.
$unmatched string ‘drop’ drop, or error when the join would drop rows. - $by: list of [leftColumn, rightColumn] pairs; a bare ‘k’ means [‘k’, ‘k’]. Empty for a cross join. - $type: inner, left, right, full, semi, anti or cross. - Columns: x’s columns, then y’s non-key columns (all of y’s with $keep). Clashing names get $suffix. Without $keep, key columns come from x, filled from y for rows only y has (right and full joins). - Rows: x order, with each x row’s matches in y order; right and full joins then add y’s unmatched rows in y order. Semi and anti joins keep x’s rows and columns and never duplicate rows. - Matching: NA matches NA unless !$naMatches; 1 matches 1.0; factors match strings by label. - $multiple: all, any, first or last match per x row. - $relationship: one-to-one, one-to-many, many-to-one or many-to-many; a violation throws. Unspecified many-to-many warns. - $unmatched: drop, or error when a join would drop rows. - The result keeps x’s grouping.

Reshaping

->pivotLongerSpec()

$table->pivotLongerSpec(array $spec, bool $dropNa = false): Table

Pivot columns into rows from a spec, as tidyr’s pivot_longer_spec().

Each spec row is [‘.name’ => source column, ‘.value’ => value column, …name parts]. Output: the other (id) columns, the name-part columns, then one column per distinct .value. Each input row gives one row per distinct name-part combination, in spec order; a missing (combination, .value) is NA. $dropNa drops rows whose value columns are all NA. Values combine by vctrs rules (int and double give double); incompatible types throw “Can’t combine”.

Parameter Type Default Description
$spec list<array<string, mixed>>
$dropNa bool false

Method of DataFrame, SqlTable, PolarsTable
Returns Table

->pivotWiderSpec()

$table->pivotWiderSpec(    array $spec,    ?array $idColumns = null,    array $valuesFill = [],): Table

Pivot rows into columns from a spec, as tidyr’s pivot_wider_spec().

Each spec row is [‘.name’ => new column, ‘.value’ => values_from column, …names_from column => value]. New columns appear in spec order after the id columns, which default to every column not used by the spec; rows follow the first appearance of each id combination. Missing cells take $valuesFill[valueColumn] or NA. When some cell has several values, every new column becomes a list-column (a list of values per cell, null when empty) and tidyr’s “not uniquely identified” warning is raised.

Parameter Type Default Description
$spec list<array<string, mixed>>
$idColumns list<string>|null null
$valuesFill array<string, mixed> []
