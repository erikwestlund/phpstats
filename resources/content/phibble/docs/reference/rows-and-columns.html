NameRepair::repair()

NameRepair::repair(    array $names,    Closure|string $mode = 'check_unique',): array

Repair column names, as vctrs::vec_as_names().

Modes: minimal makes names non-null; unique adds a …n suffix to empty, ..., ..j, and duplicated names; check_unique throws unless names are unique and non-empty; universal is unique and also makes names syntactic in R. A closure receives the names and returns the repaired list.

Parameter Type Default Description
$names list<string|null>
$mode string|Closure(list<string>): list<string> ‘check_unique’ minimal, unique, check_unique, universal, or a closure.

Static method of Phibble\NameRepair
Returns list<string>
Throws InvalidArgumentException: when check_unique finds empty or duplicated names, or a closure returns a different number of names.

->filter()

$table->filter(Closure|Expr $predicate): Table

Keep rows where the predicate is true. NA counts as false.

A closure runs once per row. An Expr runs once per group, a whole column at a time, so aggregates such as mean() compare within the group.

Parameter Type Default Description
$predicate Closure(Row, Table): ?bool|Expr A row closure or an expression.

Method of DataFrame, SqlTable, PolarsTable
Returns Table
