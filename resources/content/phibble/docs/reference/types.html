Model data

->toModelData()

$table->toModelData(?array $names = null): array

Columns for model fitting (Phit\fit_lm, Phit\fit_glm, Phit\model_matrix):

  • float, int: list<float|int|null>
  • bool: list<bool|null> (a two-level contrast, as in R)
  • string: list<string|null> (the model sorts levels, as R does)
  • date: days since 1970-01-01; datetime: seconds since epoch
  • factor: [‘levels’ => list, ‘codes’ => list, ‘ordered’ => bool], with 0-based codes, null for NA, and every level in table order

List-columns cannot be modelled and throw.

Parameter Type Default Description
$names list<string>|null null Columns to include; all by default.

Method of DataFrame
Returns array<string, list<mixed>|array{levels: list<string>, codes: list<?int>, ordered: bool}>
Examples Types
