Load, transform, and summarize typed data frames in PHP. Tables are immutable, and null represents missing data. Names and semantics follow R’s tibble, readr, and dplyr.

This summary reads the Palmer penguins data, penguins.csv:

use Phibble\DataFrame;use function Phibble\Expr\{col, mean, median, n};$penguins = DataFrame::fromCsv('penguins.csv');$summary = $penguins    ->filter(col('body_mass')->isNa()->not())    ->groupBy(['species', 'sex'])    ->summarize([        'n' => n(),        'mass' => mean(col('body_mass')),        'flipper' => median(col('flipper_len')),    ]);echo $summary, "\n";

A step that a backend cannot run, such as a PHP closure, runs in a DataFrame. Backends lists where results can differ.

Other packages

These PHPstats packages read or return phibble tables:

  • phplyr: dplyr and tidyr as PHP functions and method chains.
  • phit: statistical models, through DataFrame::toModelData(). Its extension also reads CSV natively.
  • phiz: plots of a DataFrame.
  • CmdStanPHP: a DataFrame as model data, and draws and summaries as tables.
