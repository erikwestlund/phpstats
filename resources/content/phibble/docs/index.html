phibble is a port of R’s tibble to PHP, with the readr-style input and output a data frame needs. A DataFrame holds typed columns, treats null as NA, and never changes in place: every operation returns a new frame.

$penguins = DataFrame::fromCsv('penguins.csv');

$summary = $penguins
    ->filter(col('body_mass')->isNa()->not())
    ->groupBy(['species', 'sex'])
    ->summarise([
        'n' => n(),
        'mass' => mean(col('body_mass')),
        'flipper' => median(col('flipper_len')),
    ]);

echo $summary;

phibble is the shared table type of a small family of packages for statistics in PHP. The other packages read and return phibble tables:

  • phplyr ports dplyr and tidyr as pipe-able functions.
  • phit is a native extension for statistical models and descriptive statistics. It reads model data with DataFrame::toModelData().
  • phpolars is an optional Polars-backed table.
  • cmdstanphp runs Stan models and will accept phibble frames.

The packages talk to each other through the Table contract. DataFrame is the in-memory implementation. SqlTable implements the same contract over a SQL query, so the verbs compile to SQL and run in the database.

Install

phibble needs PHP 8.3 or later. PHP 8.5 adds the |> pipe operator, which phibble and phplyr pipelines can use.

composer require phpstats/phibble

phibble has no required dependencies beyond PHP’s PDO extension. It works with Laravel and Doctrine query builders without depending on either.
