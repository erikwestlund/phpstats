Read readings.csv into a DataFrame, with one column’s type declared and the rest guessed:

date,station,temp_c,rain_mm,wind_kmh,windy
2024-03-01,north,7.5,0.0,12,FALSE
2024-03-01,south,9.1,1.2,31,TRUE
2024-03-02,north,6.8,NA,18,FALSE
2024-03-02,south,8.4,3.5,35,TRUE
2024-03-03,north,10.2,0.0,9,FALSE
2024-03-03,south,11.0,0.4,22,FALSE
use Phibble\DataFrame;

$readings = DataFrame::fromCsv('readings.csv', types: ['station' => 'factor']);

echo $readings, "\n";
# A tibble: 6 × 6

6 2024-03-03 south     11       0.4       22 FALSE
  • Each column’s type is guessed from its values, as readr’s read_csv() guesses it. The guess uses up to 1,000 sampled rows (guessMax).
  • Whole numbers are read as int, where readr reads double.
  • types: ['station' => 'factor'] overrides the guess, which reads station as a string.
  • NA and empty fields are missing values, which phibble stores as null.

The runnable script loads Composer’s autoloader and reads readings.csv from the working directory.
