Installation

composer require phpstats/phibble

phibble requires PHP 8.3, 8.4, or 8.5, and the mbstring and PDO extensions. These are optional:

Optional Enables
The phit extension, 0.2.0 or later Native CSV reading in fromCsv(), fromCsvChunked(), and csvChunks(). Results match the PHP reader.
The php_polars extension from phpolars PolarsTable and polars(), described in Backends.
illuminate/database The ->toDataFrame() and ->phibble() macros, described in Laravel. Laravel applications already have it.

The examples use the Palmer penguins data:

curl -LO https://raw.githubusercontent.com/phpstats/phibble/v0.6.1/docs/data/penguins.csv

Imports

The examples on this page use these imports:

use Phibble\DataFrame;use function Phibble\{tibble, tribble};use function Phibble\Expr\{col, desc, mean, median, n};

Phibble\Expr has functions named min, max, sum, round, abs, log, floor, str_pad, str_split, str_replace, and a few others that share names with PHP built-ins. In a file that imports them, a bare round($x) calls phibble’s expression helper. Write \round($x) for PHP’s function.

tibble() builds a data frame column by column:

  • A list gives one value per row, and a single value is repeated.
  • A closure receives the columns built so far.
$scores = tibble(    student: ['ana', 'ben', 'cy'],    score: [81.5, 74.0, null],    passed: fn (DataFrame $t) => array_map(        fn ($s) => $s === null ? null : $s >= 75,        $t['score'],    ),    term: 'fall',);echo $scores;
# A tibble: 3 × 4
  student score passed term 
  <chr>   <dbl> <lgl>  <chr>
1 ana      81.5 TRUE   fall 
2 ben      74   FALSE  fall 
3 cy       NA   NA     fall

tribble() takes the column names first, then one list per row:

$sites = tribble(    ['site', 'lat', 'opened'],    ['north', 44.9, 2019],    ['south', 41.2, 2021],);echo $sites;
# A tibble: 2 × 3
  site    lat opened

DataFrame::fromRows() takes a list of associative arrays, and keys missing from a row are NA. DataFrame::fromColumns() takes an array of columns and accepts explicit types.

$rows = DataFrame::fromRows([    ['id' => 1, 'dose' => 2.5, 'arm' => 'a'],    ['id' => 2, 'arm' => 'b'],]);$cols = DataFrame::fromColumns(    ['id' => [1, 2], 'arm' => ['a', 'b']],    types: ['arm' => 'factor'],);echo $rows, "\n\n", $cols;
# A tibble: 2 × 3

2     2  NA   b    

# A tibble: 2 × 2

  <int> <fct>
1     1 a

Inspect

echo $df prints a data frame as tibble does:

  • The header gives the size, and each column shows its type.
  • More than 20 rows print the first 10.
  • Numbers show three significant digits.
  • NA prints as NA, or <NA> in text columns.

format(n: 30, width: 120) prints more rows or a wider table. glimpse() gives one line per column, which suits wide data frames:

Each column has one type from the Phibble\Type enum, inferred from the values, and PHP null is NA in every type. Types covers inference, casts, and factors.

Read values:

  • $df->name, $df['name'], and $df->column('name') return a column as a PHP list.
  • Rows are Phibble\Row objects, which read values as properties or array keys. Iterating a data frame yields its rows.
  • An unknown column name throws Phibble\Exception\ColumnNotFound. Names are never matched partially.

Transform

Data frames have the dplyr verbs as methods: select(), filter(), mutate(), rename(), arrange(), groupBy(), summarize(), distinct(), slice(), head(), and join(). Each returns a new data frame, and the original never changes:

$df = tibble(x: [1, 2, 3]);$doubled = $df->mutate(['x' => col('x')->mul(2)]);echo json_encode($df->x), ' ', json_encode($doubled->x), "\n";
[1,2,3] [2,4,6]

filter() and mutate() accept a row closure, which receives a Row. arrange() takes column names, or [name, 'desc'] pairs.

$penguins = DataFrame::fromCsv('penguins.csv');$heavy = $penguins    ->select(['species', 'island', 'body_mass', 'year'])    ->filter(fn ($r) => $r->body_mass > 5500)    ->mutate(['kg' => fn ($r) => $r->body_mass / 1000])    ->arrange([['body_mass', 'desc']])    ->head(5);echo $heavy;
# A tibble: 5 × 5
  species island body_mass  year    kg
  <chr>   <chr>      <int> <int> <dbl>
1 Gentoo  Biscoe      6300  2007  6.3 
2 Gentoo  Biscoe      6050  2007  6.05
3 Gentoo  Biscoe      6000  2008  6   
4 Gentoo  Biscoe      6000  2009  6   
5 Gentoo  Biscoe      5950  2008  5.95

The same verbs accept expressions built with col() and the helper functions. Expressions run a whole column at a time, and SQL and Polars tables can translate them.

$penguins = DataFrame::fromCsv('penguins.csv');$heavy = $penguins    ->select(['species', 'island', 'body_mass', 'year'])    ->filter(col('body_mass')->gt(5500))    ->mutate(['kg' => col('body_mass')->div(1000)])    ->arrange([desc(col('body_mass'))])    ->head(5);echo $heavy;
# A tibble: 5 × 5

# A tibble: 3 × 2

Summarize

groupBy() records grouping columns, and summarize() (or summarise()) returns one row per group:

  • Groups are sorted, with NA last, as in dplyr.
  • With several grouping columns, the result keeps all but the last.
  • In a grouped data frame, filter() and mutate() work within each group, and an aggregate in mutate() repeats for each row of its group.
  • A row closure receives the row’s group as its second argument: fn (Row $r, DataFrame $group) => ....
$penguins = DataFrame::fromCsv('penguins.csv')    ->dropNa(['body_mass']);$centered = $penguins    ->groupBy(['species'])    ->mutate([        'vs_species' => col('body_mass')            ->sub(mean(col('body_mass'))),    ])    ->select(['species', 'body_mass', 'vs_species'])    ->head(4);echo $centered;
# A tibble: 4 × 3
# Groups:   species [1]
  species body_mass vs_species
  <chr>       <int>      <dbl>
1 Adelie       3750       49.3
2 Adelie       3800       99.3
3 Adelie       3250     -451. 
4 Adelie       3450     -251.

Groups are the combinations that occur in the data. groupBy($names, drop: false), like dplyr’s .drop = FALSE, also gives a factor’s empty levels a group, where n() and sum() are 0:

$penguins = DataFrame::fromCsv('penguins.csv')    ->asFactor('species')    ->filter(col('species')->ne('Chinstrap'));echo $penguins    ->groupBy(['species'], drop: false)    ->summarize(['n' => n()]);
# A tibble: 3 × 2
  species       n
  <fct>     <int>
1 Adelie      152
2 Chinstrap     0
3 Gentoo      124

Combine

distinct() keeps the first row of each combination of the given columns. join() takes the other table, the keys, and the type: inner, left, right, full, semi, anti, or cross. Joins follow dplyr 1.1, and NA keys match each other.

$penguins = DataFrame::fromCsv('penguins.csv');$islands = tribble(    ['island', 'area_km2'],    ['Biscoe', 6.1],    ['Dream', 0.9],);$joined = $penguins    ->distinct(['species', 'island'])    ->join($islands, ['island'], 'left');echo $joined;
# A tibble: 5 × 3
  species   island    area_km2
  <chr>     <chr>        <dbl>
1 Adelie    Torgersen     NA  
2 Adelie    Biscoe         6.1
3 Adelie    Dream          0.9
4 Gentoo    Biscoe         6.1
5 Chinstrap Dream          0.9

A condition can also compare columns, as in dplyr’s join_by(). Here each order gets the latest price set on or before its day:

$orders = tribble(    ['order', 'item', 'day'],    [1, 'tea', 3],    [2, 'tea', 9],    [3, 'coffee', 4],);$prices = tribble(    ['item', 'from_day', 'price'],    ['tea', 1, 2.5],    ['tea', 5, 2.75],    ['coffee', 1, 4.0],    ['coffee', 6, 4.5],);echo $orders->join(    $prices,    ['item', ['closest', 'day', '>=', 'from_day']],    'left',);
# A tibble: 3 × 5
  order item     day from_day price
  <int> <chr>  <int>    <int> <dbl>
1     1 tea        3        1  2.5 
2     2 tea        9        5  2.75
3     3 coffee     4        1  4

Output

  • toRows() returns a list of associative arrays, and toColumns() an array of columns.
  • writeCsv($path) and toCsv() write CSV as readr’s write_csv() does.
  • toJson() writes records, or columns with toJson('columns').

Reading and writing data covers the formats.

Method chains and the pipe operator

Verbs chain as methods on PHP 8.3, 8.4, and 8.5. On PHP 8.5, |> with arrow functions runs the same pipeline. phplyr provides verbs that work with |> without arrow functions.

  • PHP 8.5+
  • PHP 8.3–8.4
$penguins = DataFrame::fromCsv('penguins.csv');$counts = $penguins |>    (fn (DataFrame $f) => $f->groupBy(['island'])) |>    (fn (DataFrame $f) => $f->summarize(['n' => n()])) |>    (fn (DataFrame $f) => $f->arrange([desc(col('n'))]));echo $counts;
$penguins = DataFrame::fromCsv('penguins.csv');$counts = $penguins    ->groupBy(['island'])    ->summarize(['n' => n()])    ->arrange([desc(col('n'))]);echo $counts;
# A tibble: 3 × 2
  island        n
  <chr>     <int>
1 Biscoe      168
2 Dream       124
3 Torgersen    52
