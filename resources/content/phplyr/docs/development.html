Tests

The tests use Pest and run under PHP 8.3, 8.4, and 8.5. They call functions through pipe(), so they parse on every version. tests/Pipe/ holds the tests written with |>; bin/test leaves them out before PHP 8.5.

composer installbin/test                 # loads .ext/libphit.dylib when presentNO_EXT=1 bin/test        # pure-PHP descriptive statisticsPHP=/path/to/php83 bin/test

The method chain’s @method list in src/Chain.php is generated. After adding or changing a table function, run bin/chain-docblock; a test fails while the list is out of date.

Most tests compare phplyr with R. The scripts in tests/r/ run the same pipelines with dplyr and tidyr and write JSON fixtures to tests/Fixtures/:

Rscript tests/r/reference.R   # single-table functions, windows, across, tidyselectRscript tests/r/expr.R        # expressionsRscript tests/r/joins.R       # joins and rowwiseRscript tests/r/join_by.R     # join_by() conditionsRscript tests/r/tidyr.R       # tidyr functionsRscript tests/r/rows.R        # set operations, rows_*(), dplyr 1.2 helpersRscript tests/r/coverage.R    # functions added after phplyr 0.1.0Rscript tests/r/models.R      # lm() and glm() coefficientsRscript tests/r/janitor.R     # janitor functions (needs the janitor package)

tests/PolarsTest.php runs about 120 pipelines on both DataFrame and PolarsTable and requires the same columns, types, groups, and rows from each. The polars CI job runs it with the prebuilt php_polars extension.

Phibble\Expr\Clock::freeze() fixes the time that today() and now() return, for tests.

composer lint checks the naming conventions with PHP_CodeSniffer.

Documentation

The site is a Quarto project in docs/. Code examples live in docs/examples/*.php. bin/docs-examples runs each one with docs/data as the working directory and writes docs/examples/_<name>.md with the code and its output, which the pages include. Rendering never executes PHP.

An example uses |>, and docs/examples/<name>.chain.php beside it is the same example as a method chain. bin/docs-examples runs both and fails if their output differs. The page shows the two in tabs labeled “PHP 8.5+” and “PHP 8.3–8.4”, with the output once. bin/docs-examples needs PHP 8.5, and it loads phit from .ext/libphit.dylib for the model examples.

Most examples leave out the require line and the imports, and bin/docs-examples adds them before it runs the code. An example that requires vendor/autoload.php itself is a complete script. It runs as written, so a missing import fails the run, and the page shows it without the opening tag and the require line. The first example, the porting script, and the pages in the Examples section (docs/examples/<slug>.qmd, with their code in docs/examples/pages/) are complete scripts. A subdirectory’s _prelude.php, such as the Gallery’s, replaces the generated prelude for its examples, and the page shows it once.

PHP=/path/to/php85 bin/docs-examples   # refresh example outputPHP=/path/to/php85 bin/render-docs     # examples, quarto render, publish to docs/

docs/_variables.yml names the latest release. The data URLs in the docs, the README, and site.json point at that tag, and a test fails until a new CHANGELOG release is matched there and in the README.

Commit the rendered HTML. phpstats.org imports it from the commit it pins and serves it at https://phplyr.phpstats.org/docs. GitHub Pages serves redirects to those pages, which .github/workflows/pages.yml builds with bin/pages-redirects.

Site content

site/ holds phplyr’s content for phplyr.phpstats.org. The phpstats site reads it at a pinned commit.

Path Contents Made by
site/site.json Manifest: summary, install, example, docs pages, examples, and file lists bin/site-manifest
site/benchmarks/backends.json Backend and dplyr timings bin/site-benchmarks, from docs/benchmarks/
site/verifications/*.json Every test that checks phplyr against R, with its assertion count and largest floating-point error bin/site-verifications

bin/site-verifications runs the test suite with PHPLYR_VERIFY_LOG set. Each test that reads an R fixture through rReference() then logs its assertions and the differences recorded by expectClose(). The script writes nothing unless every test passes. Set POLARS_PHP to a PHP command that loads php_polars to add the PolarsTable parity file.

To refresh the benchmarks, run bench/backends.php --csv-dir=bench/data, then Rscript bench/backends.R, then bin/site-benchmarks. tests/SiteTest.php checks that the files and pages site.json names exist.
