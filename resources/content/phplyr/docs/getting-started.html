Imports

phplyr’s table functions and helpers are namespaced functions. Import the ones a file uses with use function:

use Phibble\DataFrame;
use function Phplyr\{phplyr, filter, mutate, group_by, summarise, arrange, desc, n, mean};

A method chain only needs phplyr() and the helpers it uses, such as n, mean, and desc. The table functions are its methods.

Three phplyr functions share names with PHP built-ins: count, min, and max. In a file that imports them, a bare count($array) calls phplyr’s count(). Write \count(), \min(), and \max() for the built-ins.

Loading data

phibble reads CSV files, PDO queries, and query builders, and builds data frames from PHP arrays:

$schools = DataFrame::fromCsv('schools.csv');
$rows = DataFrame::fromRows([['id' => 1, 'x' => 2.5], ['id' => 2, 'x' => null]]);
$cols = DataFrame::fromColumns(['id' => [1, 2], 'x' => [2.5, null]]);

null is NA. DataFrames are immutable, and every function returns a new data frame. echo $df prints the first rows in tibble’s format.

Chaining functions

A function such as filter(...) returns a closure that takes a table. phplyr runs a sequence of them in three ways, and all three give the same result.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)

phplyr($t) starts a chain. Each method runs the phplyr function of that name with the same arguments, and get() returns the table. A chained method is camelCase, matching the methods on a phibble DataFrame, so group_by() is ->groupBy():

$out = phplyr($schools)
    ->filter(fn ($r) => $r->score > 80)
    ->arrange(desc('score'))
    ->get();

echo prints a chain’s table directly. A function whose result isn’t a table, such as pull(), n_groups(), or lm(), returns that result and ends the chain, as ->pull() and ->nGroups(). ->pipe($closure) applies a closure of your own and continues.

The pipe operator calls each closure with the value on its left:

$out = $schools
    |> filter(fn ($r) => $r->score > 80)
    |> arrange(desc('score'));

pipe() applies the closures in order and works on every PHP version:

$out = pipe($schools, filter(fn ($r) => $r->score > 80), arrange(desc('score')));
// is the same as
$out = arrange(desc('score'))(filter(fn ($r) => $r->score > 80)($schools));

The rest of this guide shows each example both as a method chain and with |>. The two are interchangeable.

Columns are named with strings: write 'score' where dplyr takes a bare score.

Row closures and vector helpers

phplyr accepts two kinds of expressions.

A row closure is an ordinary PHP closure. It receives the row as a Phibble\Row (read columns as $r->score or $r['score']) and, as a second argument, the table of the row’s group:

mutate(gap: fn ($r) => $r->score - $r->prior_score)
filter(fn ($r, $group) => $r->score > mean('score')($group))

A vector helper is one of phplyr’s functions, such as lag('x'), cumsum('x'), min_rank('x'), or mean('x'). It is evaluated once per group on whole columns, with dplyr’s semantics. A summary helper used in mutate() returns one value per group, which is recycled to every row of the group:

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
$schools = phplyr(DataFrame::fromCsv('schools.csv'))->groupBy('school')->get();

echo json_encode([
    'groups' => phplyr($schools)->groupVars(),
    'n_groups' => phplyr($schools)->nGroups(),
    'sizes' => \array_slice(phplyr($schools)->groupSize(), 0, 4),
]), "\n\n";

// Grouped mutate: helpers are evaluated within each group.
echo phplyr($schools)
    ->mutate(centered: fn ($r, $g) => round($r->score - mean('score')($g), 2), rank_in_school: min_rank(desc('score')))
    ->ungroup()
    ->head(4);

// One table per group.
$parts = phplyr($schools)->groupSplit();
echo "\n", \count($parts), ' tables; the first has ', $parts[0]->nrow(), " rows\n";
$schools = DataFrame::fromCsv('schools.csv') |> group_by('school');

echo json_encode([
    'groups' => $schools |> group_vars(),
    'n_groups' => $schools |> n_groups(),
    'sizes' => \array_slice($schools |> group_size(), 0, 4),
]), "\n\n";

// Grouped mutate: helpers are evaluated within each group.
echo $schools
    |> mutate(centered: fn ($r, $g) => round($r->score - mean('score')($g), 2), rank_in_school: min_rank(desc('score')))
    |> ungroup()
    |> head(4);

// One table per group.
$parts = $schools |> group_split();
echo "\n", \count($parts), ' tables; the first has ', $parts[0]->nrow(), " rows\n";

Vector helpers take a column name as their first argument. That argument can also be col('x'), another helper, or a row closure. Later arguments are values, so a string there is a literal. Wrap it in col() to refer to a column.

A third form, col('x')->mul(2), builds an inspectable expression. Expressions behave like the helpers in memory, and they let the same pipeline run as SQL on a database table. See Databases and expressions.

Named arguments and options

Functions that create columns name them with PHP named arguments: mutate(total: ...), summarise(n: n()). dplyr’s dot-prefixed options keep the dot as a leading underscore, because PHP named arguments cannot start with a dot: _by, _keep, _before, _after, _groups, _keepAll, and _byGroup. The prefix is what tells an option from a column, so mutate(_before: 'id') places the new columns while mutate(before: 1) makes a column called before. See Underscored arguments.

PHP does not allow positional arguments after named ones. Put across() and other positional arguments first: summarise(across(...), n: n()).

Printing and inspecting

echo prints a data frame. glimpse() prints one line per column and passes the table through, so it can sit inside a pipeline. pull('x') returns a column as a PHP list, and $df->toRows() returns all rows as arrays.
