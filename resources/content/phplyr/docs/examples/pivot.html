Turn a table with one sales column per year into one row per store and year, then rebuild the wide table.

  • PHP 8.5+
  • PHP 8.3–8.4
use function Phibble\tribble;use function Phplyr\{pivot_longer, pivot_wider};use function Phplyr\starts_with;$wide = tribble(    ['store', 'sales_2023', 'sales_2024', 'sales_2025'],    'Leeds', 120, 135, 150,    'Lyon', 95, 110, 104,);echo $wide, "\n\n";$long = $wide |> pivot_longer(    starts_with('sales_'),    namesTo: 'year',    namesPrefix: 'sales_',    valuesTo: 'sales',);echo $long, "\n\n";echo $long |> pivot_wider(    namesFrom: 'year',    valuesFrom: 'sales',    namesPrefix: 'sales_',);
use function Phibble\tribble;use function Phplyr\{phplyr, starts_with};$wide = tribble(    ['store', 'sales_2023', 'sales_2024', 'sales_2025'],    'Leeds', 120, 135, 150,    'Lyon', 95, 110, 104,);echo $wide, "\n\n";$long = phplyr($wide)    ->pivotLonger(        starts_with('sales_'),        namesTo: 'year',        namesPrefix: 'sales_',        valuesTo: 'sales',    )    ->get();echo $long, "\n\n";echo phplyr($long)->pivotWider(    namesFrom: 'year',    valuesFrom: 'sales',    namesPrefix: 'sales_',);
# A tibble: 2 × 4
  store sales_2023 sales_2024 sales_2025
  <chr>      <int>      <int>      <int>
1 Leeds        120        135        150
2 Lyon          95        110        104

# A tibble: 6 × 3
  store year  sales
  <chr> <chr> <int>
1 Leeds 2023    120
2 Leeds 2024    135
3 Leeds 2025    150
4 Lyon  2023     95
5 Lyon  2024    110
6 Lyon  2025    104

# A tibble: 2 × 4
  store sales_2023 sales_2024 sales_2025
  <chr>      <int>      <int>      <int>
1 Leeds        120        135        150
2 Lyon          95        110        104
  • pivot_longer() stacks the columns that starts_with('sales_') selects.
  • Each column name, without the sales_ prefix, goes into year, and each value goes into sales. store repeats for each stacked value.
  • year holds strings, because the values come from column names.
  • pivot_wider() makes one column for each value of year, adds the sales_ prefix, and fills the columns from sales.
  • The columns pivot_wider() doesn’t use, here store, identify the output rows. Each distinct combination of them becomes one row.

Reference: tidyr · tidyselect and across()
