Add each order’s customer name and city from a customers table that shares the customer_id column.

  • PHP 8.5+
  • PHP 8.3–8.4
use Phibble\DataFrame;
use function Phplyr\left_join;

$orders = DataFrame::fromRows([
    ['order' => 1, 'customer_id' => 'c1', 'amount' => 25.00],
    ['order' => 2, 'customer_id' => 'c2', 'amount' => 12.50],
    ['order' => 3, 'customer_id' => 'c1', 'amount' => 8.00],
    ['order' => 4, 'customer_id' => 'c9', 'amount' => 40.00],
]);
$customers = DataFrame::fromRows([
    ['customer_id' => 'c1', 'name' => 'Ana', 'city' => 'Lisbon'],
    ['customer_id' => 'c2', 'name' => 'Ben', 'city' => 'Leeds'],
    ['customer_id' => 'c3', 'name' => 'Cleo', 'city' => 'Lyon'],
]);

echo $orders |> left_join($customers, by: 'customer_id');
use Phibble\DataFrame;
use function Phplyr\phplyr;

$orders = DataFrame::fromRows([
    ['order' => 1, 'customer_id' => 'c1', 'amount' => 25.00],
    ['order' => 2, 'customer_id' => 'c2', 'amount' => 12.50],
    ['order' => 3, 'customer_id' => 'c1', 'amount' => 8.00],
    ['order' => 4, 'customer_id' => 'c9', 'amount' => 40.00],
]);
$customers = DataFrame::fromRows([
    ['customer_id' => 'c1', 'name' => 'Ana', 'city' => 'Lisbon'],
    ['customer_id' => 'c2', 'name' => 'Ben', 'city' => 'Leeds'],
    ['customer_id' => 'c3', 'name' => 'Cleo', 'city' => 'Lyon'],
]);

echo phplyr($orders)->leftJoin($customers, by: 'customer_id');

  • left_join() keeps every row of orders in its original order.
  • An order with no matching customer gets NA in the new columns. A customer with no orders is left out.
  • Each order gets one output row per matching customer. If customers had two rows for c1, each c1 order would appear twice and the result would have more rows than orders. Pass relationship: 'many-to-one' to throw an exception instead.
  • inner_join() drops the orders with no match. full_join() also keeps customers with no orders and adds them after the matched rows.
