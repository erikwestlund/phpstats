Keep the orders with a positive quantity and add a line total and a size label to each.

  • PHP 8.5+
  • PHP 8.3–8.4
use function Phibble\tribble;use function Phplyr\{filter, mutate, if_else, col};$orders = tribble(    ['order', 'product', 'qty', 'price'],    1, 'pen', 10, 1.50,    2, 'notebook', 0, 4.00,    3, 'stapler', 2, 12.00,    4, 'pen', 40, 1.25,);echo $orders |>    filter(fn ($r) => $r->qty > 0) |>    mutate(        total: fn ($r) => $r->qty * $r->price,        size: if_else(col('qty')->ge(20), 'bulk', 'single'),    );
use function Phibble\tribble;use function Phplyr\{phplyr, if_else, col};$orders = tribble(    ['order', 'product', 'qty', 'price'],    1, 'pen', 10, 1.50,    2, 'notebook', 0, 4.00,    3, 'stapler', 2, 12.00,    4, 'pen', 40, 1.25,);echo phplyr($orders)    ->filter(fn ($r) => $r->qty > 0)    ->mutate(        total: fn ($r) => $r->qty * $r->price,        size: if_else(col('qty')->ge(20), 'bulk', 'single'),    );

  • filter() keeps the rows for which the row closure returns true.
  • mutate() adds one column for each named argument.
  • A row closure such as fn ($r) => $r->qty * $r->price runs once per row and reads the row’s columns as properties.
  • A column expression such as col('qty')->ge(20) works on the whole column, and if_else() uses it to pick 'bulk' or 'single'.
