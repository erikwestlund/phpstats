This example computes a count, a total, and a mean for each region and sorts the regions by their totals.

Prerequisites: PHP 8.3 or later and composer require phpstats/phplyr. The pipe version needs PHP 8.5. See Installation.

The sales table is created inline. Save the script as example.php in the project directory and run php example.php.

  • PHP 8.5+
  • PHP 8.3–8.4
<?php

require 'vendor/autoload.php';

use Phibble\DataFrame;
use function Phplyr\{group_by, summarize, arrange, desc, n, sum, mean};

$sales = DataFrame::fromRows([
    ['region' => 'North', 'product' => 'pen', 'units' => 12],
    ['region' => 'North', 'product' => 'stapler', 'units' => 3],
    ['region' => 'South', 'product' => 'pen', 'units' => 20],
    ['region' => 'South', 'product' => 'notebook', 'units' => 7],
    ['region' => 'South', 'product' => 'stapler', 'units' => null],
    ['region' => 'West', 'product' => 'notebook', 'units' => 9],
]);

echo $sales |>
    group_by('region') |>
    summarize(orders: n(), total_units: sum('units', naRm: true), avg_units: mean('units', naRm: true)) |>
    arrange(desc('total_units'));
<?php

require 'vendor/autoload.php';

use Phibble\DataFrame;
use function Phplyr\{phplyr, desc, n, sum, mean};

$sales = DataFrame::fromRows([
    ['region' => 'North', 'product' => 'pen', 'units' => 12],
    ['region' => 'North', 'product' => 'stapler', 'units' => 3],
    ['region' => 'South', 'product' => 'pen', 'units' => 20],
    ['region' => 'South', 'product' => 'notebook', 'units' => 7],
    ['region' => 'South', 'product' => 'stapler', 'units' => null],
    ['region' => 'West', 'product' => 'notebook', 'units' => 9],
]);

echo phplyr($sales)
    ->groupBy('region')
    ->summarize(orders: n(), total_units: sum('units', naRm: true), avg_units: mean('units', naRm: true))
    ->arrange(desc('total_units'));
# A tibble: 3 × 4
  region orders total_units avg_units
  <chr>   <int>       <int>     <dbl>
1 South       3          27      13.5
2 North       2          15       7.5
3 West        1           9       9

group_by('region') makes each region a group, and summarize() returns one row per group with a column for each named argument. n() counts the rows in the group. The South region has a missing units value, so naRm: true leaves it out of the sum and the mean, as R’s na.rm = TRUE does. Without it, both would be NA. arrange(desc('total_units')) sorts the summary from the largest total to the smallest.

Each argument of summarize() can use the columns created before it. A summary named units would replace the units column for the arguments after it, as in dplyr, which is why the total is called total_units.

See Single-table functions for summarize(), Grouping for group_by(), and Vector helpers for n(), sum(), and mean().
