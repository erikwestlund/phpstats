Grouping and ungrouping

group_by() sets the grouping columns. Selectors work, named arguments group by a computed column, and _add: true adds to the existing groups. _drop: false keeps groups for unused factor levels, so summarize() and count() return them with n() = 0, as dplyr does. ungroup() removes grouping, or only the named columns.

Groups are ordered like dplyr’s: sorted by key, factors by level order, and NA last. filter(), mutate(), summarize(), and the slice functions work within groups. _by: groups for a single call and returns an ungrouped table.

  • PHP 8.5+
  • PHP 8.3–8.4

group_by()

group_by(mixed ...$columns): Closure

Group by columns (names or selectors). Named arguments group by a computed column: group_by(decade: fn ($r) => intdiv($r->year, 10) * 10). Options: _add (add to the existing groups), _drop (false keeps empty factor-level groups; needs backend support).

Returns a function of a table, which returns a table. Chain method: ->groupBy(). Throws LogicException on invalid arguments. An unknown underscored option throws InvalidArgumentException. Example.

ungroup()

ungroup(mixed ...$columns): Closure

Remove grouping, or only the named grouping columns.

Returns a function of a table, which returns a table. Chain method: ->ungroup(). Example.

with_groups()

with_groups(mixed $_groups, Closure $verb): Closure

Run a table function on the table grouped by _groups, then restore the original grouping (superseded in dplyr by _by): with_groups('g', mutate(m: mean('x'))). A null _groups runs it ungrouped.

Returns a function of a table, which returns a table. Chain method: ->withGroups().

Call fn (Table $group, array $key) for each group and return the list of results. With _keep: true the group table keeps the grouping columns.

Returns a function of a table, which returns one result per group. Chain method: ->groupMap().

group_modify()

group_modify(Closure $fn): Closure

Replace each group with the table fn (Table $group, array $key) returns, then put the key columns back in front. The result stays grouped.

Returns a function of a table, which returns a table. Chain method: ->groupModify(). Throws UnexpectedValueException on invalid arguments.

group_walk(Closure $fn): Closure

Call fn (Table $group, array $key) for each group; return the table unchanged.

Returns a function of a table, which returns the table unchanged, after calling the function on each group. Chain method: ->groupWalk().

One row per group: the key columns and a list-column of each group’s other columns as a table. Options: _key (the list-column, ‘data’), _keep (also keep the key columns in the nested tables).

Row-wise operations

rowwise() makes each row its own group. Closures in summarize() and vector helpers then see one row at a time. Optional id columns stay as groups in the result of summarize(). c_across(cols) gives the current row’s values of the selected columns, for helpers such as sum(c_across(starts_with('x'))).

  • PHP 8.5+
  • PHP 8.3–8.4
echo DataFrame::fromRows([    ['id' => 'a', 'q1' => 3, 'q2' => 5, 'q3' => null],    ['id' => 'b', 'q1' => 4, 'q2' => 1, 'q3' => 2],]) |>    rowwise('id') |>    summarize(total: fn ($row) => Stats::sum(        [...$row->column('q1'), ...$row->column('q2'), ...$row->column('q3')],        naRm: true,    ));
