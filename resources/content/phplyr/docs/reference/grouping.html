group_by() sets the grouping columns. Selectors work, named arguments group by a computed column, and _add: true adds to the existing groups. _drop: false keeps groups for unused factor levels, so summarize() and count() return them with n() = 0, as dplyr does. ungroup() removes grouping, or only the named columns.

Groups are ordered like dplyr’s: sorted by key, factors by level order, and NA last. filter(), mutate(), summarize(), and the slice functions work within groups. _by: groups for a single call and returns an ungrouped table.

  • PHP 8.3–8.4

Row-wise operations

rowwise() makes each row its own group. Closures in summarize() and vector helpers then see one row at a time. Optional id columns stay as groups in the result of summarize(). c_across(cols) gives the current row’s values of the selected columns, for helpers such as sum(c_across(starts_with('x'))).

  • PHP 8.5+
  • PHP 8.3–8.4
