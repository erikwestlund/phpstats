Selectors

Selectors pick columns by name, pattern, or type. They work in select(), relocate(), rename_with(), arrange(), distinct(), group_by(), count(), across(), pick(), and the tidyr functions.

Selector Columns
'x', ['x', 'y'] By name
starts_with('x'), ends_with(), contains() By name fragment; case-insensitive unless ignoreCase: false
matches('^x\\d+$') By regular expression
num_range('x', 1, 3) x1, x2, x3
everything(), last_col() All columns, the last column
all_of([...]), any_of([...]) Names from a list, strict or lenient
where('numeric'), where(fn ($values, $type, $name) => ...) By type or predicate
group_cols() The grouping columns
except(...) Everything but these (dplyr’s -x)
any_selected(...), all_selected(...) Union and intersection

where() accepts 'numeric', 'integer', 'double', 'character', 'logical', 'factor', 'date', 'datetime', 'time', and 'list', or a Phibble\Type. 'numeric' selects integer and double columns. 'time' selects phibble’s time columns, R’s hms, and needs phibble 0.6 or later.

starts_with()

starts_with(array|string $prefix, bool $ignoreCase = true): Selector

Columns whose names start with a prefix (case-insensitive by default).

Returns Selector. Pivot between wide and long.

ends_with()

ends_with(array|string $suffix, bool $ignoreCase = true): Selector

Columns whose names end with a suffix (case-insensitive by default).

Returns Selector. Example.

contains()

contains(array|string $needle, bool $ignoreCase = true): Selector

Columns whose names contain a string (case-insensitive by default).

Returns Selector.

matches()

matches(string $pattern, bool $ignoreCase = true): Selector

Columns whose names match a regular expression. Bare patterns are wrapped in delimiters; case-insensitive by default.

Returns Selector.

num_range()

num_range(string $prefix, int $from, int $to, int $width = 0): Selector

Columns named prefix + number for each number: num_range('x', 1, 3).

Returns Selector.

everything()

everything(): Selector

Every column.

Returns Selector.

last_col()

last_col(int $offset = 0): Selector

The last column, or the one $offset before it.

Returns Selector. Throws OutOfRangeException on invalid arguments.

all_of()

all_of(array $names): Selector

Exactly these columns; all must exist.

Returns Selector.

any_of()

any_of(array $names): Selector

These columns, skipping any that don’t exist.

Returns Selector.

where()

where(Closure|Phibble\Type|string $predicate): Selector

Columns for which a predicate holds. The predicate receives (list $values, Type $type, string $name). Shortcuts: a Phibble, or one of ‘numeric’, ‘integer’, ‘double’, ‘character’, ‘logical’, ‘factor’, ‘date’, ‘datetime’, ‘time’ (phibble 0.6 and later), ‘list’.

Returns Selector. Throws InvalidArgumentException on invalid arguments. Example.

except()

except(mixed ...$columns): Selector

Everything except these columns: select(except('id')) is dplyr’s select(-id).

Returns Selector.

any_selected()

any_selected(mixed ...$selections): Selector

Columns matched by any of the selections (union).

Returns Selector.

all_selected()

all_selected(mixed ...$selections): Selector

Columns matched by every selection (intersection, like a & b in tidyselect).

Returns Selector.

group_cols()

group_cols(): Selector

The grouping columns.

Returns Selector.

across()

across(cols, fns, names:) applies functions to several columns inside mutate() or summarize(). Grouping columns are never selected. fns is one function or an associative array of named functions. Output names default to {col} for one function and {col}_{fn} for several.

  • PHP 8.5+
  • PHP 8.3–8.4
$schools = DataFrame::fromCsv('schools.csv') |> group_by('school');// Phplyr helpers can be passed by name; each gets the column name.echo $schools |>    summarize(across(where('numeric'), ['avg' => mean(...), 'sd' => sd(...)])) |>    head(3);// Other closures get the column's values (summarize) or each value (mutate).echo "\n", $schools |>    summarize(across(['study_hours', 'score'], fn (array $v) => round(\max($v) - \min($v), 1), names: 'range_{col}')) |>    head(3);echo "\n", $schools |> ungroup() |> mutate(across(ends_with('score'), fn ($v) => round($v))) |> head(3);

What each function receives:

  • A phplyr helper passed as a first-class callable, such as mean(...), is called with the column name.
  • In summarize(), other closures receive the column’s values as a list.
  • In mutate(), other closures receive one value at a time, or the whole column if the first parameter is typed array.
  • A closure may return a helper’s result, as in fn ($v) => mean($v, naRm: true), which is then evaluated on the group.

Inside any of these functions, cur_column() returns the name of the column being processed.

if_any(cols, fn) and if_all(cols, fn) test a predicate across columns, in filter() or as a logical column in mutate(). They use R’s NA logic, so a predicate may return null for NA. With no columns selected, if_any() is false and if_all() is true, as in dplyr 1.1. pick(...) returns the selected columns of the current group as a table, for use inside closures.

across()

across(mixed $cols = null, Closure|array|null $fns = null, ?string $names = null): Across

Apply functions to columns inside mutate() or summarise(): summarise(across(starts_with('x'), mean(...))), mutate(across(where('numeric'), fn ($v) => $v * 2)), summarise(across(['a', 'b'], ['avg' => mean(...), 'sd' => sd(...)])).

Names default to ‘{col}’ for one function and ’{col}_{fn}’ for a named list.

Returns Across. Example.

if_any()

if_any(mixed $cols, Closure $predicate): Vec

Per-row test that a predicate holds for any of the columns, for filter(): filter(if_any(starts_with('x'), fn ($v) => $v > 0)).

Returns a vector helper (Vec). Its expression runs on a database table when its arguments are columns, literals, or other helpers.

if_all()

if_all(mixed $cols, Closure $predicate): Vec

Per-row test that a predicate holds for all of the columns.

Returns a vector helper (Vec). Its expression runs on a database table when its arguments are columns, literals, or other helpers.

c_across()

c_across(mixed $cols = null): Vec

The values of the selected columns in the current row, for rowwise() tables: rowwise() |> mutate(total: sum(c_across(starts_with('x')))). In a group of several rows the values run column by column.

Returns a vector helper (Vec). Its expression runs on a database table when its arguments are columns, literals, or other helpers.

pick()

pick(mixed ...$columns): Closure

The selected columns of the current group as a table, for use in summarise() closures or with vec(): fn ($g) => pick('a', ‘b’)($g)->toRows().

Returns a function of a table, which returns a table. Chain method: ->pick().

cur_column()

cur_column(): string

The name of the column across() is working on, inside one of its functions: across(['a', 'b'], fn ($v) => cur_column().': '.$v).

Returns string. Throws LogicException on invalid arguments.
