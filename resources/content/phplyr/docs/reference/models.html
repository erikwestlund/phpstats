lm(), glm(), lmer(), and glmer() fit models with phit. phit reads factor levels from the table, builds the model matrix from an R formula, and fits the model. phplyr adds no model code of its own.

phplyr phit function
lm() Phit\fit_ols()
glm() Phit\fit_generalized_linear()
lmer() Phit\fit_mixed_gaussian()
glmer() Phit\fit_mixed_logistic()

phit 0.4 also has the older names, such as fit_lm(), as deprecated aliases. phplyr calls the current names.

The functions come from the phit extension or from phit-polyfill, its PHP port, and phplyr calls both the same way. phit’s Extension or polyfill page compares them.

  • Install the polyfill with composer require phpstats/phit-polyfill. When the extension is loaded, the polyfill defines nothing.
  • The polyfill throws an exception while OPcache’s JIT is enabled. Set opcache.jit=disable where it runs.
  • mean(), sd(), var_(), median(), and quantile() call phit only when the extension is loaded. Otherwise, including with the polyfill, they run in PHP with the same results.
  • With neither installed, the four functions throw a RuntimeException that names the missing phit function.

CI runs phplyr’s tests with each implementation. Both runs compare lm() and glm() coefficients with R’s, and lmer() fixed effects with lme4’s.

  • PHP 8.5+
  • PHP 8.3–8.4
$table |> lm('y ~ x + group');$table |> glm('passed ~ hours', family: 'binomial');$table |> lmer('score ~ hours + (1 | school)');$table |> glmer('passed ~ hours + (1 | school)', family: 'binomial');
phplyr($table)->lm('y ~ x + group');phplyr($table)->glm('passed ~ hours', family: 'binomial');phplyr($table)->lmer('score ~ hours + (1 | school)');phplyr($table)->glmer('passed ~ hours + (1 | school)', family: 'binomial');
Function Model Options
lm($formula) Linear regression
glm($formula, family:) Generalized linear model family: 'gaussian' (the default), 'binomial', or 'poisson', and link:
lmer($formula) Linear mixed model with lme4’s random-effect terms, such as (1 \| school) REML by default; reml: false fits by maximum likelihood
glmer($formula) Generalized linear mixed model The binomial family with the logit link and one random intercept, such as (1 \| school), which is what phit supports

Other named arguments go to phit’s function unchanged. phit’s documentation lists them and the formula syntax it accepts.

Results

Each function returns phit’s result array in place of a table, so it ends a method chain. columns holds R’s coefficient names, in R’s order, and coefficients, std_errors, p_values, and conf_int follow the same order. The array also has the fitted values, residuals, fit statistics such as r_squared and sigma, and n_observations and n_dropped, which count the rows used and the rows dropped for missing values.
