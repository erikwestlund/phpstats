lm(), glm(), lmer(), and glmer() pass the table to phit’s Phit\fit_lm(), Phit\fit_glm(), Phit\fit_lmer(), and Phit\fit_glmer(). phplyr adds no model code of its own. phit reads factor levels from the table, builds the model matrix from an R formula, and fits the model.

Two implementations of these functions are supported, and phplyr calls both the same way:

  • The phit extension, written in Rust.
  • phit-polyfill, a PHP port of the extension’s code, for systems where the extension cannot be installed. Install it with composer require phpstats/phit-polyfill. When the extension is loaded, the polyfill defines nothing.

CI runs phplyr’s test suite with each one. Both runs compare lm() and glm() coefficients with R’s and lmer() fixed effects with lme4’s.

phit-polyfill has the same functions, arguments, and results for the models, with these differences:

  • It is slower. In phit-polyfill’s benchmarks, linear models took about 9 times as long as with the extension, logistic models about 22 times, and mixed models 13 to 78 times.
  • Its functions throw an exception while OPcache’s JIT is enabled. Set opcache.jit=disable where it runs.
  • It does not speed up the descriptive helpers. mean(), sd(), var_(), median(), and quantile() call phit only when the extension is loaded, and otherwise run in PHP with the same results.
  • It leaves out phit’s CSV reader, which phplyr does not use.

With neither installed, the four functions throw a RuntimeException that names the missing phit function.

  • PHP 8.5+
  • PHP 8.3–8.4
$table |> lm('y ~ x + group');
$table |> glm('passed ~ hours', family: 'binomial');
$table |> lmer('score ~ hours + (1 | school)');
$table |> glmer('passed ~ hours + (1 | school)', family: 'binomial');
phplyr($table)->lm('y ~ x + group');
phplyr($table)->glm('passed ~ hours', family: 'binomial');
phplyr($table)->lmer('score ~ hours + (1 | school)');
phplyr($table)->glmer('passed ~ hours + (1 | school)', family: 'binomial');
Function Model Options
lm($formula) Linear regression
glm($formula, family:) Generalized linear model family: 'gaussian' (the default), 'binomial', or 'poisson', and link:
lmer($formula) Linear mixed model with lme4’s random-effect terms, such as (1 \| school) REML by default; reml: false fits by maximum likelihood
glmer($formula, family:) Generalized linear mixed model family: 'binomial' by default

Other named arguments go to phit’s function unchanged. phit’s documentation lists them and the formula syntax it accepts.

Results

Each function returns phit’s result array in place of a table, so it ends a method chain. columns holds R’s coefficient names, in R’s order, and coefficients, std_errors, p_values, and conf_int follow the same order. The array also has the fitted values, residuals, fit statistics such as r_squared and sigma, and n_observations and n_dropped, which count the rows used and the rows dropped for missing values.

  • PHP 8.5+
  • PHP 8.3–8.4
$fit = DataFrame::fromCsv('schools.csv') |>
    filter(fn ($r) => $r->prior_score > 50) |>
    lm('score ~ study_hours + prior_score');

foreach (['(Intercept)', 'study_hours', 'prior_score'] as $i => $term) {
    printf("%-12s %8.4f  (se %.4f)\n", $term, $fit['coefficients'][$i], $fit['std_errors'][$i]);
}
printf("R² = %.4f, n = %d\n", $fit['r_squared'], $fit['n_observations']);

$logit = DataFrame::fromCsv('learning.csv') |> glm('passed ~ study_hours + practice_score', family: 'binomial');
