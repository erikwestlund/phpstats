lm(), glm(), lmer(), and glmer() pass the input table to the phit extension’s Phit\fit_lm(), Phit\fit_glm(), Phit\fit_lmer(), and Phit\fit_glmer(). The extension reads factor levels from the table, builds the model matrix, and returns coefficients, standard errors, and fit statistics in the same order as R.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
phplyr($table)->lm('y ~ x + group');
phplyr($table)->glm('passed ~ hours', family: 'binomial');   // also 'poisson', link:
phplyr($table)->lmer('score ~ hours + (1 | school)');        // REML; reml: false for ML
phplyr($table)->glmer('passed ~ hours + (1 | school)', family: 'binomial');
$table |> lm('y ~ x + group');
$table |> glm('passed ~ hours', family: 'binomial');   // also 'poisson', link:
$table |> lmer('score ~ hours + (1 | school)');        // REML; reml: false for ML
$table |> glmer('passed ~ hours + (1 | school)', family: 'binomial');

lmer() and glmer() take lme4’s random-effect bars. The result includes columns with R’s coefficient names. All four need phit with the formula functions. Without the extension they throw an exception that says so.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
$fit = phplyr(DataFrame::fromCsv('schools.csv'))
    ->filter(fn ($r) => $r->prior_score > 50)
    ->lm('score ~ study_hours + prior_score');

foreach (['(Intercept)', 'study_hours', 'prior_score'] as $i => $term) {
    printf("%-12s %8.4f  (se %.4f)\n", $term, $fit['coefficients'][$i], $fit['std_errors'][$i]);
}
printf("R² = %.4f, n = %d\n", $fit['r_squared'], $fit['n_observations']);

$logit = phplyr(DataFrame::fromCsv('learning.csv'))->glm('passed ~ study_hours + practice_score', family: 'binomial');
echo 'logit coefficients: ', implode(', ', array_map(fn ($b) => round($b, 4), $logit['coefficients'])), "\n";
