Vector helpers are evaluated once per group on whole columns. Use them as mutate(), filter(), and summarize() arguments. They follow R’s NA rules: a summary returns NA when its input has an NA unless naRm: true, ranks keep NA, and cumulative functions stay NA after the first NA.

The first argument is the input column. A string there is a column name. It can also be col('x'), another helper, or a row closure. Later arguments are values. ->map(fn ($value, $r) => ...) transforms a helper’s result row by row.

With the phit extension loaded, mean, sd, var_, median, and quantile use it. Without it, they run in PHP. The test suite checks both against R.
