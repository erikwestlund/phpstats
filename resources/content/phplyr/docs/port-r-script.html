A typical R analysis of the schools data, translated to PHP. It reads a CSV file, cleans and reshapes it, summarizes it, and fits a linear, a logistic, and a random-intercept model.

Data: schools.csv. The R script needs dplyr, tidyr, and lme4. The PHP script needs phplyr and, for the models, phit; see Models.

R

suppressPackageStartupMessages({  library(dplyr)  library(tidyr)  library(lme4)})schools <- as_tibble(read.csv("schools.csv"))# Clean: drop incomplete rows, band study time,# compute the gain.clean <- schools |>  filter(!is.na(score), study_hours > 0) |>  mutate(    hours_band = case_when(      study_hours < 4 ~ "low",      study_hours < 8 ~ "mid",      .default = "high"    ),    gain = score - prior_score,    passed = as.integer(score >= 75)  )# Reshape: one row per student and test.long <- clean |>  mutate(student = row_number()) |>  select(student, school, prior = prior_score,         final = score) |>  pivot_longer(c(prior, final), names_to = "test",               values_to = "points")long |>  group_by(test) |>  summarise(mean = mean(points), sd = sd(points))# Summarize: students per school and band, then# the schools with the largest mean gains.clean |>  count(school, hours_band) |>  pivot_wider(names_from = hours_band, values_from = n,              values_fill = 0) |>  head(3)clean |>  group_by(school) |>  summarise(n = n(), mean_gain = mean(gain)) |>  arrange(desc(mean_gain)) |>  head(3)# Model: linear, logistic, and random-intercept fits.fit_lm <- lm(score ~ study_hours + prior_score,             data = clean)fit_glm <- glm(passed ~ study_hours + prior_score,               family = binomial, data = clean)fit_lmer <- lmer(  score ~ study_hours + prior_score + (1 | school),  data = clean)round(coef(fit_lm), 4)round(coef(fit_glm), 4)round(fixef(fit_lmer), 4)

What changed in translation

  • Loading. read.csv() becomes DataFrame::fromCsv(), which infers column types like readr.
  • Pipes. On PHP 8.5, R’s |> stays |>. On PHP 8.3 and 8.4, the pipeline becomes a method chain that starts with phplyr($t).
  • Column references. Bare names become strings, or col('x') inside expressions, so score - prior_score becomes col('score')->sub(col('prior_score')).
  • Conditions. case_when(x < 4 ~ "low", .default = "high") becomes case_when([col('x')->lt(4), 'low'], default: 'high').
  • Renaming in select. select(prior = prior_score) becomes select(['prior' => 'prior_score']).
  • Column sets. c(prior, final) becomes ['prior', 'final'].
  • Models. lm(), glm(), and lmer() take the same formulas. They return arrays, so coef() and fixef() become reads of coefficients.
  • Printing. DataFrames print in tibble’s format.

On a database table from Phibble\tbl(), the cleaning, counting, and grouped-summary steps run as SQL, because they use col() expressions and phplyr’s helpers. The reshaping step loads the rows into PHP. See Databases and expressions.
