Filter, transform, join, and reshape tables with dplyr- and tidyr-style functions. Use PHP 8.5 pipes, or method chains on PHP 8.3 and later.

A first pipeline

Keep the students who studied at least five hours, summarize each school, and print the five schools with the highest average score.

composer require phpstats/phplyrcurl -O https://raw.githubusercontent.com/phpstats/phplyr/v0.4.5/docs/data/schools.csv
  • PHP 8.5+
  • PHP 8.3–8.4
use Phibble\DataFrame;use function Phplyr\{filter, group_by, summarize};use function Phplyr\{arrange, head, desc, n, mean, sd};$schools = DataFrame::fromCsv('schools.csv');echo $schools |>    filter(fn ($r) => $r->study_hours >= 5) |>    group_by('school') |>    summarize(        students: n(),        avg_score: mean('score'),        sd_score: sd('score'),    ) |>    arrange(desc('avg_score')) |>    head(5);
use Phibble\DataFrame;use function Phplyr\{phplyr, desc, n, mean, sd};$schools = DataFrame::fromCsv('schools.csv');echo phplyr($schools)    ->filter(fn ($r) => $r->study_hours >= 5)    ->groupBy('school')    ->summarize(        students: n(),        avg_score: mean('score'),        sd_score: sd('score'),    )    ->arrange(desc('avg_score'))    ->head(5);

phplyr and phibble

The tables come from phibble, which Composer installs with phplyr. phplyr adds dplyr’s and tidyr’s functions on top of phibble’s table methods, so a pipeline runs on an in-memory DataFrame, on a database table as SQL, or on Polars.

phplyr has:

  • dplyr’s single-table and two-table functions, with grouped window functions, across(), column selectors, and join_by() conditions.
  • tidyr’s pivoting, completing, splitting, nesting, and list-column functions.
  • janitor’s clean_names(), remove_empty(), get_dupes(), and tabyl().
  • lm(), glm(), lmer(), and glmer(), which fit models with phit.

Functions and methods lists every function and method, with a link to its reference entry.

Install

composer require phpstats/phplyr

phplyr needs PHP 8.3 or later with the mbstring and PDO extensions. Installation lists the optional extensions, and Compatibility and limitations lists the dplyr features phplyr doesn’t have.
