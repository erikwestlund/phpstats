phplyr is a library of functions for filtering, transforming, summarizing, joining, and reshaping tables of data in PHP. Each function takes a table and returns a new one, so a sequence of them reads as a pipeline from the raw data to the result. The functions and their arguments follow R’s dplyr and tidyr packages, and the test suite compares their results with R’s.

A first pipeline

The script below reads a CSV file of test scores from 250 students in 12 schools. It keeps the students who studied at least five hours, summarizes each school, and prints the five schools with the highest average score.

To run it, create a Composer project in an empty directory and download the data:

composer require phpstats/phplyrcurl -O https://raw.githubusercontent.com/phpstats/phplyr/v0.4.3/docs/data/schools.csv

Save the script as first.php in the same directory and run php first.php. The “PHP 8.5+” version uses the pipe operator |>. The “PHP 8.3–8.4” version is the same pipeline as a method chain and runs on PHP 8.3 and later.

  • PHP 8.5+
  • PHP 8.3–8.4
<?phprequire __DIR__.'/vendor/autoload.php';use Phibble\DataFrame;use function Phplyr\{filter, group_by, summarize, arrange, head, desc, n, mean, sd};$schools = DataFrame::fromCsv('schools.csv');echo $schools |>    filter(fn ($r) => $r->study_hours >= 5) |>    group_by('school') |>    summarize(students: n(), avg_score: mean('score'), sd_score: sd('score')) |>    arrange(desc('avg_score')) |>    head(5);
<?phprequire __DIR__.'/vendor/autoload.php';use Phibble\DataFrame;use function Phplyr\{phplyr, desc, n, mean, sd};$schools = DataFrame::fromCsv('schools.csv');echo phplyr($schools)    ->filter(fn ($r) => $r->study_hours >= 5)    ->groupBy('school')    ->summarize(students: n(), avg_score: mean('score'), sd_score: sd('score'))    ->arrange(desc('avg_score'))    ->head(5);

phplyr and phibble

The tables come from phibble, which Composer installs with phplyr. phibble reads CSV files, database queries, and PHP arrays into a typed, immutable DataFrame. Its methods, such as filter(), mutate(), groupBy(), summarize(), arrange(), and join(), are the operations every phibble table implements. They take closures, arrays of column definitions, and phibble expressions.

phplyr is built on those methods and adds:

  • dplyr’s functions and arguments, including grouped window functions such as lag() and min_rank(), across(), column selectors such as starts_with(), join_by() conditions, and the slice_*() family.
  • tidyr’s pivoting, completing, splitting, nesting, and list-column functions.
  • janitor’s clean_names(), remove_empty(), get_dupes(), and tabyl().
  • Adapters that pass a table to phit’s lm(), glm(), lmer(), and glmer().

A phplyr pipeline runs on any phibble table: the in-memory DataFrame, a database table from Phibble\tbl(), which runs the pipeline as SQL, and Phibble\Polars\PolarsTable, which runs it in Polars through the phpolars extension.

Install

composer require phpstats/phplyr

phplyr supports PHP 8.3, 8.4, and 8.5, and requires the mbstring and PDO extensions. Pipelines written with the pipe operator |> need PHP 8.5.

The optional features are statistical models (the phit extension or phit-polyfill), native descriptive statistics (phit), the Polars backend (phpolars), janitor’s transliteration of names (intl), and database tables (a PDO driver). Installation in Getting started describes the requirements and each optional feature.

Compatibility and limitations lists the PHP and backend details and the dplyr features phplyr does not have.
