This reference is generated from the public signatures and docblocks in src/. Every method that adds or changes something returns a new Plot, and the plot it was called on is unchanged.

Exceptions

  • InvalidArgumentException for input phiz cannot use, such as an unknown aesthetic, scale type, theme, or legend position, a geom without an aesthetic it needs, data that is neither rows nor columns, or a plot with no layers. The message names the problem.
  • Phiz\Exceptions\VlConvertNotFound when static export cannot find the vl-convert binary.
  • Phiz\Exceptions\ExportFailed when vl-convert fails, times out, or writes nothing, or when a file cannot be written.

Both export exceptions implement Phiz\Exceptions\PhizException.

Functions

Most functions in the Phiz\ namespace return a closure that applies the method of the same name, for the pipe operator and apply(). They take the same arguments as that method.

  • aes(mixed ...$mappings): Aes: Aesthetic mappings: aes(x: ‘displ’, y: ‘hwy’, color: ‘class’).
  • ggplot(mixed $data = null, Aes|array|null $mapping = null): Plot: A plot of data with optional mappings.
