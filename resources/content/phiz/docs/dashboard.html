Build Livewire components whose phiz charts follow the component’s state. The page has two separate examples:

  • A minimal component charts revenue from an application’s own orders table, with one filter.
  • A linked dashboard charts the bundled mpg car data, so it runs as written, with three charts that share filters.

Requirements: a Laravel application with Livewire 3, and composer require phpstats/phiz phpstats/phibble phpstats/phplyr.

A minimal component

One chart of monthly revenue per customer from an orders table, filtered by sales channel.

app/Livewire/RevenueByMonth.php:

namespace App\Livewire;use App\Models\Order;use Livewire\Component;use Phibble\DataFrame;use Phiz\Plot;use function Phplyr\{    col, floor_date, group_by, mutate, sum, summarize,};class RevenueByMonth extends Component{    public string $channel = 'All';    public function render()    {        $orders = Order::query()->when(            $this->channel !== 'All',            fn ($q) => $q->where('channel', $this->channel),        );        $monthly = DataFrame::fromQuery($orders) |>            mutate(                month: floor_date(col('placed_on'), 'month'),            ) |>            group_by('month', 'customer') |>            summarize(revenue: sum('total'));        $chart = Plot::of($monthly)            ->aes(x: 'month', y: 'revenue', color: 'customer')            ->line()            ->point()            ->labs(x: null, y: 'Revenue ($)', color: null)            ->size('container', 260);        return view('livewire.revenue-by-month', [            'chart' => $chart,        ]);    }}

resources/views/livewire/revenue-by-month.blade.php:

<div>
    <select wire:model.live="channel">
        <option>All</option>
        <option>Web</option>
        <option>App</option>
        <option>Marketplace</option>
    </select>

    <x-phiz :plot="$chart" />
</div>
  • Redrawing. Livewire reruns render() after each property change. <x-phiz> redraws the chart when its specification changes.
  • Server-side data. The query, the monthly summary, and the chart are built in PHP. The page receives only the summarized rows.
  • Width. size('container', 260) makes the chart fill its element’s width at a fixed height.

A linked dashboard

Three charts follow the same filters: a drive and a year selected in the page, and a vehicle class selected from a list. A shared function builds the charts, a component holds the state, and a view lays them out.

The shared function

fuel_dashboard() takes the cars table and the filter state. It returns three plots and the class summary behind the bar chart. The file is examples/dashboard.php, and examples/dashboard.chain.php is the method-chain version.

  • PHP 8.5+
  • PHP 8.3–8.4
use Phibble\Contracts\Table;use Phiz\Plot;use function Phiz\{aes, calc, field};use function Phplyr\{    arrange, desc, filter, group_by, mean, n, summarize,};/** * @param string|null $drive 'f', 'r', '4', or null for all * @param int|null $year 1999, 2008, or null for both * @return array{summary: Table, bars: Plot, *     scatter: Plot, trend: Plot} */function fuel_dashboard(    Table $cars,    ?string $drive = null,    ?int $year = null,    ?string $selected = null,): array {    $byDrive = $cars |> filter(        fn ($r) => $drive === null || $r->drv === $drive,    );    $subset = $byDrive |> filter(        fn ($r) => $year === null || $r->year === $year,    );    $byClass = $subset |>        group_by('class') |>        summarize(            cars: n(),            hwy: mean('hwy'),            cty: mean('cty'),        ) |>        arrange(desc('hwy'));    // The trend compares the years, so it ignores $year.    $byManufacturer = $byDrive |>        group_by('manufacturer', 'year') |>        summarize(hwy: mean('hwy'));    $test = 'datum.class === '.json_encode($selected ?? '');    $bars = Plot::of($byClass)        ->aes(            x: 'hwy',            y: field('class', sort: '-x'),            fill: calc($test, 'selected', 'nominal'),        )        ->col()        ->scaleFill(            domain: [false, true],            range: ['#9ECAE1', '#08519C'],            guide: false,        )        ->tooltip(['class', 'cars', 'hwy', 'cty'])        ->labs(            title: 'Mean highway mpg by class',            x: 'Highway mpg',            y: null,        )        ->size('container', 220);    $scatter = Plot::of($subset)        ->aes(x: 'displ', y: 'hwy', color: 'class')        ->point(alpha: 0.7, size: 40)        ->smooth(            aes(x: 'displ', y: 'hwy'),            method: 'lm',            color: '#333333',            inheritAes: false,        )        ->tooltip([            'manufacturer', 'model', 'year', 'displ', 'hwy',        ])        ->theme(legendPosition: 'bottom')        ->labs(            title: 'Displacement and highway mpg',            x: 'Displacement (L)',            y: 'Highway mpg',            color: null,        )        ->size('container', 220);    $trend = Plot::of($byManufacturer)        ->aes(x: 'year:O', y: 'hwy', group: 'manufacturer')        ->line(color: '#BBBBBB')        ->point(color: '#666666', size: 20)        ->tooltip(['manufacturer', 'year', 'hwy'])        ->labs(            title: 'Manufacturers, 1999 to 2008',            x: null,            y: 'Mean highway mpg',        )        ->size('container', 220);    return [        'summary' => $byClass,        'bars' => $bars,        'scatter' => $scatter,        'trend' => $trend,    ];}
use Phibble\Contracts\Table;use Phiz\Plot;use function Phiz\{aes, calc, field};use function Phplyr\{desc, mean, n, phplyr};/** * @param string|null $drive 'f', 'r', '4', or null for all * @param int|null $year 1999, 2008, or null for both * @return array{summary: Table, bars: Plot, *     scatter: Plot, trend: Plot} */function fuel_dashboard(    Table $cars,    ?string $drive = null,    ?int $year = null,    ?string $selected = null,): array {    $byDrive = phplyr($cars)        ->filter(            fn ($r) => $drive === null || $r->drv === $drive,        )        ->get();    $subset = phplyr($byDrive)        ->filter(            fn ($r) => $year === null || $r->year === $year,        )        ->get();    $byClass = phplyr($subset)        ->groupBy('class')        ->summarize(            cars: n(),            hwy: mean('hwy'),            cty: mean('cty'),        )        ->arrange(desc('hwy'))        ->get();    // The trend compares the years, so it ignores $year.    $byManufacturer = phplyr($byDrive)        ->groupBy('manufacturer', 'year')        ->summarize(hwy: mean('hwy'))        ->get();    $test = 'datum.class === '.json_encode($selected ?? '');    $bars = Plot::of($byClass)        ->aes(            x: 'hwy',            y: field('class', sort: '-x'),            fill: calc($test, 'selected', 'nominal'),        )        ->col()        ->scaleFill(            domain: [false, true],            range: ['#9ECAE1', '#08519C'],            guide: false,        )        ->tooltip(['class', 'cars', 'hwy', 'cty'])        ->labs(            title: 'Mean highway mpg by class',            x: 'Highway mpg',            y: null,        )        ->size('container', 220);    $scatter = Plot::of($subset)        ->aes(x: 'displ', y: 'hwy', color: 'class')        ->point(alpha: 0.7, size: 40)        ->smooth(            aes(x: 'displ', y: 'hwy'),            method: 'lm',            color: '#333333',            inheritAes: false,        )        ->tooltip([            'manufacturer', 'model', 'year', 'displ', 'hwy',        ])        ->theme(legendPosition: 'bottom')        ->labs(            title: 'Displacement and highway mpg',            x: 'Displacement (L)',            y: 'Highway mpg',            color: null,        )        ->size('container', 220);    $trend = Plot::of($byManufacturer)        ->aes(x: 'year:O', y: 'hwy', group: 'manufacturer')        ->line(color: '#BBBBBB')        ->point(color: '#666666', size: 20)        ->tooltip(['manufacturer', 'year', 'hwy'])        ->labs(            title: 'Manufacturers, 1999 to 2008',            x: null,            y: 'Mean highway mpg',        )        ->size('container', 220);    return [        'summary' => $byClass,        'bars' => $bars,        'scatter' => $scatter,        'trend' => $trend,    ];}
  • Selection. A computed selected field colors the selected class in the bar chart.
  • One fit. The scatterplot’s linear fit sets inheritAes: false, so it fits all filtered cars together instead of one line per class.
  • Trend. The trend chart ignores the year filter, so both years stay visible.

The component

app/Livewire/FuelDashboard.php:

namespace App\Livewire;use Livewire\Attributes\Url;use Livewire\Component;use Phibble\DataFrame;use Phiz\Datasets;class FuelDashboard extends Component{    #[Url]    public ?string $drive = null;    #[Url]    public ?int $year = null;    public ?string $selected = null;    public function select(string $class): void    {        $this->selected = $this->selected === $class            ? null            : $class;    }    public function render()    {        $cars = DataFrame::fromRows(Datasets::mpg());        return view('livewire.fuel-dashboard', fuel_dashboard(            $cars,            $this->drive,            $this->year,            $this->selected,        ));    }}
  • Shareable state. #[Url] keeps the drive and year in the query string, so a filtered view can be bookmarked.
  • Data source. The example reads the bundled mpg data. An application would use DataFrame::fromQuery() or a cached table.
  • Toggle. Selecting the selected class again clears the selection.

Clicks on a chart

The loader dispatches a phiz:rendered event with the Vega view. An Alpine handler can forward a click on a bar to the component:

<div x-on:phiz:rendered="
    $event.detail.view.addEventListener('click', (e, item) =>
        item?.datum?.class && $wire.select(item.datum.class))
">
    <x-phiz :plot="$bars" wire:key="bars" />
</div>

Linking in the browser

When the data is small enough to send to the page, a composition can link charts with no server request. Brushing the scatterplot filters the bar chart, and Vega-Lite recomputes the means in the browser.

use Phiz\Compose;use Phiz\Datasets;use Phiz\Plot;use function Phiz\field;$mpg = Datasets::mpg();$plot = Compose::beside(    Plot::of($mpg)        ->aes(x: 'displ', y: 'hwy', color: 'drv')        ->point(alpha: 0.7)        ->brush(encodings: ['x', 'y'])        ->size(300, 240),    Plot::of($mpg)        ->aes(            x: 'mean(hwy)',            y: field('class', sort: '-x'),        )        ->col(filter: ['param' => 'brush'], fill: '#4C78A8')        ->labs(x: 'Mean highway mpg', y: null)        ->size(240, 240),);

Choosing where to compute

  • Server-side summaries send only summarized rows. They suit large tables, database queries, and statistics computed in PHP, such as model fits. Each interaction is a Livewire request.
  • Browser-side linking sends the raw rows once and responds without a request. It suits up to a few thousand rows (Large data).
  • Both can share a page: a Livewire filter chooses the rows, and a brush explores them in the browser.
