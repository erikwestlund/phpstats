Write one chart to an HTML page, an SVG image, and a PNG image.

Code

The chart plots weight against fuel economy for the 32 cars of R’s mtcars data, bundled with phiz as resources/data/mtcars.csv.

  • PHP 8.5+
  • PHP 8.3–8.4
use Phiz\Datasets;use function Phiz\{aes, geom_point, ggplot, labs};$plot = ggplot(Datasets::mtcars(), aes(x: 'wt', y: 'mpg')) |>    geom_point() |>    labs(x: 'Weight (1,000 lb)', y: 'Miles per gallon');$plot->save('chart.html');            // drawn by the browser$plot->save('chart.svg');             // rendered by vl-convert$plot->save('chart.png', scale: 2);   // rendered by vl-convert
use Phiz\Datasets;use Phiz\Plot;$plot = Plot::of(Datasets::mtcars())    ->aes(x: 'wt', y: 'mpg')    ->point()    ->labs(x: 'Weight (1,000 lb)', y: 'Miles per gallon');$plot->save('chart.html');            // drawn by the browser$plot->save('chart.svg');             // rendered by vl-convert$plot->save('chart.png', scale: 2);   // rendered by vl-convert

Runnable scripts: save.php (PHP 8.5+) and save.chain.php (PHP 8.3–8.4).

Result

The SVG file:

save() picks the format from the file extension: html (or htm), json, svg, png, jpg (or jpeg), or pdf. Any other extension throws an InvalidArgumentException.

  • HTML is drawn by the browser. The page holds the Vega-Lite specification and loads vega, vega-lite, and vega-embed from the jsDelivr CDN, so it needs a network connection to display. Tooltips and other interaction work there. For a page that works offline, write $plot->html(assets: Assets::inline(...)) to a file (HTML).
  • Images are rendered by vl-convert. SVG, PNG, JPG, and PDF need the vl-convert binary, which renders without a browser. Without it, save() throws Phiz\Exceptions\VlConvertNotFound with installation instructions (Installing vl-convert). Images are static, so interaction is lost.
  • scale: 2 doubles the pixel dimensions of PNG and JPG files. It is also the default.
  • json writes the Vega-Lite specification.
  • Reproducibility. With the same vl-convert version, the same specification produces the same SVG bytes on every run, except for unseeded jitter (Reproducible SVG).
