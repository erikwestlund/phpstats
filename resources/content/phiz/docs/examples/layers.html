This example draws a scatterplot of engine size against fuel economy and adds a least-squares line with its confidence band as a second layer.

Prerequisites: phiz installed with Composer (Installation). The pipe version needs PHP 8.5, and the method chain runs on PHP 8.3 and later.

Data

Datasets::mpg() returns the 234 cars of ggplot2’s mpg data, bundled with phiz as resources/data/mpg.csv. The example uses two of its columns:

displ hwy
1.8 29
1.8 29
2.0 31

displ is the engine displacement in liters, and hwy is the highway fuel economy in miles per gallon.

Code

Save the script beside the vendor directory and run it with php layers.php.

  • PHP 8.5+
  • PHP 8.3–8.4
<?php

require 'vendor/autoload.php';

use Phiz\Datasets;

use function Phiz\{aes, geom_point, geom_smooth, ggplot, labs};

$plot = ggplot(Datasets::mpg(), aes(x: 'displ', y: 'hwy')) |>
    geom_point(alpha: 0.5) |>
    geom_smooth(method: 'lm') |>
    labs(x: 'Engine displacement (L)', y: 'Highway miles per gallon');

$plot->save('layers.html');
<?php

require 'vendor/autoload.php';

use Phiz\Datasets;
use Phiz\Plot;

$plot = Plot::of(Datasets::mpg())
    ->aes(x: 'displ', y: 'hwy')
    ->point(alpha: 0.5)
    ->smooth(method: 'lm')
    ->labs(x: 'Engine displacement (L)', y: 'Highway miles per gallon');

$plot->save('layers.html');

How it works

ggplot() and aes() set the data and the mappings that every layer inherits. geom_point() adds the points, with alpha: 0.5 so that overlapping cars show as darker points. geom_smooth(method: 'lm') adds a second layer: a straight line fitted by least squares, and a shaded 95% confidence band for the mean. phiz fits the line and computes the band in PHP, and the band matches R’s predict(fit, interval = "confidence"). save() writes a standalone HTML page that draws the chart in a browser.

The line summarizes the trend: highway economy falls as displacement rises. The points curve upward again at the largest displacements, which a straight line cannot follow. The default method, loess, follows local changes like this one (Geoms).

Reference: ggplot(), aes(), point(), smooth(), labs(), and save().
