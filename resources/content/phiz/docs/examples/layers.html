Plot highway fuel economy against engine displacement, then add a least-squares line with its confidence band.

Data

Datasets::mpg() returns the 234 cars of ggplot2’s mpg data, bundled with phiz as resources/data/mpg.csv. The example uses two of its columns:

displ hwy
1.8 29
1.8 29
2.0 31

displ is the engine displacement in liters, and hwy is the highway fuel economy in miles per gallon.

Code

  • PHP 8.5+
  • PHP 8.3–8.4
use Phiz\Datasets;use function Phiz\{aes, geom_point, geom_smooth, ggplot, labs};$plot = ggplot(Datasets::mpg(), aes(x: 'displ', y: 'hwy')) |>    geom_point(alpha: 0.5) |>    geom_smooth(method: 'lm') |>    labs(x: 'Engine displacement (L)', y: 'Highway miles per gallon');$plot->save('layers.html');
use Phiz\Datasets;use Phiz\Plot;$plot = Plot::of(Datasets::mpg())    ->aes(x: 'displ', y: 'hwy')    ->point(alpha: 0.5)    ->smooth(method: 'lm')    ->labs(x: 'Engine displacement (L)', y: 'Highway miles per gallon');$plot->save('layers.html');

Runnable scripts: layers.php (PHP 8.5+) and layers.chain.php (PHP 8.3–8.4).

Result

Vega-Lite specification
  • Inheritance. Both layers use the data and the x and y mappings given to ggplot() and aes(). A layer can add its own mappings or data, or set inheritAes: false to ignore the plot’s mappings.
  • The band. method: 'lm' fits a straight line by least squares. The shaded band is a 95% confidence interval for the mean highway economy at each displacement, so most individual cars fall outside it. phiz computes the fit and the band in PHP, and they match R’s predict(fit, interval = "confidence"). level: changes the confidence level, and se: false hides the band.
  • The fit. Cars with larger engines tend to have lower highway economy. At the largest displacements the points rise again, which a straight line cannot follow. The default method, loess, fits a local curve instead (Fitted curves).
  • Transparency. alpha: 0.5 makes overlapping points show as darker points.

In R, the same chart is ggplot(mpg, aes(displ, hwy)) + geom_point(alpha = 0.5) + geom_smooth(method = "lm").
