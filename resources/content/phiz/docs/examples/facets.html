Split a scatterplot of car weight against fuel economy into one panel for each number of cylinders.

Data

Datasets::mtcars() returns the 32 cars of R’s mtcars data, bundled with phiz as resources/data/mtcars.csv. The example uses three of its columns:

model mpg cyl wt
Mazda RX4 21.0 6 2.620
Mazda RX4 Wag 21.0 6 2.875
Datsun 710 22.8 4 2.320

wt is the weight in thousands of pounds, mpg is the fuel economy in miles per gallon, and cyl is the number of cylinders: 11 cars have 4, 7 have 6, and 14 have 8.

Code

  • PHP 8.5+
  • PHP 8.3–8.4
use Phiz\Datasets;use function Phiz\{aes, facet_wrap, geom_point, ggplot, labs};$plot = ggplot(Datasets::mtcars(), aes(x: 'wt', y: 'mpg')) |>    geom_point() |>    facet_wrap('cyl', ncol: 3) |>    labs(x: 'Weight (1,000 lb)', y: 'Miles per gallon');$plot->save('facets.html');
use Phiz\Datasets;use Phiz\Plot;$plot = Plot::of(Datasets::mtcars())    ->aes(x: 'wt', y: 'mpg')    ->point()    ->facetWrap('cyl', ncol: 3)    ->labs(x: 'Weight (1,000 lb)', y: 'Miles per gallon');$plot->save('facets.html');

Runnable scripts: facets.php (PHP 8.5+) and facets.chain.php (PHP 8.3–8.4).

Result

Vega-Lite specification

facet_wrap('cyl', ncol: 3) draws the plot once for each value of cyl, from the rows with that value, and wraps the panels into three columns.

  • Shared scales. By default every panel uses the same axis ranges, so a position means the same weight and economy in each panel.
  • Free scales. scales: 'free' gives each panel its own ranges, and 'free_x' or 'free_y' frees one axis. Free scales show the spread within each group, but panels can no longer be compared by position.
  • Reading the panels. Heavier cars tend to have more cylinders, so a single scatterplot mixes the two. The panels show how weight and economy are associated among cars with the same number of cylinders.

In R, the same chart is ggplot(mtcars, aes(wt, mpg)) + geom_point() + facet_wrap(~cyl, ncol = 3).
