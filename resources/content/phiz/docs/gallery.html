Each chart below is drawn from the code under it. The code uses the bundled datasets, loaded as $mpg = Datasets::mpg(), $mtcars = Datasets::mtcars(), $economics = Datasets::economics(), and $faithful = Datasets::faithful(). The statistics examples use a linear model fit and posterior draws defined at the top of examples/catalog.php, which holds every example.

Means with error bars

Precomputed means with normal-approximation 95% intervals.

Vega-Lite specification
Plot::of(array_map(    function ($class) use ($mpg) {        $rows = array_filter(            $mpg,            fn ($r) => $r['class'] === $class,        );        $values = array_column($rows, 'hwy');        $n = count($values);        $mean = array_sum($values) / $n;        $squares = array_map(            fn ($v) => ($v - $mean) ** 2,            $values,        );        $se = sqrt(array_sum($squares) / ($n - 1) / $n);        return [            'class' => $class,            'mean' => $mean,            'lower' => $mean - 1.96 * $se,            'upper' => $mean + 1.96 * $se,        ];    },    array_values(array_unique(array_column($mpg, 'class'))),))    ->aes(x: 'class', y: 'mean', ymin: 'lower', ymax: 'upper')    ->errorbar(width: 8)    ->point(size: 50)    ->labs(x: null, y: 'Mean highway mpg (95% CI)');
