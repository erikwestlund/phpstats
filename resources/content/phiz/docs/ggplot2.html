Most ggplot2 code translates line by line. The tables below list the translations, and Differences lists where phiz behaves differently because Vega-Lite draws the plot.

Translating a plot

ggplot(mpg, aes(displ, hwy, colour = drv)) +  geom_point(alpha = 0.5) +  geom_smooth(method = "lm") +  facet_wrap(~year) +  scale_y_log10() +  labs(x = "Displacement (L)", y = "Highway mpg") +  theme_minimal()

The pipe form keeps ggplot2’s function names. The method chain builds the same plot on PHP 8.3 and 8.4.

  • PHP 8.5+
  • PHP 8.3–8.4
ggplot($mpg, aes(x: 'displ', y: 'hwy', color: 'drv')) |>    geom_point(alpha: 0.5) |>    geom_smooth(method: 'lm') |>    facet_wrap('year') |>    scale_y_log10() |>    labs(x: 'Displacement (L)', y: 'Highway mpg') |>    theme_minimal();
Plot::of($mpg)    ->aes(x: 'displ', y: 'hwy', color: 'drv')    ->point(alpha: 0.5)    ->smooth(method: 'lm')    ->facetWrap('year')    ->scaleY(type: 'log')    ->labs(x: 'Displacement (L)', y: 'Highway mpg')    ->theme('minimal');

Aesthetics are named arguments, so aes(displ, hwy) becomes aes(x: 'displ', y: 'hwy'). Field names are strings. colour and alpha are accepted as aliases of color and opacity.

Differences

  • Sizes. Point size is an area in square pixels, as in Vega-Lite, rather than a diameter in millimeters. The default is 30. linewidth is in pixels.
  • Bins. bins: is a maximum, and Vega-Lite rounds the boundaries. Use binwidth: and boundary: for exact bins.
  • Limits. xlim() and ylim() zoom without removing data. ggplot2 removes the data outside the limits, which changes statistics computed from it.
  • Densities. The default bandwidth is Vega-Lite’s. adjust: multiplies R’s bw.nrd0, so adjust: 1 reproduces ggplot2’s default.
  • Smoothers. Loess, lm, quad, and poly fits and their bands are computed in PHP. Loess follows R’s loess(surface = "direct"), while ggplot2 interpolates the loess surface, so its curve can differ slightly. Above 3,000 rows, loess falls back to Vega-Lite’s transform without a band, where ggplot2 switches to a GAM. There is no gam method.
  • Colors. Categorical colors come from Vega-Lite’s palette by default. theme('gray') switches to ggplot2’s hue_pal() colors, computed for the number of levels. scaleColor(values:) or scheme: sets them explicitly.
  • Panels. A discrete axis is 300 pixels by default, the same as a continuous axis, and grows by 20 pixels per level beyond 15 levels.
  • Violins. violin() draws each violin as a Vega-Lite trail, whose ends are rounded. There is no draw_quantiles option; layer a boxplot() instead.
  • Polar coordinates. coordPolar() draws bars, columns, and arcs. Vega-Lite has no polar form for lines, points, or areas, so radar charts are not available.
  • Not available. There is no sec_axis(), no geom_dotplot(), and no geom_quantile(). Use raw() or layer() for any Vega-Lite feature phiz does not wrap.

Additions

phiz also has features that ggplot2 leaves to other packages:

  • tooltips, pan and zoom, brushing, legend highlighting, and sliders (see Interaction)
  • linked views across compositions
  • the statistics helpers for phit fits and CmdStanPHP draws (see Statistics)
  • Vega-Lite aggregates and time units in field shorthand, such as 'mean(hwy)' and 'year(date):O'
