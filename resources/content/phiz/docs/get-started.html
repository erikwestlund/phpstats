Installation

composer require phpstats/phiz

phiz supports PHP 8.3, 8.4, and 8.5 (composer.json allows >=8.3 <8.6), and CI tests all three on Linux. macOS is supported too. Examples written with the pipe operator |> need PHP 8.5, and each one also has a method-chain version for PHP 8.3 and 8.4. phiz needs only the json extension, which PHP includes by default, and has no required Composer dependencies.

These features are optional:

  • vl-convert, a standalone binary, adds svg(), png(), pdf(), and save() with those extensions. Version 1.9.0 is tested. Installing vl-convert gives the commands for Linux and macOS.
  • Laravel adds the <x-phiz> Blade component and the @phizScripts directive. The service provider is discovered automatically. The component’s tests run on Laravel 12. Laravel and Livewire covers it.
  • phit, the extension or its pure-PHP polyfill phpstats/phit-polyfill, builds design rows from a fit’s formula. Predictions for formula fits in effect_plot(), predictions(), and marginal_means() need it unless design: is given, and so do random-slope design columns in random_effects_plot() when it rebuilds conditional variances from the data. The documentation fits are checked against polyfill 0.3.0. Statistics describes the fit arrays the helpers read.

A complete first chart

In a new directory, run composer require phpstats/phiz, then save this script as chart.php beside the vendor directory:

<?php

require __DIR__.'/vendor/autoload.php';

use Phiz\Datasets;
use Phiz\Plot;

$plot = Plot::of(Datasets::mpg())
    ->aes(x: 'displ', y: 'hwy', color: 'drv')
    ->point()
    ->labs(x: 'Displacement (L)', y: 'Highway mpg', color: 'Drive');

$plot->save('chart.html');

php chart.php writes chart.html, a standalone page. Open it in a browser to see the chart. The page loads vega, vega-lite, and vega-embed from the jsDelivr CDN, so viewing it needs a network connection. save('chart.svg'), save('chart.png'), and save('chart.pdf') write static files instead and need the vl-convert binary (Rendering).

Data, mappings, and geoms

A plot starts with data and aesthetic mappings. Plot::of() takes the data, aes() maps fields to visual channels, and a geom such as point() adds a layer. The bundled Datasets class provides a few classic datasets for examples.

use Phiz\Datasets;
use Phiz\Plot;

$plot = Plot::of(Datasets::mpg())
    ->aes(x: 'displ', y: 'hwy')
    ->point();

Mapping another field to color gives each class its own color and adds a legend. Fixed properties, such as a point size or an opacity, are geom arguments.

use Phiz\Datasets;
use Phiz\Plot;

$plot = Plot::of(Datasets::mpg())
    ->aes(x: 'displ', y: 'hwy', color: 'class')
    ->point(size: 40, alpha: 0.7);

Layers

Each geom adds a layer, and layers inherit the plot’s mappings. This plot overlays a loess smoother on the points and labels the axes.

use Phiz\Datasets;
use Phiz\Plot;

$plot = Plot::of(Datasets::mpg())
    ->aes(x: 'displ', y: 'hwy')
    ->point(alpha: 0.4)
    ->smooth(span: 0.6)
    ->labs(x: 'Displacement (L)', y: 'Highway mpg');

Plots are immutable. Every method returns a new plot, so a base plot can be stored and extended in several directions.

$mpg = Datasets::mpg();
$base = Plot::of($mpg)->aes(x: 'displ', y: 'hwy');

$scatter = $base->point();
$smooth = $base->point(alpha: 0.3)->smooth(method: 'lm');

Pipes

PHP 8.5’s pipe operator composes ggplot2-style functions. ggplot() starts a plot, and each geom_*(), scale_*(), labs(), or theme_*() function returns a closure that takes a plot and returns the next one. The method chain builds the same specification on every supported PHP version.

  • PHP 8.5+
  • PHP 8.3–8.4
use Phiz\Datasets;

use function Phiz\{aes, geom_point, geom_smooth, ggplot, labs, theme_minimal};

$plot = ggplot(Datasets::mpg(), aes(x: 'displ', y: 'hwy', color: 'drv')) |>
    geom_point(alpha: 0.5) |>
    geom_smooth(method: 'lm', se: false) |>
    labs(x: 'Displacement (L)', y: 'Highway mpg', color: 'Drive') |>
    theme_minimal();
use Phiz\Datasets;
use Phiz\Plot;

use function Phiz\aes;

$plot = Plot::of(Datasets::mpg(), aes(x: 'displ', y: 'hwy', color: 'drv'))
    ->point(alpha: 0.5)
    ->smooth(method: 'lm', se: false)
    ->labs(x: 'Displacement (L)', y: 'Highway mpg', color: 'Drive')
    ->theme('minimal');

The functions and the methods accept the same arguments. On PHP 8.3 and 8.4, apply() also takes the functions, after use function Phiz\{aes, geom_point, ggplot, labs};: ggplot(Datasets::mpg(), aes(x: 'displ', y: 'hwy'))->apply(geom_point(), labs(x: 'Displacement (L)')). A plot can also apply reusable fragments with apply():

$house = fn (Plot $plot) => $plot->theme('minimal', baseSize: 12)->size(480, 300);

$plot = Plot::of(Datasets::mpg())->aes(x: 'displ', y: 'hwy')->point()->apply($house);

Output

A plot compiles to a Vega-Lite specification on demand.

$plot->toArray();        // the specification as a PHP array
$plot->toJson();         // as JSON
$plot->embed();          // an HTML fragment with the container and script tags
$plot->html();           // a standalone HTML page
$plot->svg();            // SVG through vl-convert
$plot->save('plot.pdf'); // the file extension picks the format

Rendering covers the options for each output, and Laravel and Livewire covers the Blade component.
