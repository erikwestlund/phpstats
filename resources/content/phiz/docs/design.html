Vega-Lite does the drawing

phiz does not draw graphics. It translates a ggplot2-style description into a Vega-Lite specification. Vega-Lite then resolves scales, lays out facets and legends, runs transforms, handles interaction, and renders to canvas or SVG. The PHP side stays small, and plots behave the same in the browser and in static export.

Most statistics run where Vega-Lite runs them: bins, densities, loess fits, aggregates, quantiles, and window functions are Vega-Lite transforms. phiz computes a statistic in PHP only when Vega-Lite cannot:

  • the confidence bands of smooth() with lm, quad, or poly
  • curve() evaluations of PHP functions
  • the bandwidth behind density(adjust:)
  • the statistics helpers’ intervals and predictions

Mapping ggplot2 to Vega-Lite

ggplot2 phiz Vega-Lite
ggplot(data, aes(...)) Plot::of($data)->aes(...) data and encoding
geom_*() ->point(), ->line(), … a layer with a mark
stat_*() geom parameters transform
position = "dodge" position: 'dodge' xOffset
scale_*() ->scaleX(), … the channel’s scale, axis, and legend
coord_flip() ->coordFlip() swapped channels
facet_wrap(), facet_grid() ->facetWrap(), ->facetGrid() facet with an inner spec
theme() ->theme() config
patchwork Compose hconcat, vconcat, concat

Versions

phiz emits Vega-Lite 6 specifications. The pinned browser libraries are vega 6.4.0, vega-lite 6.4.3, and vega-embed 7.3.0. Static export uses vl-convert with Vega-Lite 6.1, and the tests validate every specification against the Vega-Lite 6.1.0 JSON schema, the version both renderers support.
