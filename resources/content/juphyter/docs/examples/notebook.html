Summarize a phibble data frame in one notebook cell and plot the result in the next.

Requires the php kernel from Installation. The pipe tab needs PHP 8.5, and the method chain runs on PHP 8.3 and later.

Setup

Create a Composer project and start JupyterLab in it:

mkdir mileage && cd mileagecomposer require phpstats/phibble phpstats/phplyr \    phpstats/phiz~/.venvs/juphyter/bin/jupyter lab

Create a notebook with the PHP kernel from the launcher. The data is the mpg dataset that ships with phiz: 234 cars, with each car’s class and its highway mileage in miles per gallon (hwy).

Cells

  • A use statement applies to its own cell and every later one.
  • phplyr’s round() replaces PHP’s built-in round() in the cells after the import.
use Phibble\DataFrame;use Phiz\Datasets;use Phiz\Plot;use function Phplyr\{phplyr, group_by, summarize};use function Phplyr\{arrange, desc, n, mean, round};

A cell’s last value is its output. A phibble data frame is shown as a table.

  • PHP 8.5+
  • PHP 8.3–8.4
$mpg = DataFrame::fromRows(Datasets::mpg());$byClass = $mpg |>    group_by('class') |>    summarize(cars: n(), hwy: round(mean('hwy'), 1)) |>    arrange(desc('hwy'));$byClass;

Variables persist across cells, so the next cell plots $byClass. A phiz plot is shown as a chart.

Plot::of($byClass)    ->aes(x: 'class', y: 'hwy')    ->col()    ->labs(x: 'Vehicle class', y: 'Mean highway mpg');
