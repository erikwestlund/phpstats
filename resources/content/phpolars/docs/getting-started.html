Installing

phpolars needs PHP 8.3, 8.4, or 8.5 (non-thread-safe) on Linux or macOS. It is not on Packagist yet, so build it from a checkout:

git clone https://github.com/phpstats/phpolars && cd phpolars
PHP=$(which php) PHP_CONFIG=$(which php-config) cargo build --release
php -d extension=$PWD/target/release/libphp_polars.so script.php   # .dylib on macOS

The -d flag loads the extension for one run. To load it on every run, add extension=$PWD/target/release/libphp_polars.so, with the path written out in full, to the php.ini that php --ini reports.

The build needs a stable Rust toolchain and libclang and takes several minutes. cargo build --profile dist produces a smaller library in target/dist. The v0.1.0 release also attaches prebuilt PHP 8.5 binaries for Linux on x86_64 and arm64. See Deployment.

On macOS with Homebrew, also set LIBCLANG_PATH=$(brew --prefix llvm)/lib. When several PHP versions are installed, point PHP and PHP_CONFIG at the PHP you will load the extension into, because the build uses that PHP’s headers.

Imports

Classes live in Phpolars and functions are namespaced, so import them:

use Phpolars\{DataFrame, Series};
use function Phpolars\{col, lit, when, read_csv};

A first query

$sales = read_csv('sales.csv');

echo $sales
    ->select(
        'id',
        'product',
        col('units')->fillNull(0),
        ['revenue' => col('units')->mul(col('price'))->round(2)],
        when(col('price')->ge(5))->then(lit('premium'))->otherwise(lit('standard'))->alias('tier'),
    )
    ->head(5);

Strings passed where py-polars expects an expression input, such as select(), name columns. Use lit() for a string value there. In comparisons and arithmetic, strings are literals: col('store')->ne('S1').

Grouping

$sales = read_csv('sales.csv');

echo $sales->groupBy(['store', 'product'], maintainOrder: true)
    ->agg(
        len()->alias('rows'),
        col('units')->sum(),
        col('units')->nullCount()->alias('missing_units'),
        col('price')->max()->alias('top_price'),
    )
    ->sort(['store', 'product'])
    ->head(6), "\n";

// Shorthands aggregate every non-key column.
echo $sales->select('store', 'units', 'price')->groupBy('store')->mean()->sort('store');

Lazy queries

A LazyFrame records operations and optimizes them before running. scan_csv() starts one from a file, and collect() runs it:

$query = scan_csv('sales.csv')
    ->filter(col('units')->gt(5))
    ->groupBy('store')
    ->agg(col('units')->sum())
    ->sort('store');

echo $query->explain(), "\n\n";
echo $query->collect();
SORT BY [col("store")]
  AGGREGATE[maintain_order: false]
    [col("units").sum()] BY [col("store")]
    FROM
    Csv SCAN [sales.csv]
    PROJECT 2/6 COLUMNS
    SELECTION: col("units") > 5
    ESTIMATED ROWS: 201
