Installing

phpolars runs on PHP 8.3, 8.4, and 8.5, non-thread-safe (NTS) builds, on Linux and macOS. Install it with PIE, PHP’s extension installer:

pie install phpstats/phpolars

On Linux on x86_64 and arm64 with glibc 2.34 or later, PIE downloads a prebuilt binary. On other platforms, including macOS, it builds the extension from source, which needs a stable Rust toolchain and libclang and takes several minutes. PIE then enables the extension in php.ini. Under PHP-FPM, restart FPM afterwards so that its workers load the extension. Deployment covers servers, Laravel Forge, Laravel Herd, and manual installs.

Checking the installation

php -r 'echo phpversion("php_polars"), PHP_EOL;'

The command prints the installed version, such as 0.2.1. It checks the CLI. PHP-FPM reads its own php.ini, so check a web request separately, for example with extension_loaded('php_polars') in a page.

Imports

Classes live in Phpolars, and functions are namespaced, so import them:

use Phpolars\{DataFrame, Series};
use function Phpolars\{col, lit, when, read_csv};

A first query

$sales = read_csv('sales.csv');

echo $sales
    ->select(
        'id',
        'product',
        col('units')->fillNull(0),
        ['revenue' => col('units')->mul(col('price'))->round(2)],
        when(col('price')->ge(5))->then(lit('premium'))->otherwise(lit('standard'))->alias('tier'),
    )
    ->head(5);

Grouping

$sales = read_csv('sales.csv');

echo $sales->groupBy(['store', 'product'], maintainOrder: true)
    ->agg(
        len()->alias('rows'),
        col('units')->sum(),
        col('units')->nullCount()->alias('missing_units'),
        col('price')->max()->alias('top_price'),
    )
    ->sort(['store', 'product'])
    ->head(6), "\n";

// Shorthands aggregate every non-key column.
echo $sales->select('store', 'units', 'price')->groupBy('store')->mean()->sort('store');

Lazy queries

A DataFrame runs each method immediately. A LazyFrame records operations and runs them, optimized, when collect() is called. scan_csv() starts a lazy query from a file, so Polars reads only the columns and rows that the query needs:

$query = scan_csv('sales.csv')
    ->filter(col('units')->gt(5))
    ->groupBy('store')
    ->agg(col('units')->sum())
    ->sort('store');

echo $query->explain(), "\n\n";
echo $query->collect();
SORT BY [col("store")]
  AGGREGATE[maintain_order: false]
    [col("units").sum()] BY [col("store")]
    FROM
    Csv SCAN [sales.csv]
    PROJECT 2/6 COLUMNS
    SELECTION: col("units") > 5
    ESTIMATED ROWS: 201

Missing values

phpolars follows Polars: a missing value is null, aggregates such as sum() and mean() skip it, and null sorts first. phibble and phplyr follow R and dplyr instead. phibble and phplyr compares the two.
