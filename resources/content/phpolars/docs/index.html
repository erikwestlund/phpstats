Query and transform data with Polars from PHP. Use eager data frames, or build lazy queries with expressions.

The Composer package is phpstats/phpolars. PIE installs it as the php_polars extension, which is the name that extension= and phpversion() use. Polars runs inside the PHP process: expressions such as col('units')->mul(col('price')) run on Polars’ own threads, and PHP values are created only when code asks for them, for example with toDicts().

The API follows py-polars, Polars’ Python package, with camelCase method names and snake_case functions. Compatibility and limitations covers the differences and how agreement with py-polars is tested.

$sales = read_csv('sales.csv', tryParseDates: true);$top = $sales    ->filter(col('units')->gt(0))    ->withColumns(col('units')->mul(col('price'))->alias('revenue'))    ->groupBy('product', maintainOrder: true)    ->agg(col('revenue')->sum()->round(2), ['orders' => len()], col('price')->mean()->round(2)->alias('avg_price'))    ->sort('revenue', descending: true);echo $top;

The example reads sales.csv, the docs’ example data. Getting started has a complete script and the command that downloads the data.

What it includes

  • DataFrame and LazyFrame with py-polars’ methods: select, withColumns, filter, sort, groupBy/agg, join, unique, pivot, unpivot, explode, describe, and more.
  • Expressions with arithmetic, three-valued logic, aggregations, window functions (over), when/then/otherwise, and the str, dt, list, struct, and name namespaces.
  • Series, with the same expression methods.
  • CSV, Parquet, JSON, NDJSON, and Arrow IPC reading and writing, with lazy scans and streaming sinks, and reading and writing through PDO.
  • SQL queries over data frames.
  • A thread-pool cap for PHP-FPM (php_polars.max_threads).

Functions and methods lists every function, selector, and class, with links to the signatures.

The phpolars API or phibble and phplyr

  • The phpolars API (Phpolars\DataFrame, LazyFrame, Series, and expressions) follows Polars’ semantics. A missing value is null, and aggregates skip it.
  • phibble’s Phibble\Polars\PolarsTable runs phibble tables and phplyr pipelines in Polars with dplyr’s semantics, in which null is R’s NA. The adapter belongs to phibble and runs on this extension.

phibble and phplyr covers the choice and the differences in semantics.
