read_* functions return a DataFrame. scan_* functions return a LazyFrame, so filters and column selections are pushed into the reader. DataFrame::write*() writes a file; LazyFrame::sink*() streams a query’s result to a file without collecting it in memory.

Format Read Scan Write Sink
CSV read_csv scan_csv writeCsv sinkCsv
Parquet read_parquet scan_parquet writeParquet sinkParquet
Arrow IPC read_ipc scan_ipc writeIpc sinkIpc
NDJSON read_ndjson scan_ndjson writeNdjson sinkNdjson
JSON (array of rows) read_json writeJson
PDO database read_database writeDatabase

read_database($query, $pdo) reads a query’s result from any PDO connection. params binds placeholders through prepare() and execute(). schemaOverrides casts columns afterwards, which helps with drivers that return numbers or dates as strings: ['d' => 'Date'] parses ISO date text.

$df->writeDatabase('table', $pdo) inserts the rows in batches inside a transaction and returns the row count. ifTableExists is fail (the default), append, or replace. A new table gets portable column types: BIGINT, DOUBLE PRECISION, TEXT, BOOLEAN, DATE, and TIMESTAMP (DATETIME(6) on MySQL). List and struct values are stored as JSON text. It is tested against SQLite, PostgreSQL 17, and MySQL 8.4.

A scan runs when the query is collected. collect(engine: 'streaming'), added in v0.2.1, processes a large file in batches and keeps less of it in memory; Performance measures the difference.

Parquet, IPC, and JSON support are Cargo features. An extension built without one raises a ComputeError from that format’s functions.
