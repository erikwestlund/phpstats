Give each day of sales the price in force on that date and the mean of its units over the last three calendar days, on dates with gaps.

Requires the phpolars extension (Getting started). Script: time-series.php.

use Phpolars\DataFrame;
use function Phpolars\col;

// Daily unit sales, with no rows for March 3 and March 7.
$sales = (new DataFrame([
    'date' => ['2024-03-01', '2024-03-02', '2024-03-04', '2024-03-05', '2024-03-06', '2024-03-08'],
    'units' => [12, 15, 9, 20, 14, 18],
]))->withColumns(col('date')->str()->toDate());

// List prices, each in force from its date until the next change.
$prices = (new DataFrame([
    'from' => ['2024-03-01', '2024-03-05'],
    'price' => [4.50, 4.95],
]))->withColumns(col('from')->str()->toDate());

$priced = $sales
    ->joinAsof($prices, leftOn: 'date', rightOn: 'from')
    ->withColumns(
        col('units')->mul(col('price'))->alias('revenue'),
        col('units')->rollingMeanBy('date', '3d')->round(2)->alias('units_3d'),
    );

echo $priced;

  • joinAsof() matches backward by default. Each row of $sales gets the last row of $prices whose from is on or before its date. Both inputs must be sorted by their join columns, and unsorted input raises an InvalidOperationError. The reference covers strategy: 'forward' and 'nearest', tolerance, and by groups.
  • rollingMeanBy('date', '3d') uses the window (date - 3d, date], so it excludes the date three days earlier and includes the row’s own date. This is the default closed: 'right'. closed also accepts 'left', 'both', and 'none'.
  • The window keeps its three-day duration when dates are missing, and it holds fewer rows. The window for March 4 holds March 2 and March 4, because March 3 has no row and March 1 is the excluded endpoint.
  • rollingMean(3) would average the last three rows instead, whatever their dates.
