Give each day of sales the price in force on that date and a mean of units over the last three calendar days, on dates with gaps.

Requires the phpolars extension (Getting started). Runnable script: time-series.php.

use Phpolars\DataFrame;use function Phpolars\col;// Daily unit sales, with no rows for March 3 and 7.$sales = (new DataFrame([    'date' => [        '2024-03-01', '2024-03-02', '2024-03-04',        '2024-03-05', '2024-03-06', '2024-03-08',    ],    'units' => [12, 15, 9, 20, 14, 18],]))->withColumns(col('date')->str()->toDate());// List prices, each in force until the next change.$prices = (new DataFrame([    'from' => ['2024-03-01', '2024-03-05'],    'price' => [4.50, 4.95],]))->withColumns(col('from')->str()->toDate());$priced = $sales    ->joinAsof($prices, leftOn: 'date', rightOn: 'from')    ->withColumns(        col('units')->rollingMeanBy('date', '3d')            ->round(2)            ->alias('units_3d'),    );echo $priced;
shape: (6, 5)

  • joinAsof() takes the last price whose from is on or before each date.
  • Both inputs must be sorted by their join columns. Unsorted input raises an InvalidOperationError.
  • The '3d' window is (date - 3d, date]: it includes the row’s own date and excludes the date three days earlier.
  • A missing day leaves the window three days long, with fewer rows in it. For March 4, the window holds only March 2 and March 4.
  • rollingMean(3) would average the last three rows, whatever their dates.
