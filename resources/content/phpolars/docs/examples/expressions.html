This example summarizes each group of a data frame with several expressions in one agg() call.

Prerequisites: the phpolars extension, which needs no Composer packages. Getting started covers installing it.

The input is a small data frame of six orders across three regions. Save the script as expressions.php and run it with php expressions.php:

<?php
use Phpolars\DataFrame;
use function Phpolars\{col, len};

$orders = new DataFrame([
    'region' => ['north', 'north', 'south', 'south', 'south', 'west'],
    'customer' => ['ana', 'ben', 'ana', 'cy', 'cy', 'di'],
    'amount' => [120.0, 80.0, 45.5, 300.0, 60.0, 95.0],
    'returned' => [false, true, false, false, true, false],
]);

$byRegion = $orders
    ->groupBy('region', maintainOrder: true)
    ->agg(
        len()->alias('orders'),
        col('amount')->sum()->alias('total'),
        col('amount')->filter(col('returned')->not())->sum()->alias('kept'),
        col('customer')->nUnique()->alias('customers'),
        col('customer')->sortBy('amount', descending: true)->first()->alias('top_customer'),
    );

echo $byRegion;

groupBy() splits the rows by region, and agg() evaluates each expression once per group. An expression describes a computation on columns. It holds no data of its own, and Polars evaluates the expressions on its own threads.

  • len() counts the rows in the group.
  • col('amount')->sum() adds up a column.
  • filter() inside an expression keeps only some of the group’s rows, here the orders that were not returned, before sum() runs.
  • nUnique() counts distinct values.
  • sortBy('amount', descending: true)->first() takes the customer of the largest order.

alias() names each result column. maintainOrder: true keeps the groups in the order they first appear. Without it, the group order can change between runs.
