Summarize each group of a DataFrame with several expressions in one agg() call.

Requires the phpolars extension (Getting started). Script: expressions.php.

use Phpolars\DataFrame;
use function Phpolars\{col, len};

$orders = new DataFrame([
    'region' => ['north', 'north', 'south', 'south', 'south', 'west'],
    'customer' => ['ana', 'ben', 'ana', 'cy', 'cy', 'di'],
    'amount' => [120.0, 80.0, 45.5, 300.0, 60.0, 95.0],
    'returned' => [false, true, false, false, true, false],
]);

$byRegion = $orders
    ->groupBy('region', maintainOrder: true)
    ->agg(
        len()->alias('orders'),
        col('amount')->sum()->alias('total'),
        col('amount')->filter(col('returned')->not())->sum()->alias('kept'),
        col('customer')->nUnique()->alias('customers'),
        col('customer')->sortBy('amount', descending: true)->first()->alias('top_customer'),
    );

echo $byRegion;

  • col('amount')->filter(col('returned')->not())->sum() filters inside the aggregate. It sums only the group’s orders that were not returned, while orders and total still include every order.
  • col('customer')->sortBy('amount', descending: true)->first() orders each group’s customers by another column, amount, and takes the first. The result is the customer of the group’s largest order.
  • maintainOrder: true keeps the groups in the order they first appear. Without it, the order of the groups in the result is not guaranteed and can change between runs.
