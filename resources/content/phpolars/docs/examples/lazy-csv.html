Filter and aggregate a CSV file with a lazy query, so that Polars can push the column selection and the filter into the CSV reader.

Requires the phpolars extension (Getting started). Scripts: lazy-csv.setup.php and lazy-csv.php.

Make the input file

lazy-csv.setup.php writes orders.csv to the current directory: one million orders with six columns, about 53 MB. It stops without writing if orders.csv already exists.

use Phpolars\DataFrame;
use function Phpolars\{col, int_range};

if (file_exists('orders.csv')) {
    fwrite(STDERR, "orders.csv already exists. Run this in an empty directory.\n");
    exit(1);
}

(new DataFrame(['i' => [0]]))
    ->select(int_range(0, 1_000_000)->alias('order_id'))
    ->withColumns(
        col('order_id')->mod(4)->replaceStrict([0, 1, 2, 3], ['north', 'south', 'east', 'west'], returnDtype: 'String')->alias('region'),
        col('order_id')->mul(7919)->mod(5000)->alias('customer_id'),
        col('order_id')->mul(104729)->mod(100_000)->truediv(100)->alias('amount'),
        col('order_id')->mul(31)->mod(7)->eq(0)->alias('returned'),
        col('order_id')->cast('String')->str()->replace('^', 'note for order ')->alias('note'),
    )
    ->writeCsv('orders.csv');
use function Phpolars\{col, len, scan_csv};

$query = scan_csv('orders.csv')
    ->filter(col('amount')->gt(500)->and(col('returned')->not()))
    ->groupBy('region')
    ->agg(
        len()->alias('orders'),
        col('amount')->mean()->round(2)->alias('avg_amount'),
    )
    ->sort('region');

echo $query->explain(), "\n\n";
echo $query->collect();

The plan that explain() prints shows what the scan does:

  • PROJECT 3/6 COLUMNS: the reader converts only region, amount, and returned into values. It still reads the whole file and splits every line into fields.
  • SELECTION: the filter runs inside the scan on each chunk as it is parsed. Rows that fail it are dropped there, so they never reach the aggregation or form one large table in memory.
  • simple π 2/2: only region and amount go on from the scan to the aggregation.
  • ESTIMATED ROWS: the planner’s estimate from the file size and a sample of lines. It is not a count.

Work happens only when the query needs it:

  • scan_csv() returns without opening the file, so a missing file raises a ComputeError later, at explain() or collect().
  • Polars infers the schema from the header and the first rows when the plan first needs it, for example in explain(), collectSchema(), or collect().
  • collect() runs the optimized plan and returns a DataFrame. read_csv() would instead parse all six columns of every row before the filter runs.

collect(engine: 'streaming') runs the same query in batches. On a five-million-row version of this file (276 MB), its peak memory footprint was 71 MB, against 217 MB with the default engine (macOS, measured on 2026-11-01). The saving depends on the query. Performance measures a filtered scan.
