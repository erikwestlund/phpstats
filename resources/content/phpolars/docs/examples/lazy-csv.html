This example scans a CSV file with a lazy query, so Polars reads only the rows and columns the query needs.

Prerequisites: the phpolars extension, which needs no Composer packages. Getting started covers installing it.

The script first writes orders.csv, a file of one million orders with six columns, to the current directory, and deletes it at the end. Save the script as lazy-csv.php and run it with php lazy-csv.php:

<?php
use Phpolars\DataFrame;
use function Phpolars\{col, int_range, len, scan_csv};

// Write a CSV file of one million orders to query.
(new DataFrame(['i' => [0]]))
    ->select(int_range(0, 1_000_000)->alias('order_id'))
    ->withColumns(
        col('order_id')->mod(4)->replaceStrict([0, 1, 2, 3], ['north', 'south', 'east', 'west'], returnDtype: 'String')->alias('region'),
        col('order_id')->mul(7919)->mod(5000)->alias('customer_id'),
        col('order_id')->mul(104729)->mod(100_000)->truediv(100)->alias('amount'),
        col('order_id')->mul(31)->mod(7)->eq(0)->alias('returned'),
        col('order_id')->cast('String')->str()->replace('^', 'note for order ')->alias('note'),
    )
    ->writeCsv('orders.csv');

$query = scan_csv('orders.csv')
    ->filter(col('amount')->gt(500)->and(col('returned')->not()))
    ->groupBy('region')
    ->agg(
        len()->alias('orders'),
        col('amount')->mean()->round(2)->alias('avg_amount'),
    )
    ->sort('region');

echo $query->explain(), "\n\n";
echo $query->collect();

unlink('orders.csv');

scan_csv() returns a LazyFrame without reading the file. filter(), groupBy(), agg(), and sort() add steps to a query plan, and collect() optimizes the plan, runs it, and returns a DataFrame. read_csv() would instead load all six columns of every row into memory before the filter runs.

explain() prints the optimized plan. PROJECT 3/6 COLUMNS means that the scan reads only region, amount, and returned. SELECTION means that the filter runs during the scan, so rows that fail it are dropped as the file is read. ESTIMATED ROWS is the planner’s estimate of the file’s size, made before reading it.

collect(engine: 'streaming') runs the query in batches, which uses less memory on large files. Performance has measurements.
