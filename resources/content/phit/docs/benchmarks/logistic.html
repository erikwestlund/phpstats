The standard benchmark compares the release PHP extension, R glm(binomial) and statsmodels Logit on identical synthetic observations. The raw report preserves all timing samples, machine and runtime versions, input hashes, numerical outputs and differences from R.

def ordered_table(rows):
    table = pd.DataFrame(rows)

    return table.sort_values(["observations", "coefficients", "implementation"]).reset_index(drop=True)

What is timed?

Workers load the same CSV once, perform one untimed warm-up, and measure five full fits. Each timed fit materializes coefficients, covariance, standard errors, normal z tests, p-values, Wald intervals, every fitted probability and response residual, likelihood, deviance, null deviance, AIC and residual degrees of freedom. PHP also converts inputs and all outputs and constructs row metadata within the timer. Startup, CSV loading, data generation and final JSON serialization are excluded.

R uses formula/model construction and QR-based IRLS, with epsilon 1e-14 to stabilize covariance agreement. Python uses Newton fitting with tolerance 1e-10; PHP uses weighted SVD Newton updates and its documented convergence rules. Starting values, linear solves and stopping criteria differ. This is a comparison of complete public API calls, not equal iteration counts or isolated decomposition speeds. Common numerical-library thread variables are set to one; installed backends and requested settings are recorded. Workers run separately with order alternated between cases. Other machine activity can affect measurements. R’s elapsed timer has coarse millisecond resolution for small cases.

Simulation and agreement

NumPy RNG seed 20261011 generates study hours uniformly between 1 and 12, practice scores as clipped 45 + 3 × hours + normal noise with standard deviation 8, and independent standard-normal preparation scores for the wider case. Binary outcomes are independent Bernoulli draws with

\[\eta_i=-3.28+0.22\,\mathrm{hours}_i+0.018\,\mathrm{score}_i +0.15\sum_j\mathrm{preparation}_{ij},\qquad \pi_i=\frac{1}{1+e^{-\eta_i}}.\]

This simulation is separate from the small R-generated teaching sample; its values are unrounded and its seed is different. Every runtime reads identical 17-significant-digit CSV values. Data hashes, generating coefficients and sample correlations are recorded. All coefficient-level quantities and scalar statistics are compared with R at tolerance 1e-9 + 1e-7 × abs(reference). Full fitted/residual vectors are materialized; cross-runtime comparison samples ten evenly spaced rows, while small fixtures check complete vectors. PHP convergence must be true and its update count must be between one and 100. Wald intervals use R confint.default(), and the null baseline follows the documented intercept convention.
