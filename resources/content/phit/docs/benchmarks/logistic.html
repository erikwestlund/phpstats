phit’s fit_logistic_matrix(), R glm(binomial), and statsmodels Logit fit identical simulated observations at four sizes. The raw report keeps every timing sample, machine and runtime versions, input hashes, numerical outputs, and differences from R.

Timing boundaries

Each timed fit materializes coefficients, covariance, standard errors, normal z tests, p-values, Wald intervals, every fitted probability and response residual, likelihood, deviance, null deviance, AIC, and residual df.

Implementation Fitting
phit Weighted SVD Newton updates, with phit’s convergence rules
R Formula and model construction, then QR-based IRLS with epsilon 1e-14
statsmodels Newton with tolerance 1e-10

Starting values, linear solves, and stopping criteria differ, so iteration counts differ too. This compares complete public API calls, not decomposition speed.

Whole-process time includes loading, imports, the warm-up, and every timed fit. Peak RSS covers the whole worker, not only the solver. PHP’s memory_limit is disabled, because large nested PHP arrays can exceed typical application limits.

Simulation and agreement

Study hours are uniform between 1 and 12. Practice scores are 45 + 3 × hours plus normal noise with standard deviation 8, clipped. The wider case adds independent standard-normal preparation scores. Outcomes are independent Bernoulli draws with

\[\eta_i=-3.28+0.22\,\mathrm{hours}_i+0.018\,\mathrm{score}_i +0.15\sum_j\mathrm{preparation}_{ij},\qquad \pi_i=\frac{1}{1+e^{-\eta_i}}.\]

This simulation is separate from the small teaching sample. Data hashes, generating coefficients, and sample correlations are recorded.

Coefficient-level quantities and scalar statistics are compared with R at 1e-9 + 1e-7 * abs(reference). Fitted values and residuals are computed in full and compared at ten evenly spaced rows; the small fixtures compare full vectors. phit must report convergence within 1 to 100 updates. Wald intervals follow R confint.default(), and the null baseline follows the documented intercept convention.
