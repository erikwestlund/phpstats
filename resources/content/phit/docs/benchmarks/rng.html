The sampling API uses local ChaCha20 state and inverse CDFs. This benchmark times full PHP batches for normal, beta and Poisson at 1,000, 100,000 and one million draws. Every call reinitializes the explicit seed and allocates the complete numeric output. Raw results retain the seed, input hashes, numerical evidence, PHP version, binary hash, all timing samples, process elapsed time and peak RSS.

Independent verification first

Before any timing phase, Python independently computes the ChaCha blocks at 17 evenly spaced indices, with the pinned PCG seed expansion/Open01 mapping. Base-R quantiles transform those exact probabilities. PHP’s sampled points must match at 1e-15 + 1e-12*abs(reference); discrete values match the integer quantiles. The full output is consumed by mean/variance calculations and checked against theoretical moments within eight standard errors (using the distribution’s fourth central moment for variance). Fixed seeds make these checks deterministic.

This complements the ordinary 25-case independent stream/quantile fixture suite. It does not compare every element to R and does not claim that R’s own RNG shares the ChaCha sequence. Each timed result undergoes the same numerical checks again.

Timing interpretation

Five measurements follow one untimed warm-up. Timing includes ChaCha setup, quantile evaluation, PHP result allocation and ordinary reclamation of previous results. JSON I/O and numerical summaries are outside the timed call. Peak RSS covers the whole worker, including summaries and inputs; it is not isolated RNG state memory. These are API-level times on the recorded machine, not universal throughput guarantees or a comparison with optimized rejection samplers.

The normal/Poisson/beta cases show differing inverse-CDF costs. The method retains one numerical quantile path for every family. A future optimized sampler should be justified by measured demand and independent distribution/reproducibility tests.

Reproduction

Configure matching PHP/headers as in development. Python’s standard library and R/jsonlite are reference tools only.
