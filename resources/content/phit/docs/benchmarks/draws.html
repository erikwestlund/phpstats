R uses normalized weights, colSums, crossprod of square-root-weighted centered draws, chol/backsolve, matrix multiplication and determinant(logarithm=TRUE). The independent 80-digit fixtures and identity tests separately constrain covariance-map orientation, affine round trips and determinant sign/scale. Benchmark verification compares PHP/R results; ordinary tests provide the algebraic identity and edge-case checks.

PHP’s moments/affine calls include conversion from nested PHP numeric arrays to owned Rust vectors, strict validation, numerical computation and conversion back to PHP arrays. R starts from already numeric matrices and does not implement all of PHP’s validation/rank policies. This is an API-level workload comparison, not a measurement of isolated matrix multiplication. Map timings depend only on parameter count; the corresponding draw count labels the surrounding workload. Compensated sums in Rust and R’s BLAS cross-products have different arithmetic and runtime costs.

Reproduction and timing boundaries

Build using the matching PHP/header environment, then run:

cargo build -p phit --release --locked# R and jsonlite are benchmark-only development dependencies.PHP=/opt/homebrew/bin/php python3 tests/benchmarks/run-draws.py# Optional overrides: RSCRIPT, STATS_EXTENSION; --repeats 5 --output /path/report.json

Python 3’s standard library generates inputs with random.Random(20261012). Draws have a shared Gaussian component, independent Gaussian noise and parameter means increasing by 0.1. Nonuniform weights have deterministic zeros every 11th row. Covariances are constructed from deterministic full-rank lower factors. The affine matrix includes off-diagonal mixing and a reflection, with a nonzero shift. Temporary JSON inputs are identical for PHP and R; their SHA-256 hashes are retained in the report. No intercept column is added.

Each worker loads JSON once. Startup, input generation, JSON parsing/serialization and reference comparison are outside timed calls. Input loading is recorded separately. Both APIs compute complete result arrays/matrices in each timed call; PHP includes native input conversion, validation and result allocation. Timings also include ordinary runtime reclamation of prior results.

R’s elapsed timer has millisecond resolution. Each map measurement batches 1,000 calls. Moments/affine batch 1,000 calls for the 1,000 × 4 case, 100 for 4,000 × 16, and 10 for both larger cases; the reported value divides by the batch count. This avoids zero small-call readings but still limits R timing precision. R’s garbage collection and machine load contribute variation; raw measurements are available for review. This run does not measure peak memory, Linux, PHP-FPM, Stan evaluation, PSIS or complete moment-matching iterations.
