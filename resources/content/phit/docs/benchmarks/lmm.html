Algorithm

phit follows lme4’s penalized least-squares elimination. It separates within-group deviations from group means and caches an augmented QR square-root summary, so each trial variance ratio factors p + 1 + G rows rather than all n. Covariance is computed only for the selected solution. The walkthrough derives the reduction and checks its residual norms numerically.

phit uses nalgebra QR and SVD with no BLAS, LAPACK, or sparse backend. lme4 uses a general sparse Cholesky factorization; phit’s specialized reduction applies the same elimination and keeps SVD rank checks.

Timing boundaries and methods

Timed calls include estimation, fixed-effect covariance and normal Wald inference, variance components, ICC, likelihood/AIC, all population/conditional fits and both residual vectors, and all conditional group estimates. PHP also validates/copies inputs and converts all output arrays and group and sample metadata inside the timer.

R uses lmer REML=FALSE with bobyqa rhoend=1e-10. Python uses MixedLM ML BFGS with gtol=1e-10 and recalculates plug-in GLS covariance to align with the documented convention. Its own joint observed-Hessian covariance is a different convention and is not compared. Rust scans a log-ratio profile grid and refines analytic-score roots with compact weighted SVD GLS fits, after a one-time QR reduction. The algorithms and stopping rules differ, so this compares complete API calls, not one common solver.

Simulation and numerical checks

NumPy RNG seed 20261011 generates correlated study hours and prior scores, independent standard-normal extra predictors, and schools with roughly equal sizes. Outcomes follow

\[y_i=50+1.8\,\mathrm{hours}_i+0.2\,\mathrm{prior}_i +0.5\sum_j\mathrm{extra}_{ij}+b_{g(i)}+\epsilon_i, \quad b_g\sim N(0,6^2),\quad\epsilon_i\sim N(0,5^2).\]

This sample is separate from the saved small teaching dataset. Identical 17-significant-digit CSVs are used by every worker. All coefficient-level fields, variance components, ICC, likelihood/AIC and all group effects are checked. Observation-length outputs are fully materialized, but cross-runtime checks sample ten evenly spaced rows; small fixtures check every row.

Benchmark absolute tolerance is 1e-7. Relative tolerance is 1e-6 for ordinary outputs, 1e-5 for covariance, SE, z-statistics, variance components, sigma and ICC, and 1e-9 for likelihood/AIC. Small saved references use the tighter uniform 1e-7 + 1e-6 × abs(reference) policy.

At 100,000 rows, R’s between-group variance differed from the analytic-score solution by about 2.6e-6 relative while log-likelihood differed by only about 8e-10. The log-ratio profile score was approximately 2.55e-4 in R, -1.88e-6 in Python and 3.12e-11 in Rust. A flat likelihood and the floating-point resolution of the objective limit how closely independently optimized variance components agree, and the variance-sensitive tolerances above reflect that measurement. Likelihood agreement keeps its tight tolerance. The finite profile grid is not a proof of global optimality.
