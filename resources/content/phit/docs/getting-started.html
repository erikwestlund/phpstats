Fit a linear model to ten flats, read the estimates, and predict rents for flats that are not in the data.

The page runs with the extension or the plain-PHP polyfill. The data are simulated: rent is the monthly rent in an unnamed currency, area is the floor area in square meters, and district is one of three districts.

Data

The formula functions take named columns: an associative array of column => list of values, with every column the same length. A table object with toModelData() or toColumns(), such as a phibble DataFrame, is also accepted.

use function Phit\{fit_ols, predict};$flats = [    'rent' => [        1879.25, 1805.03, 2022.29, 1267.85, 1509.24,        2240.10, 959.51, 2386.54, 1655.80, 1420.00,    ],    'area' => [        74.4, 57.4, 66.4, 49.1, 45.7,        92.4, 37.0, 93.9, 61.2, 52.3,    ],    'district' => [        'north', 'south', 'north', 'east', 'south',        'north', 'east', 'south', 'east', 'south',    ],];
  • Numeric values make a numeric column.
  • Strings make a factor whose levels sort in byte order, so east is the reference level.
  • Model formulas lists every accepted column type.

Fit

$fit = fit_ols('rent ~ area + district', $flats);

rent is the response. area + district adds a slope for floor area and treatment-coded indicators for the districts. The intercept is included unless the formula removes it with - 1 or + 0.

fit_generalized_linear(), fit_mixed_gaussian(), and fit_mixed_logistic() return the same naming and accounting keys with the statistics of their model. See Linear and generalized linear models and Mixed models.

Predict

predict() rebuilds the formula over new data. The response column is not needed, and factor levels are those the fit saw.

$new = [    'area' => [55.0, 80.0],    'district' => ['east', 'north'],];$p = predict($fit, $new, interval: 'prediction');foreach ($p['fit'] as $i => $value) {    printf(        "%.2f [%.2f, %.2f]\n",        $value,        $p['lower'][$i],        $p['upper'][$i],    );}
1407.55 [991.59, 1823.51]
2090.69 [1676.97, 2504.41]
  • interval: 'prediction' covers one new flat’s rent. interval: 'confidence' covers the mean rent.
  • A district the fit never saw throws an exception with code 1001.
  • Prediction covers generalized linear and mixed-model predictions.

Missing values

null and NAN are missing. By default, a row with a missing value in any column the formula uses is dropped, and the fit emits one E_WARNING. With rent set to null in the third row, the warning reads:

Phit\fit_ols(): dropped 1 of 10 observations with missing values (listwise deletion)
  • The result reports n_observations 9, n_input 10, and dropped_rows [2].
  • diagnostics.warnings records listwise deletion removed 1 of 10 original rows.
  • missing: 'raise' rejects missing values. The call throws an Exception with code 1001 and the message missing values found with missing='raise'.

Missing values defines which values count as missing and how rows are counted.

Errors

Invalid input and failed fits throw a PHP Exception. getCode() gives the category, for example:

Code Meaning
1001 Invalid input
1002 Mismatched lengths
1004 Rank-deficient design
1006 Nonconvergence
