Generate reproducible samples with dist_{family}_rng(). Each call starts a new random stream from the supplied seed and returns a PHP array.

// Default mean 0 and SD 1.$normal = Phit\dist_normal_rng(n: 5, seed: 42);$measurements = Phit\dist_normal_rng(    n: 8,    seed: 20261012,    mean: 10,    sd: .5,);$counts = Phit\dist_poisson_rng(    n: 8,    seed: 20261013,    lambda: 3.2,);$beta = Phit\dist_beta_rng(n: 8, seed: 17, alpha: 2, beta: 5);

Signature and parameters

dist_{family}_rng(int $n, int $seed, ...parameters): array. The parameters and defaults are those of the probability functions.

  • n is an integer in [0, 1000000]. Both n and seed are required.
  • seed is a nonnegative PHP integer, from 0 to PHP_INT_MAX (2^63 − 1 on the supported 64-bit platforms).
  • The result is a packed list<float> of exactly n finite values. Discrete counts are floats too.
  • Sampling is already a batch operation, so there is no scalar form and no _array suffix.

Reproducibility and state

  • The same seed and parameters give the same result within the same build.
  • A shorter request returns the prefix of a longer one.
  • Calls do not share a stream, so one call never advances another.
  • PHP’s mt_srand() and other application RNG state are neither read nor changed.
  • There is no time-based seed, no OS entropy, no retained RNG object, and no hidden global state.
  • A seed selects the same uniform sequence for every family, so reusing a seed couples the results through their quantiles. Use different seeds for batches that should be independent.
  • Seeds are not designed to match R’s or NumPy’s generators.
  • Results can change between phit versions when a dependency or quantile algorithm changes. Bitwise agreement across library versions, compilers, or platform math libraries is not promised.

Uniform, categorical, and permutation sampling

Four samplers have no probability functions. They take the same n and seed arguments, have the same limits, and use one uniform from the same stream per draw.

Function R equivalent Returns
dist_uniform_rng(n, seed, min = 0, max = 1) runif(n, min, max) list<float>
dist_categorical_rng(n, seed, prob) sample(length(prob), n, replace = TRUE, prob = prob) - 1 list<int>

permutation_rng(n, seed, size = null) sample(n, size) - 1 list<int> 
$x = Phit\dist_uniform_rng(n: 5, seed: 1, min: -1, max: 1);$categories = ['returns', 'sizing', 'quality'];$picked = array_map(    fn ($k) => $categories[$k],    Phit\dist_categorical_rng(        n: 5,        seed: 2,        prob: [.2, .5, .3],    ),);// One rating per review, each from its own probabilities.$ratings = Phit\dist_categorical_rows_rng(    seed: 3,    prob: [[.1, .6, .3], [.7, .2, .1]],);// All of 0..9.$shuffled = Phit\permutation_rng(n: 10, seed: 4);// The first three.$subset = Phit\permutation_rng(n: 10, seed: 4, size: 3);

Indices are 0-based, so they index PHP lists directly. Add one for R’s 1-based categories.

  • Uniform. Each draw is min + (max - min) * u, as in R’s runif(). min must not exceed max, and min == max gives min.
  • Categorical. prob is a list of finite, nonnegative weights with a positive sum, divided by their sum as in R’s sample(). The draw for u is the first index k with u * sum(prob) < prob[0] + ... + prob[k]. A zero weight is never drawn. If rounding puts u * sum(prob) at or above the sum, the last positive weight is drawn.
  • Rows. dist_categorical_rows_rng() takes up to one million weight vectors and returns one draw per row. Rows may differ in length. Draw i uses the ith uniform, so equal rows give dist_categorical_rng()’s result for the same seed.
  • Permutation. permutation_rng() runs a partial Fisher–Yates shuffle of 0..n-1. Step i swaps position i with i + floor(u * (n - i)), capped at n - 1. size is in [0, n] and defaults to n. A smaller size returns the prefix of the full permutation.

These samplers use the same uniforms as the other families, so their results also differ from R’s for the same seed.

Errors

Condition Exception code
Negative n or seed, a parameter outside its domain, a non-list prob, a negative weight, a zero weight sum, min > max, or size > n 1001
Nonfinite parameter, weight, weight sum, or bound; a sample beyond the binary64 range 1003
More than one million draws or rows, or a permutation n above one million 1007
Wrong PHP argument type PHP runtime error (code 0)
  • Parameters are validated even when n is 0. A valid empty request returns [].
  • A sample beyond the binary64 range rejects the whole batch. No partial results, dropped samples, or infinities are returned. Very heavy tails or extreme scales can therefore fail with finite parameters.
  • The one-million limit bounds one allocation. Callers control the total workload.

Implementation and reproducibility

Each output takes a 64-bit word from ChaCha20. rand’s Open01<f64> maps its upper 52 bits to a midpoint strictly inside (0, 1), and the family’s validated inverse CDF transforms it.

  • One uniform per sample, including point masses.
  • The open interval excludes infinite support endpoints. The smallest and largest representable tail probabilities are 2^-53 and 1 − 2^-53.
  • Inverse-CDF sampling keeps one numerical path for all 13 parameterizations, at some cost against family-specific samplers. The sampling benchmarks measure normal, beta, and Poisson batches.
  • The pinned rand_core seed_from_u64 expands the integer seed into the 256-bit ChaCha key with its documented PCG32 mapping.
  • Dependencies: rand 0.9.5 and rand_chacha 0.9.0, pinned in the lock file. Their MIT license notices are under third-party/. A change to either, or to a quantile algorithm, is reviewed as a reproducibility change.
