These ten functions summarize ordinary PHP numeric arrays. They are deterministic, stateless native calculations; no intercept, model fitting or retained sample object is involved. Array keys are ignored and iteration order aligns pairs and weights. Results are floats except stat_quantile_array, which returns a packed list in probability-array iteration order.

Calls and conventions

Phit\stat_mean(array $values, string $missing = 'raise'): float;Phit\stat_var(array $values, string $type = 'sample', string $missing = 'raise'): float;Phit\stat_sd(array $values, string $type = 'sample', string $missing = 'raise'): float;Phit\stat_cov(array $x, array $y, string $type = 'sample', string $missing = 'raise'): float;Phit\stat_cor(array $x, array $y, string $missing = 'raise'): float;Phit\stat_quantile(array $values, float $p, string $missing = 'raise'): float;Phit\stat_quantile_array(array $values, array $probabilities, string $missing = 'raise'): array;Phit\stat_median(array $values, string $missing = 'raise'): float;Phit\stat_weighted_mean(array $values, array $weights, string $missing = 'raise'): float;Phit\stat_weighted_var(array $values, array $weights, string $type = 'frequency', string $missing = 'raise'): float;

type: 'sample' variance/SD/covariance divides by n−1; 'population' divides by n. Population variance/SD permits one value and returns zero. Covariance/correlation requires at least two aligned retained pairs under either normalization. Other summaries require one retained value. Correlation with a constant input is NAN, an explicitly undefined statistic. An empty requested probability array returns [] after validating the supplied values.

Quantiles use R’s default type 7 interpolation. For sorted values x, index \(h=1+(n-1)p\); interpolate between adjacent values using the fractional part of h. p must be in [0,1]. Endpoints are the minimum and maximum. Median is the type-7 quantile at p=0.5. The batch function sorts once for all requested probabilities; it returns exactly the same values as scalar calls.

Weight definitions

Let \(W=\sum_i w_i\), \(m=\sum_i w_i x_i/W\), and \(SS=\sum_i w_i(x_i-m)^2\). Weights must be nonnegative and finite; the retained total must be positive.

Weighted variance type Definition Interpretation
frequency (default) \(SS/(W-1)\) Replication/count weights; requires W > 1
reliability \(SS/(W-\sum_i w_i^2/W)\) Reliability/precision weights; requires a positive denominator
population \(SS/W\) Weighted population second moment

Frequency and reliability weighting differ. Integer frequency weights reproduce the sample variance of an expanded sample. Reliability/population results are invariant to multiplying all weights by a positive constant. Zero weights are allowed. One effective value has zero population variance but undefined reliability variance. Negative weights are rejected even when the paired value is missing. Weights are aligned to original input positions before pairwise deletion. The separate draw moments API always normalizes weights and calls reliability normalization 'unbiased'; it never treats weights as counts.

Missing values and errors

Null and NAN are missing values. The default missing: 'raise' rejects them with 1001. missing: 'drop' explicitly removes them, pairwise for covariance, correlation and weighted functions. No warning or retained-row metadata is returned; dropping is opt-in. Infinity always raises 1003, including an element paired with a missing value. Strings, booleans, objects and nested arrays raise 1001. All aligned arrays must have equal original lengths, or 1002 is raised.

Unsupported type/missing options, insufficient retained values, invalid weights or invalid probability domains raise 1001. NAN probability raises 1003. Nonfinite arithmetic results also raise 1003, including an overflowing weight sum or squared deviation. The explicit NAN for constant-input correlation remains valid. This release fixed a case where an overflowing variance had been hidden as zero by floating-point max(NAN, 0).

Sums use Neumaier compensation; variances/covariances use corrected two-pass centered moments. This improves accuracy with large common offsets. These are binary64 calculations and do not promise arbitrary-scale extended precision.

Density estimation, interpolation, and the ECDF

Five functions follow R’s density(), bw.nrd0(), bw.nrd(), approx(), and ecdf(). Argument names match R’s.

Phit\stat_density(array $x, string|float $bw = 'nrd0', float $adjust = 1.0, string $kernel = 'gaussian',    int $n = 512, ?float $from = null, ?float $to = null, float $cut = 3.0, ?array $weights = null,    string $missing = 'raise'): array; // ['x' => list, 'y' => list, 'bw' => float, 'n' => int]Phit\stat_bw_nrd0(array $x, string $missing = 'raise'): float;Phit\stat_bw_nrd(array $x, string $missing = 'raise'): float;Phit\stat_approx(array $x, array $y, array $xout, string $method = 'linear', int $rule = 1,    string $ties = 'mean', float $f = 0.0, string $missing = 'raise'): array;Phit\stat_ecdf(array $x, array $q, string $missing = 'raise'): array;

stat_density reproduces R’s algorithm. The data are binned linearly onto a grid of at least 512 points (the next power of two above n), convolved with the kernel by FFT, and interpolated onto n points from from to to. The grid ends default to the data range extended by cut bandwidths. The bandwidth is 'nrd0' (Silverman’s rule, the default), 'nrd' (Scott’s variation), or a positive number, and is multiplied by adjust. The kernels are gaussian, epanechnikov, rectangular, triangular, biweight, cosine, and optcosine. Weights are used as given, as in R. Weights that sum to one are renormalized after missing values are dropped. The automatic bandwidths ignore weights, as R’s do. R’s ucv, bcv, and SJ bandwidths are not available.

stat_approx sorts the points by x and collapses tied x values by ties ('mean', 'min', or 'max'). It then interpolates linearly or, with method: 'constant', by a step function in which f weights the right-hand value. Outside the data range, rule: 1 returns NAN and rule: 2 returns the value at the nearer end. stat_ecdf returns the proportion of x at or below each q.

The data arrays (x, y, and weights) follow the missing-value policy above. Pairs are dropped together. Evaluation points (xout and q) may be infinite, and a null or NAN point returns NAN, as R returns NA.

$draws = Phit\dist_normal_rng(4000, 7, 0.3, 0.05);$d = Phit\stat_density($draws);$heights = Phit\stat_approx($d['x'], $d['y'], [0.25, 0.3, 0.35]);$below = Phit\stat_ecdf($draws, [0.0]); // share of draws at or below zero
