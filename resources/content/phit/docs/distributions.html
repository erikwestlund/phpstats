Evaluate densities, probabilities, and quantiles for 12 distribution families in 13 parameterizations (negative binomial has two), one value at a time or for a whole array. Each function returns a PHP float or a packed PHP array.

$p = Phit\dist_normal_cdf(x: 1.96); // 0.975$tails = Phit\dist_t_sf_array(values: [1, 2, 3], df: 12);$logMass = Phit\dist_poisson_logpmf_array(    counts: [0, 2, 5],    lambda: 3.2,);$interval = Phit\dist_gamma_quantile_array(    probabilities: [.025, .975],    shape: 2,    scale: 3,);
  • Draw random samples with the seeded dist_{family}_rng() functions in Seeded sampling. The uniform, categorical, and permutation samplers are described there too.
  • Distribution functions evaluate a specified distribution. To estimate parameters from data, use a model such as fit_generalized_linear(family: 'poisson').
  • Descriptive statistics summarize supplied values, and the posterior-draw kernels summarize draw matrices.

Operations

Replace {family} with a parameterization name from the next table.

Operation Scalar function Returns
Density dist_{family}_pdf(x, ...) Continuous density f(x)
Log density dist_{family}_logpdf(x, ...) ln f(x)
Mass dist_{family}_pmf(k, ...) Discrete P(X = k)
Log mass dist_{family}_logpmf(k, ...) ln P(X = k)
CDF dist_{family}_cdf(x_or_k, ...) P(X ≤ x)
Log CDF dist_{family}_logcdf(x_or_k, ...) ln P(X ≤ x)
Survival dist_{family}_sf(x_or_k, ...) P(X > x), computed directly
Log survival dist_{family}_logsf(x_or_k, ...) ln P(X > x)
Quantile dist_{family}_quantile(p, ...) Inverse CDF, p in [0, 1]

Continuous families have pdf and logpdf. Discrete families have pmf and logpmf. That gives seven operations for each of the 13 parameterizations, or 91 scalar functions.

Every operation also has an _array form with the same parameters and defaults. Its first argument is an array.

Families and parameters

Each row is one parameterization. Parameters are listed in call order, with defaults. Every parameter must be finite and inside its domain.

Family Parameters Support and domain
normal mean = 0, sd = 1 Real line; sd > 0
t df Standard Student’s t, no location or scale; df > 0
chisquare df x ≥ 0; df > 0
f df1, df2 x ≥ 0; both positive
beta alpha, beta [0, 1]; both positive
gamma shape, scale = 1 x ≥ 0; both positive; mean shape * scale
exponential rate = 1 x ≥ 0; rate > 0; mean 1 / rate
lognormal meanlog = 0, sdlog = 1 x > 0; log X is Normal(meanlog, sdlog); sdlog > 0
logistic location = 0, scale = 1 Real line; scale > 0
binomial size, prob Integers 0..size; size an integer in 0..2^53; prob in [0, 1]
poisson lambda Nonnegative integers; lambda ≥ 0
nbinom size, prob Failures before the size-th success; real size > 0; prob in (0, 1]
nbinom_mu size, mu Same distribution; size > 0, mu ≥ 0; variance mu + mu^2 / size
  • Gamma’s second parameter is a scale. Exponential’s is a rate.
  • Negative-binomial size is a positive real dispersion parameter, not a trial count. The two forms agree when prob = size / (size + mu).
  • Poisson lambda = 0, binomial size = 0 or prob of 0 or 1, and negative-binomial prob = 1 or mu = 0 are point masses.

Batch evaluation

  • The output is a packed list in input iteration order. Keys are not kept.
  • Empty input returns [], but the parameters are still validated.
  • One invalid element rejects the whole call. No elements are dropped.
  • The distribution is constructed once per call. The benchmarks show when batching saves PHP call overhead.

Tails and likelihoods

Use the survival function for upper tails, and the log functions when a probability may underflow.

Phit\dist_normal_sf(10);    // 7.62e-241 - Phit\dist_normal_cdf(10); // 0.0// -804.61; dist_normal_sf(40) is 0.0Phit\dist_normal_logsf(40);$logLikelihood = array_sum(    Phit\dist_poisson_logpmf_array([2, 5, 3, 0], lambda: 2.5),);
  • A density is not a probability and can exceed one.
  • Sum log densities or log masses to get the log-likelihood of independent observations.
  • The log probability of an impossible event is -INF. json_encode() with JSON_THROW_ON_ERROR rejects nonfinite values, so choose a serialization policy for them.

examples/distributions.php shows a two-sided t test, a confidence interval for a mean, a Poisson likelihood, extreme upper tails, and the two negative-binomial forms.

Boundaries

  • Outside the support, a density or mass is 0 and its log is -INF.
  • A boundary density can be infinite, for example a beta density with a shape below one at an endpoint.
  • A discrete PMF at a non-integer count is 0. CDF and SF use the floor of the evaluation point, and SF always means strictly greater.
  • Continuous quantiles at p = 0 and p = 1 are the support bounds, including infinities.
  • A discrete quantile is the smallest support value whose CDF reaches p. The comparison allows a relative 64 * EPSILON on the smaller tail, to absorb rounding at CDF steps. A point mass returns its location at p = 1, which differs from R and SciPy in some degenerate cases.
  • Count quantiles are returned as PHP floats, so they are exact only up to 2^53.

Evidence

  • Distributions: verification compares phit with R, SciPy, and 60-digit mpmath references, with tolerances for each quantity and the documented boundary differences.
  • Distributions: performance covers 1,000, 100,000, and one million values, including peak memory.

Implementation notes

The distribution functions use their own module, not the estimators’ statrs paths. An audit of statrs 0.19 on the saved R cases (raw results) found lost small tails, a relative binomial CDF error near 4.8e-4 at size one million, and inaccurate extreme quantiles. statrs has no log-tail API, so the audit used log(CDF) and log(SF).

Families Probability backend Density and extreme tails
Normal, lognormal cdflib Cody normal tails Split normal density; Mills-ratio log tails; safeguarded quantiles
Student’s t, F, beta cdflib TOMS 708 incomplete beta Stable log beta and gamma terms; log-scale incomplete-beta fraction
Gamma, chi-square cdflib TOMS 654 incomplete gamma Stable densities; log-scale gamma series and fraction
Binomial, negative binomial cdflib incomplete beta Loader saddle-point mass; direct log tails
Poisson cdflib incomplete gamma Loader Poisson mass; log-scale gamma tails
Exponential, logistic Closed-form Rust expm1, log1p, and stable softplus
  • The runtime pins the MIT-licensed cdflib = 0.4.3. GPL nmath ports were not used.
  • Both tails are computed independently, with custom log-scale expansions below 1e-280.
  • Continuous quantiles use bracketed Newton steps on the log tail.
  • The mean-form negative binomial converts its parameters without overflowing size + mu.
  • There is no R, Python, or BLAS runtime dependency.

These methods make numerical failure explicit. They do not prove accuracy for every finite argument or arbitrarily extreme shape.
