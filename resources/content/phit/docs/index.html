Fit statistical models, compute probability distributions, and summarize data in PHP. Model functions accept formulas or explicit designs and return PHP arrays.

Formulas follow R: rent ~ area + district models rent from floor area and district. phit builds the numeric design from named columns, including factors, interactions, and transformations such as log(area).

use function Phit\{fit_ols, predict};$fit = fit_ols('rent ~ area + district', $flats);// ['(Intercept)' => 352.64, 'area' => 19.18, ...]$fit['named'];$fit['p_values'];  // One per coefficient, in the same order$fit['r_squared']; // 0.927$p = predict(    $fit,    ['area' => [55.0], 'district' => ['east']],    interval: 'prediction',);// [1407.55], with $p['lower'] and $p['upper']$p['fit'];

A first model runs this example with its data.

Each model also has a matrix function, such as fit_ols_matrix(), for code that builds its own design. See Matrix model functions.

Results

  • Coefficient names, treatment contrasts, term order, deviance, and AIC follow R’s lm() and glm(). Mixed models follow lme4.
  • Rows with missing values are dropped with a warning, and every result reports which rows it used.
  • Errors are PHP exceptions with stable numeric codes.
  • The verification pages compare each model with R, lme4, and statsmodels and record the tolerances.

Requirements

phit runs on non-thread-safe PHP 8.3, 8.4, and 8.5 on Linux and macOS. It installs with PIE or from prebuilt Linux binaries (Installation). Where the extension cannot be installed, the plain-PHP polyfill provides every function except the CSV reader, and runs more slowly.
