Conventions that must match

ML is explicit: R and statsmodels otherwise support/default to REML, which fits a different variance criterion. Likelihood here integrates over group effects. Fixed-effect standard errors use plug-in GLS covariance (X’ V^-1 X)^-1, matching lme4. statsmodels’ reported joint observed-Hessian covariance can differ, so the Python runner explicitly recalculates the declared GLS convention using its fitted variance components; it does not claim its unmodified bse_fe matches every case. Normal z-based Wald intervals are constructed explicitly for every reference.

Our df_residual=n-p is informational. R mixed-model df methods may include the two variance parameters; no finite-sample t degrees of freedom are claimed here. AIC counts p+2 parameters in every case, including a zero variance boundary.

The exact tau²=0 fixture is checked against lme4 and PHP, with a separately labeled NumPy OLS-limit reference. It is not represented as a converged statsmodels mixed fit. At this boundary, variance is RSS/n and standard errors differ from OLS’s unbiased-scale inference. This explicit check avoids treating an approximate positive-variance optimizer solution as proof of exact boundary behavior.
