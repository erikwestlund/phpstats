More than two grouping levels

The fitter accepts any number of random terms. The synthetic cases use 256 repeated assessments of 64 students in 32 classes, 16 schools, and 8 districts. They fit three grouping levels (district/school/class) and four (district/school/class/student), each under ML and REML. The four-level simulation has independent Gaussian intercepts at all four levels; the three-level simulation omits the student effect. Study hours and practice scores are correlated observed predictors.

  • Random terms are independent of one another. Observations are dependent because they share group effects: two observations in the same class but of different students share the district, school, and class effects, but not the student effect or the observation noise.
  • Nested IDs must be globally unique. The matrix interface does not infer that a class belongs to a school, so reusing class number 1 across schools without a parent-aware key specifies a crossed effect. The formula interface’s (1 | g1/g2) builds these keys.
  • Three grouping levels plus the observation level are often called a four-level model. This page counts grouping terms to avoid the ambiguity.

  • Nesting adds no correlation parameter between levels; each term has its own variance.
  • Random slopes can be supplied through each term’s z columns, subject to identifiability.
  • Nested terms are factored block by block, one block per district here. The dense limits of 512 random coefficients and 50,000,000 initial matrix entries apply only to crossed designs, which connect all the random columns into one block.

  • statsmodels estimates the ML and REML fixed effects and variance components independently.
  • Fixed-effect standard errors are the plug-in GLS covariance computed from statsmodels’ estimates, as lme4 and phit report it. statsmodels’ default joint-Hessian standard errors differ.
  • Convergence is required and Python warnings are kept. BFGS uses gtol = 1e-8; at 1e-10 the REML fit reached the same likelihood but reported nonconvergence, so it is not used.
  • statsmodels’ MixedLM has no prior weights, so this comparison covers sleepstudy only.
