Each walkthrough derives one estimator step by step on a small data set: the objective, the matrices, the solution, the uncertainty and, where it applies, the likelihood. Each shows the intermediate quantities, and the comparison notebooks fit the same models in R, statsmodels and phit. The pages show saved outputs, so reading them needs no Python or R.

OLS

  • OLS mathematics: derives the estimator and evaluates each intermediate quantity on the PHP example data.
  • OLS verification: estimates identical models in R, Python statsmodels and the PHP extension, displays results and checks agreement.
