We now model a binary or grouped-binomial outcome with a Gaussian random intercept. The outcome distribution changes; the group-effect distribution remains Gaussian. This walkthrough uses the published cattle-disease cbpp data from lme4, with 56 herd/period records across 15 herds. Period one is the baseline. Data source: Lesnoff et al. (2004), Preventive Veterinary Medicine 64, 27–40. The CSV, provenance/checksum and license are included in the site.

Observed counts and constructed predictors

\[ s_i\mid b_{g(i)}\sim\operatorname{Binomial}(m_i,p_i),\qquad \eta_i=o_i+x_i^\top\beta+b_{g(i)},\qquad p_i=\frac{1}{1+e^{-\eta_i}}. \]

Here s is the observed number of new cases and m the number of animals at risk. The API takes y=s/m and weights=m; m=1 gives ordinary binary observations. The known offset o is zero in this example. The fixed columns are ones and indicators for observed periods 2, 3 and 4. These are data/prepared predictors, not guesses at coefficients.

Matrix multiplication takes each observed row’s dot product with beta. The result is log odds, not a probability. The inverse-logit converts it to a probability; adding a herd effect shifts those log odds before conversion.

Conditional likelihood and random-effect law

For one observation,

\[ \log f(s_i\mid b)=\log {m_i\choose s_i} +s_i\eta_i-m_i\log(1+e^{\eta_i}). \]

We specify b_g~N(0,tau²). Write b_g=tau*u_g with u_g~N(0,1), so zero tau is a valid boundary without computing log(0). The fixed coefficients and tau are estimated by marginal maximum likelihood:

\[ L(\beta,\tau)=\prod_g\int \left\{\prod_{i\in g}f(s_i\mid u_g;\beta,\tau)\right\} \phi(u_g)\,du_g. \]

We integrate over unobserved group effects. Merely finding their best values and ignoring this integral would fit a different objective. No prior is placed on beta or tau in this implementation; the Gaussian distribution describes population variation among groups.

Find each conditional mode

Apart from constants independent of u, the log integrand is

\[ k_g(u)=\sum_{i\in g}\{s_i\eta_i-m_i\log(1+e^{\eta_i})\}-\tfrac12u^2. \]

Its score and negative curvature are

\[ k'_g(u)=\tau\sum_{i\in g}(s_i-m_ip_i)-u,\qquad h_g(u)=-k''_g(u)=1+\tau^2\sum_{i\in g}m_ip_i(1-p_i). \]

The prior contributes the 1, making the log integrand strictly concave: every group has a unique conditional mode, even when all its outcomes are failures or successes. Safeguarded Newton updates use u + score/h; a bracket prevents an oversized step from escaping the root.

Returned random_effects are these conditional modes. With a non-Gaussian outcome, the conditional distribution can be skewed, so its mean and mode need not coincide. Gaussian mixed models have coincident means/modes.

Laplace approximation: use height and curvature

Approximating k by a quadratic near its mode gives

\[ \log L_g\approx\sum_{i\in g}\log{m_i\choose s_i} +k_g(\hat u_g)-\tfrac12\log h_g. \]

The Gaussian prior’s normalization cancels the quadratic integral’s sqrt(2*pi). The curvature term is essential: a narrow peak has less probability mass than a wide peak of the same height. This is the default one-node approximation, matching lme4 glmer(nAGQ=1).

Adaptive Gauss-Hermite quadrature

Let z_j,w_j integrate expectations under N(0,1). Center and scale those nodes at the conditional mode: u_j=mode+z_j/sqrt(h). Then

\[ L_g\approx\left\{\prod_{i\in g}{m_i\choose s_i}\right\} \frac{1}{\sqrt{h_g}}\sum_jw_j \exp\{k_g(u_j)+z_j^2/2\}. \]

For one node z=0,w=1, this is exactly Laplace. More nodes examine the shape away from the peak. We evaluate the sum with log-sum-exp to avoid underflow.

The Rust code gets nodes from eigenvalues of the Hermite Jacobi matrix, whose neighboring entries are sqrt(1), sqrt(2), etc. At 61 nodes, tiny eigenvector components gave insufficient relative accuracy for tail weights. We instead compute weights using the orthonormal polynomial sum w=1/sum(p_k(z)^2). An independent regression test verifies a tail weight of approximately 9.37e-47. Moment checks alone did not expose that tail problem.

Fixed-effect uncertainty comes from the marginal objective

The optimizer searches beta and tau jointly. Each objective evaluation solves all conditional modes and integrates the group effects. Fixed-effect covariance uses the beta block of the inverse joint observed information of the chosen approximate marginal likelihood. It includes coupling to estimated tau; it is not simply the inverse conditional X’WX matrix.

The implementation uses centered finite differences with Richardson extrapolation, then a Cholesky solve. Nonpositive information, nonstationary solutions and exhausted optimizer budgets fail explicitly. Standard errors, z tests and 95% normal Wald intervals are asymptotic approximations. There are no random-variance intervals, finite-group t corrections or REML in this binomial fitter.

Approximation accuracy: a rare-event example

The verification includes independent QUADPACK integration, which does not use Hermite nodes. On the rare-event sample, Laplace and R agree but the fitted group SD differs substantially from higher-node estimation. This is an approximation issue, not a disagreement between implementations.

Use increasing node counts to assess sensitivity, especially for rare outcomes and small groups. The verification reports errors at each fitted parameter vector; 61 nodes is still an approximation, not an accuracy guarantee for every dataset. fixed_fitted evaluates probabilities at b=0; it is not a population probability averaged over b. fitted uses each group’s conditional mode.

The code is crates/stats-core/src/logistic_mixed.rs. The core owns numeric vectors/matrices and returns Result<LogisticMixedResult, StatsError>. The PHP binding handles original input validation, one shared missing-row mask, group labels and plain-array output. Application fitting does not invoke R or Python.
