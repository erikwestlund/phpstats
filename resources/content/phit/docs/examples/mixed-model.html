Fit test scores on study hours with a random intercept for each school, then read the fixed effects, the variance components, and each school’s estimated effect.

The example runs with the phit extension or the plain-PHP polyfill (Extension or polyfill). The data are 30 simulated students, five from each of six schools, taken from docs/data/schools.csv. score is a test score in points, and study_hours is time spent studying, in hours.

Code

use function Phit\fit_mixed_gaussian;

$students = [
    // Five students from each of school-01 to school-06.
    'school' => array_merge(...array_map(fn ($s) => array_fill(0, 5, "school-0$s"), range(1, 6))),
    'study_hours' => [11.58, 2.7, 10.02, 3.71, 4.38, 4.3, 2.8, 11.5, 1.15, 3.9, 7.27, 1.24, 6.08, 1.37, 11.43,
        8.82, 11.44, 5.52, 2.04, 4.93, 3.52, 3.39, 1.15, 8.2, 9.63, 6.3, 9.93, 2.54, 2.08, 5.78],
    'score' => [78.3, 67.2, 88.2, 68.5, 60.1, 69.2, 59.1, 92.1, 64.4, 67.1, 72.9, 55.8, 62.6, 52.6, 83.1,
        63.7, 83.9, 52.8, 51.9, 57.1, 68.3, 67.6, 60.5, 81.6, 75.2, 81.5, 89.4, 60.7, 62.5, 68.6],
];

$fit = fit_mixed_gaussian('score ~ study_hours + (1 | school)', $students);

foreach ($fit['columns'] as $i => $name) {
    printf("%-12s %7.2f (se %.2f)\n", $name, $fit['coefficients'][$i], $fit['std_errors'][$i]);
}

$school = $fit['random'][0];
printf("\nschool SD %.2f, residual SD %.2f\n\n", sqrt($school['covariance'][0][0]), $fit['sigma']);

foreach ($school['group_labels'] as $g => $label) {
    printf("%s %+6.2f (se %.2f)\n", $label, $school['effects'][$g][0], sqrt($school['effects_cond_var'][$g][0][0]));
}

Interpretation

(1 | school) gives each school its own intercept, drawn from a normal distribution whose standard deviation the model estimates. The fit uses REML, as lme4::lmer() does by default.

  • Fixed effects describe the average school. The study_hours coefficient is the difference in score associated with one more study hour within a school. The model gives every school the same slope.
  • Variance components. The school SD measures how much school intercepts vary. The residual SD measures how much students vary around their own school’s line. With six schools, the school SD is estimated imprecisely.
  • School effects. effects holds each school’s predicted random intercept, the conditional mode that R’s ranef() reports. It is the school’s distance from the average intercept at the same study hours. The estimates are shrunk toward zero, more so for schools with fewer students. Every school here has five students, so their conditional standard errors are equal.
