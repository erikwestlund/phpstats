Fit test scores on study hours with a random intercept for each school, then read the fixed effects, the variance components, and each school’s estimated effect.

The example runs with the phit extension or the plain-PHP polyfill (Extension or polyfill). The data are 30 simulated students, five from each of six schools, taken from docs/data/schools.csv. score is a test score in points, and study_hours is time spent studying, in hours.

Code

use function Phit\fit_mixed_gaussian;// One line per school, five students each.$students = [    'school' => array_merge(...array_map(        fn ($s) => array_fill(0, 5, "school-0$s"),        range(1, 6),    )),    'study_hours' => [        11.58, 2.7, 10.02, 3.71, 4.38,        4.3, 2.8, 11.5, 1.15, 3.9,        7.27, 1.24, 6.08, 1.37, 11.43,        8.82, 11.44, 5.52, 2.04, 4.93,        3.52, 3.39, 1.15, 8.2, 9.63,        6.3, 9.93, 2.54, 2.08, 5.78,    ],    'score' => [        78.3, 67.2, 88.2, 68.5, 60.1,        69.2, 59.1, 92.1, 64.4, 67.1,        72.9, 55.8, 62.6, 52.6, 83.1,        63.7, 83.9, 52.8, 51.9, 57.1,        68.3, 67.6, 60.5, 81.6, 75.2,        81.5, 89.4, 60.7, 62.5, 68.6,    ],];$fit = fit_mixed_gaussian(    'score ~ study_hours + (1 | school)',    $students,);foreach ($fit['columns'] as $i => $name) {    printf(        "%-12s %7.2f (se %.2f)\n",        $name,        $fit['coefficients'][$i],        $fit['std_errors'][$i],    );}$school = $fit['random'][0];printf(    "\nschool SD %.2f, residual SD %.2f\n\n",    sqrt($school['covariance'][0][0]),    $fit['sigma'],);foreach ($school['group_labels'] as $g => $label) {    $se = sqrt($school['effects_cond_var'][$g][0][0]);    printf(        "%s %+6.2f (se %.2f)\n",        $label,        $school['effects'][$g][0],        $se,    );}

Interpretation

  • (1 | school) gives each school its own intercept, assumed to come from a normal distribution. The fit uses REML, as lme4::lmer() does by default.
  • The study_hours coefficient is an association within schools. The model gives every school the same slope.
  • The school SD describes how school intercepts vary. The residual SD describes how students vary around their school’s line.
  • With six schools, the school SD is estimated imprecisely.
  • effects are each school’s predicted intercept relative to the average, as R’s ranef() reports. They are shrunk toward zero, more so for schools with fewer students.
  • The conditional standard errors are equal because every school has five students.
