Evaluate a normal distribution with mean 100 and standard deviation 15, compare Student’s t critical values with the normal’s, and draw seeded random numbers.

The example runs with the phit extension or the plain-PHP polyfill (Extension or polyfill).

Code

use function Phit\{dist_normal_cdf, dist_normal_pdf, dist_normal_quantile, dist_normal_rng, dist_normal_sf};
use function Phit\{dist_t_quantile, dist_t_sf};

printf("density at 115      %.5f\n", dist_normal_pdf(115, 100, 15));
printf("P(X <= 130)         %.5f\n", dist_normal_cdf(130, 100, 15));
printf("95th percentile     %.3f\n\n", dist_normal_quantile(0.95, 100, 15));

// Two-sided 95% critical values and the probability beyond ±1.96.
foreach ([3, 10, 30] as $df) {
    printf("t, df %2d: critical value %.3f, P(|T| > 1.96) %.4f\n", $df, dist_t_quantile(0.975, $df), 2 * dist_t_sf(1.96, $df));
}
printf("normal:   critical value %.3f, P(|Z| > 1.96) %.4f\n\n", dist_normal_quantile(0.975), 2 * dist_normal_sf(1.96));

$draws = dist_normal_rng(5, 42, 100, 15);
echo implode(', ', array_map(fn ($x) => sprintf('%.2f', $x), $draws)), "\n";
$many = dist_normal_rng(100000, 7, 100, 15);
printf("mean of 100000 draws %.2f\n", array_sum($many) / count($many));

Notes

  • The dist_* functions follow R: _pdf is dnorm(), _cdf is pnorm(), _quantile is qnorm(), and _sf is the upper tail, pnorm(lower.tail = FALSE). The survival function keeps precision far into the tail, where 1 - cdf loses it.
  • Student’s t has heavier tails than the normal. Its critical values and tail probabilities approach the normal’s as the degrees of freedom grow.
  • dist_normal_rng($n, $seed, $mean, $sd) returns $n draws. Every call starts its own stream from the seed, so the same seed and parameters give the same draws.
