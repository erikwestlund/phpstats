Fit monthly rent from floor area and district, then predict the rent of two new flats with 95% prediction intervals.

The example runs with the phit extension or the plain-PHP polyfill (Extension or polyfill). The data are ten simulated flats: rent is the monthly rent in an unnamed currency, area is the floor area in square meters, and district is one of three districts.

Code

use function Phit\{fit_ols, predict};

$flats = [
    'rent' => [1879.25, 1805.03, 2022.29, 1267.85, 1509.24, 2240.10, 959.51, 2386.54, 1655.80, 1420.00],
    'area' => [74.4, 57.4, 66.4, 49.1, 45.7, 92.4, 37.0, 93.9, 61.2, 52.3],
    'district' => ['north', 'south', 'north', 'east', 'south', 'north', 'east', 'south', 'east', 'south'],
];

$fit = fit_ols('rent ~ area + district', $flats);

foreach ($fit['columns'] as $i => $name) {
    [$low, $high] = $fit['conf_int'][$i];
    printf("%-14s %8.2f  95%% CI [%8.2f, %8.2f]\n", $name, $fit['coefficients'][$i], $low, $high);
}
printf("R-squared %.3f, residual SD %.2f\n\n", $fit['r_squared'], $fit['sigma']);

$new = ['area' => [50.0, 80.0], 'district' => ['east', 'north']];
$p = predict($fit, $new, interval: 'prediction');

foreach ($p['fit'] as $i => $rent) {
    printf("%.0f m2, %-5s %8.2f  95%% PI [%7.2f, %7.2f]\n",
        $new['area'][$i], $new['district'][$i], $rent, $p['lower'][$i], $p['upper'][$i]);
}

Output

area              19.18  95% CI [   11.27,    27.09]
districtnorth    203.64  95% CI [ -166.19,   573.47]
districtsouth    232.16  95% CI [  -60.58,   524.90]
R-squared 0.927, residual SD 146.29

50 m2, east   1311.65  95% PI [ 898.26, 1725.04]
80 m2, north  2090.69  95% PI [1676.97, 2504.41]

Interpretation

  • district is a string column, so it becomes a factor. Its levels sort alphabetically, and the first, east, is the reference. districtnorth and districtsouth are differences from east for flats of the same area.
  • The area coefficient is the difference in rent associated with one more square meter among flats in the same district. It describes an association in these data, not the effect of enlarging a flat.
  • With ten flats the intervals are wide, and both district intervals include zero.
  • interval: 'prediction' covers the rent of one new flat. interval: 'confidence' covers the mean rent of flats like it and is narrower.
