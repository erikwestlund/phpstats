phit’s fit_mixed_gaussian_intercept_matrix() is compared with lme4 and statsmodels MixedLM, all fitted by ML, on identical observations. The executed comparison shows the calls and results side by side. Four published datasets are also checked against lme4 and nlme. Shared metrics are described in Verification.

Compared

Fixed-effect estimates and inference, covariance, population and conditional fitted values, both residual definitions, group effects, variance components, ICC, marginal likelihood, and AIC. Group labels, their order, and missing-row positions must match exactly.

Inputs and scope

Set Cases
Saved R fixtures Simulated schools with correlated predictors, a single predictor, no fixed intercept, intercept only, a singleton group, and an exact zero group-variance boundary
Three-way comparison The fixtures plus missing values in predictors, outcomes, and group IDs
Published data sleepstudy, Orthodont, Machines, and Hsb82 (provenance), checked in the published-data notebook

Reference and versions

R 4.6.1 with lme4 2.0.6 and nlme 3.1.169, statsmodels 0.15.0 on Python 3.14.7, and phit on PHP 8.5.10, on the development Mac. Linux, PHP-FPM, and other mixed-model structures are not covered by this report.

  • statsmodels estimates are combined with plug-in GLS covariance to match lme4. statsmodels’ own joint-Hessian covariance is a different convention.
  • For the boundary fixture, the Python reference is the NumPy OLS ML limit, since the statsmodels mixed optimizer is not an exact-boundary reference.

Metric and tolerance

Quantities Tolerance
All compared quantities, simulated fixtures 1e-7 absolute + 1e-6 relative
Published data, ordinary quantities 1e-7 absolute + 1e-6 relative
Published data, observation-length outputs 1e-6 absolute + 1e-6 relative
Published data, likelihood and AIC 1e-7 absolute + 1e-10 relative

The published-data notebook documents R’s optimizer precision limit for the near-zero Hsb82 residuals. A separate phit-versus-statsmodels check keeps the uniform 1e-7 + 1e-6 tolerance.

Results

All quantities pass in every case. The saved report and the published-data report record versions, full outputs, Python warnings and backend, the covariance convention, and differences from R.

Further tests outside the comparison:

  • PHP: integer and string group identity, deletion of null groups, rejection of float and boolean labels before deletion, missing-value warnings, and strict rejection.
  • Rust: units, row and group order, invalid shapes, unidentified grouping, rank deficiency, perfect fits, and unsupported zero residual variance.
  • Rust: a balanced intercept-only sample with analytically known variances and shrinkage.
  • Rust: an observation-level GLS check of the cached QR reduction at several variance ratios, with correlated predictors and large outcome offsets, for both optimized and arbitrary coefficients.

Known exceptions and limits

  • The profile search uses a finite log-ratio range and grid. It is not a proof of global optimality.
  • This record covers one random intercept fitted by ML. REML, random slopes, and several grouping terms are verified separately in R compatibility.
  • No finite-sample df adjustment or variance-component test is offered. Normal inference with few groups can be unreliable.
