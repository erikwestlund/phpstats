fit_mixed_gaussian() fits Gaussian linear mixed models, as lme4::lmer() does. fit_mixed_logistic() fits a binomial logit model with one random intercept, as lme4::glmer() does for that structure. It fits no other family or link, so it has no family or link arguments. Both take an R formula with lme4’s bar syntax for random effects.

Phit\fit_mixed_gaussian(    string $formula,    array|object $data,    bool $reml = true,    string $missing = 'drop',    array|string|null $weights = null,    ?array $start = null,    int $maxEvaluations = 20000,    float $tolerance = 1e-7,    string $optimizer = 'bobyqa',    float $objectiveTolerance = 1e-12,): array;Phit\fit_mixed_logistic(    string $formula,    array|object $data,    string $missing = 'drop',    array|string|null $weights = null,    int $quadraturePoints = 1,    int $maxEvaluations = 20000,    float $tolerance = 1e-7,): array;

Supported structures

Function Random terms Family and link Fitting method
fit_mixed_gaussian (1 | g), (x | g), (0 + x | g), (x || g) (uncorrelated), several terms such as (1 | g1) + (1 | g2), interaction groups (1 | g1:g2), and nesting (1 | g1/g2) Gaussian, identity REML (default) or ML (reml: false); BOBYQA (default) or Nelder–Mead (optimizer: 'nelder_mead')
fit_mixed_logistic Exactly one (1 | g) Binomial, logit ML by Laplace (quadraturePoints: 1, the default) or adaptive Gauss–Hermite quadrature with 2 to 61 points

Any other random-effect structure, family or link throws code 1007. Random slopes, several random terms, the Poisson and probit families, and REML are not available in fit_mixed_logistic(). Random-effect terms in fit_ols() or fit_generalized_linear() also throw code 1007.

A random-intercept model

The example uses docs/data/schools.csv: 250 simulated students in 12 schools, with study hours, a prior score, and a test score. read_csv() needs the extension; with the polyfill, read the file another way.

use function Phit\{fit_mixed_gaussian, read_csv};$csv = read_csv('docs/data/schools.csv');$schools = array_combine(    $csv['names'],    array_column($csv['columns'], 'values'),);$fit = fit_mixed_gaussian(    'score ~ study_hours + prior_score + (1 | school)',    $schools,);foreach ($fit['columns'] as $i => $name) {    printf(        "%-12s %8.4f %8.4f\n",        $name,        $fit['coefficients'][$i],        $fit['std_errors'][$i],    );}$school = $fit['random'][0];printf(    "%s: school SD %.4f, residual SD %.4f\n",    $fit['method'],    sqrt($school['covariance'][0][0]),    $fit['sigma'],);printf(    "%s %+.4f\n",    $school['group_labels'][0],    $school['effects'][0][0],);

A school’s effect is its predicted intercept relative to the average school, shrunk toward zero.

Reading a fit_mixed_gaussian result

Key Contents
coefficients, std_errors, z_statistics, p_values, conf_int, covariance Fixed effects, with normal (Wald) tests and 95% intervals

sigma, residual_variance Residual standard deviation and variance

Each random entry has these keys:

Key Contents
label, group, columns, correlated The term as written in the formula
covariance The term’s k×k random-effect covariance
effects One row of conditional modes per group
effects_cond_var One k×k conditional covariance per group, lme4’s ranef(condVar = TRUE)
group_labels, group_sizes Groups in order of first appearance after missing-value deletion
  • lme4 sorts groups instead. The estimates do not depend on the order.
  • The fixed-effect tests use the normal distribution. lme4 reports t values without p-values, and packages such as lmerTest add degrees-of-freedom approximations. phit has no degrees-of-freedom correction.
  • With few groups, Wald inference for the fixed effects can be optimistic.

Singular fits

A random-effect variance estimated at or near zero, or a correlation at ±1, makes the covariance singular. The fit returns with singular true and the warning random-effect covariance is singular or near singular in diagnostics.warnings. With these data, score ~ study_hours + (1 + study_hours | school) is singular because the estimated slope variance is near zero. A singular fit usually means the random-effect structure is more complex than the data support.

A binomial random-intercept model

docs/data/cbpp.csv holds lme4’s cbpp data: cases of contagious bovine pleuropneumonia in 15 herds over four periods.

use function Phit\{fit_mixed_logistic, read_csv};$csv = read_csv(    'docs/data/cbpp.csv',    ['types' => ['c', 'i', 'i', 'c']],);$herds = array_combine(    $csv['names'],    array_column($csv['columns'], 'values'),);$herds['healthy'] = array_map(    fn ($n, $k) => $n - $k,    $herds['size'],    $herds['incidence'],);$fit = fit_mixed_logistic(    'cbind(incidence, healthy) ~ period + (1 | herd)',    $herds,    quadraturePoints: 10,);foreach ($fit['named'] as $name => $b) {    printf("%-12s %8.4f\n", $name, $b);}printf(    "herd SD %.4f, %s\n",    $fit['random_intercept_sd'],    $fit['integration'],);

  • quadraturePoints is lme4’s nAGQ. The Laplace default (1) is fastest.
  • More points approximate the likelihood more closely, which matters most for small groups and rare events.
  • No number of points guarantees accuracy for every data set. Compare a few values when the estimates matter.
  • A row may have at most 1,000,000 trials, counted as cbind() successes plus failures or as weights. Larger counts throw an exception with code 1007.

Prediction

  • predict() adds each known group’s random effects by default, as lme4’s re.form = NULL does.
  • random: false predicts at the population level, and the grouping columns can then be absent.
  • A group the fit never saw throws code 1001 unless allowNewLevels: true, which predicts it at the population level.
  • Mixed-model predictions have no standard errors, as in lme4.

Matrix functions

fit_mixed_gaussian_matrix(), fit_mixed_gaussian_intercept_matrix() and fit_mixed_logistic_matrix() fit the same models from numeric matrices and explicit random-effect designs. fit_mixed_gaussian_intercept_matrix() is a faster path for a Gaussian random intercept by ML. Matrix model functions defines their inputs, the optimizer controls and the convergence rules.
