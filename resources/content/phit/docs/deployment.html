The deployed PHP process needs only phit.so and its system libraries. Rust, Clang, PIE, R and Python are build or development tools and are not needed at runtime. Installation covers PIE and the prebuilt binaries; this page covers PHP-FPM, containers and manual builds.

Names

  • Composer and PIE package: phpstats/phit.
  • Registered extension: phit. Use it with extension_loaded('phit'), phpversion('phit'), get_extension_funcs('phit') and Composer’s ext-phit.
  • Installed module: phit.so. A direct Cargo build produces libphit.so on Linux and libphit.dylib on macOS; they are the same extension.
  • Functions are in the Phit namespace, such as Phit\fit_ols.

Supported targets

The extension supports PHP 8.3, 8.4 and 8.5, non-thread-safe, on Linux and macOS. Windows and ZTS builds are not supported. The prebuilt binaries, which pie install downloads on Linux, are built on Debian Bookworm for x86_64 and arm64 and need glibc 2.35 or later. Alpine (musl) and older glibc releases need a source build with PIE or by hand. CI tests Linux x86_64 and arm64 at all three PHP versions, and macOS on Apple silicon.

PHP-FPM

PHP loads the extension when a process starts. After installing or replacing phit.so:

  1. Enable it in the configuration PHP-FPM reads. php --ini shows the CLI’s files, which can differ from FPM’s.
  2. Restart the PHP-FPM service so every worker loads the new module.
  3. Check the web runtime, not only the CLI, for example with extension_loaded('phit') and phpversion('phit') in a request.

Each call does its work within the request. There is no background process, subprocess, or network service.

A PHP-FPM container image

docker/Dockerfile builds a PHP-FPM image with the extension installed. From the repository root:

docker build --target checks -f docker/Dockerfile -t phit:checks .docker build -f docker/Dockerfile -t phit:local ../scripts/check-container phit:local phit:checks
  • The build installs the extension with PIE 1.5.0 and runs the Rust and PHP checks.
  • check-container sends a FastCGI request to an isolated FPM container, then runs the production image’s CLI and FPM with its shipped PHP configuration. Both must give identical OLS coefficients and a Poisson fit with a log-exposure offset.
  • The final image holds the PHP runtime and the extension. Rust, Clang, PIE, Python, sources, and test tools stay in the build stages.
  • The image keeps the official PHP entrypoint and runs PHP-FPM in the foreground.

Use it as an application base:

FROM phit:localCOPY app/ /var/www/html/

Connect your web server to FPM, which speaks FastCGI rather than HTTP.

Build pins and reproducibility

Input Pinned by
PHP and Rust base images OCI digest, one PHP digest each for 8.3, 8.4, and 8.5; build and runtime stages share the PHP image
Rust dependencies Cargo.lock
PIE PHAR SHA-256
Debian APT packages Not pinned; resolved at build time

Update the pins deliberately and rerun the checks. Because APT packages are not pinned, a rebuild is repeatable but not byte-identical. Binary manifests record the compiler, PHP API, architecture, libc, linked libraries, extension hash, and Cargo.lock hash.

Manual build without PIE

From a checkout of the repository or the release’s source archive, the standard phpize build works without PIE. pie/config.m4 and pie/Makefile.frag run the locked Cargo build:

cd pie/path/to/phpize./configure --with-php-config=/path/to/php-configmake -j4# Stage without modifying the installed PHP runtime:make install INSTALL_ROOT=/absolute/path/to/staging# Or install after reviewing the build:# sudo make install
  • Build as an unprivileged user. make install needs the built module and does not rerun Cargo under sudo.
  • INSTALL_ROOT stages under the configured extension directory.
  • On macOS, use the LLVM and header setup in the development guide.
  • After installing, add extension=phit.so to the PHP configuration. Check php --ini for the CLI and the FPM configuration separately, and confirm the functions load in both.
  • Rebuild for another PHP ABI, architecture, thread-safety or debug configuration, or platform.
