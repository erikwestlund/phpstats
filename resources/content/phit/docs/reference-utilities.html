Probability distributions and descriptive statistics

Distribution functions

Thirteen distribution parameterizations each have seven operations, in scalar and _array form, plus a sampler:

Name Operation
dist_{family}_pdf, _logpdf Density, continuous families
dist_{family}_pmf, _logpmf Mass, discrete families
dist_{family}_cdf, _logcdf Lower tail
dist_{family}_sf, _logsf Upper tail
dist_{family}_quantile Inverse CDF
dist_{family}_{operation}_array The same operation over a list of points
dist_{family}_rng Seeded samples

dist_uniform_rng, dist_categorical_rng, and dist_categorical_rows_rng are samplers only. Probability distributions lists every family with its parameter names, defaults, domains, and support, and stubs/phit.php has the exact signatures.

Inputs.

  • Numeric arguments and elements accept PHP integers or floats. Binomial size is an integer in [0, 2^53].
  • Evaluation points may be ±INF. Parameters must be finite.
  • Batch results are packed lists in input order, with keys discarded. An empty batch returns an empty list after the parameters are validated.
  • null, NAN, or a malformed element rejects the whole batch. There is no missing-value policy.

Results.

  • Boundary densities and log values can be ±INF.
  • Discrete quantiles are floats, with a 64 * EPSILON relative allowance at CDF steps.
  • A degenerate distribution returns its point mass at p = 1, even where R or SciPy differ.
Failure Code
Invalid parameter domain 1001
NAN point or nonfinite parameter 1003
Unsupported binomial size 1007
NAN numerical result 1006

Seeded sampling

dist_{family}_rng(int $n, int $seed, ...parameters): array takes the family’s parameters and defaults.

  • n is in [0, 1,000,000], and seed is a nonnegative PHP integer.
  • Every call uses its own ChaCha20 state and does not touch PHP’s random state.
  • Results are packed lists of n finite floats, including discrete counts.
  • The same seed and parameters reproduce the same draws, and a longer request extends a shorter one, within the same build.
  • An empty request still validates its parameters.
Failure Code
Negative n or seed 1001
n above 1,000,000 1007
Nonfinite parameters or generated samples 1003
PHP argument-conversion errors 0

Seeded sampling defines the inverse-CDF method, the uniform grid, and the limits of reproducibility across versions and platforms.

Descriptive statistics

The ten descriptive functions are stat_mean, stat_var, stat_sd, stat_cov, stat_cor, stat_quantile (type 7), stat_quantile_array, stat_median, stat_weighted_mean, and stat_weighted_var.

Rule Behavior
Missing values missing: 'raise' by default (code 1001). missing: 'drop' deletes them, pairwise for aligned inputs
Infinity Always raises 1003
Normalization Variance, SD, and covariance default to the sample (n − 1) divisor
Weighted variance Frequency weights by default; reliability and population options
Negative weights Rejected before missing-value deletion
Constant input to stat_cor Returns NAN
Other nonfinite arithmetic Raises 1003, so overflow cannot appear as zero variance

These defaults differ from the model functions, which drop missing rows by default, and from the draw kernels below, which accept no missing values. They do not depend on the input’s shape.

The verification record and benchmarks cover accuracy and speed.

Posterior-draw numerical kernels

Phit\draws_moments(    array $draws,    ?array $weights = null,    string $normalization = 'population',): array;Phit\draws_covariance_map(    array $sourceCovariance,    array $targetCovariance,): array;Phit\draws_affine(    array $draws,    array $matrix,    array $shift,): array;

Shared rules.

  • Draw matrices have one row per draw and one column per parameter, with at least one of each. All matrices must be rectangular.
  • Only integers and floats are accepted. null, strings, and booleans raise 1001; NAN and INF raise 1003. weights itself may be null for uniform weights.
  • Keys are ignored, iteration order sets the row and parameter order, and results are packed lists.
  • Inputs are not modified. No rows are dropped and no intercept is added; there is no missing or intercept option.
  • Ragged or incompatible dimensions raise 1002, and nonfinite arithmetic raises 1003.
Function Returns Rules
draws_moments ['mean' => list<float>, 'covariance' => list<list<float>>] Weights are finite, nonnegative, one per draw, with positive total, and are normalized to sum to one
draws_covariance_map ['matrix' => list<list<float>>, 'log_abs_det' => float] Both covariances square, finite, symmetric, positive definite, of equal size
draws_affine ['draws' => list<list<float>>, 'log_abs_det' => float] A square, invertible matrix and a shift of the parameter dimension

draws_moments. The mean is \(\sum_i w_i x_i\) and the population covariance \(\sum_i w_i(x_i-\mu)(x_i-\mu)^T\). 'unbiased' divides the covariance by \(1-\sum_i w_i^2\), so weights express reliability, not frequency counts.

  • Zero total weight, an unknown normalization, or an undefined unbiased normalization raises 1001.
  • Zero-weight rows are still validated.
  • One effective draw is valid for population moments and gives zero covariance.
  • A singular covariance is valid, including when there are fewer draws than parameters.

draws_covariance_map. Returns \(A=L_tL_s^{-1}\) from the Cholesky factors and a triangular solve, so \(A C_s A^T=C_t\) to floating-point precision. The map depends on the parameter order and is not unique.

  • Asymmetry beyond the documented tolerance raises 1001.
  • A failed positive-definite factorization or a numerically singular matrix raises 1005.
  • There is no ridge, jitter, or other regularization.

draws_affine. Each row becomes \(y_i=A x_i+b\), or \(Y=X A^T+b\) in row-oriented notation. The output keeps the row and column counts and the draw order. Negative determinants are allowed, and log_abs_det is \(\log|\det A|\). A singular or numerically singular map raises 1004.

Posterior-draw kernels gives the tolerances, formulas, and verification. Stan evaluation, PSIS, moment matching, and diagnostics belong to the consuming CmdStan package.

One-dimensional optimization and root finding

Phit\optimize(    callable $f,    float $lower,    float $upper,    ?float $tol = null,    bool $maximum = false,): array;Phit\uniroot(    callable $f,    float $lower,    float $upper,    ?float $tol = null,    int $maxiter = 1000,): array;
Function R function Returns
optimize optimize() ['minimum' => x, 'objective' => f(x)], or ['maximum' => x, 'objective' => f(x)] with maximum: true
uniroot uniroot() ['root', 'f_root', 'iter', 'estim_prec']
  • Both follow R’s C code (Brent_fmin and R_zeroin2) step by step, so they evaluate f at the same points and return the same doubles.
  • The default tol is R’s .Machine$double.eps^0.25.
  • f is any PHP callable that takes one float and returns an int or float. Any other return value raises 1001. An exception thrown by f propagates unchanged.
  • As in R, a nonfinite value during the search is replaced by the largest finite value, keeping the sign of -INF in uniroot. One E_WARNING reports the replacement.
  • uniroot needs f(lower) and f(upper) without NAN and with opposite signs.
  • When uniroot runs out of iterations, it raises an E_WARNING, sets iter to maxiter, and returns its last estimate.
  • R’s extendInt and check.conv options are not available.

tests/optimize.php compares 91 results with R 4.6.1 bit for bit, including the number of function evaluations. The cases cover smooth, flat, kinked, multimodal, and boundary minima, infinite values, roots at the endpoints, a step function, and a search that does not converge.
