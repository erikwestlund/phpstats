The figure functions follow bayesplot’s names and return a Figure, which holds the computed statistics in data and renders them:

Method Output Needs
ascii(width, height) Plain text for a terminal, log, or report. Echoing a figure prints this form. Nothing
vegaLite(width, height, maxRows) A Vega-Lite 5 spec as a PHP array, with the data inlined A Vega-Lite runtime, such as vega-embed, to display it
json() The same spec as JSON that is safe inside an HTML script element The same
html() A standalone page Loads Vega, Vega-Lite, and vega-embed from the jsDelivr CDN
svg(), png(scale: 2.0) Static images The vl-convert binary on PATH, or its path in VL_CONVERT
Function Plot
mcmc_trace($fit, 'theta') Chains overlaid by iteration
mcmc_hist($fit, 'theta', bins: 30) Histogram of all draws
mcmc_dens($fit, 'theta') Gaussian kernel density of all draws
mcmc_dens_overlay($fit, 'theta') One density curve per chain
mcmc_intervals($fit, ['mu', 'beta'], prob: 0.5, probOuter: 0.9, pointEst: 'median') Inner and outer intervals with a point estimate on a shared axis. Without a selection, every variable except lp__.
mcmc_rank_hist($fit, 'theta', bins: 20) Per-chain histograms of pooled ranks, with the count expected under uniform ranks marked
mcmc_scatter($fit, 'mu', 'sigma') Joint draws, with divergent transitions marked on MCMC fits
mcmc_acf($fit, 'theta', lags: 20) Per-chain autocorrelation bars
pareto_k_plot($fit->loo()) Pareto k by observation, with the threshold and k = 1 marked

A plotted variable names one element, such as beta[2]. mcmc_intervals() also accepts base names, which select every element. The functions take a fit or a draws_array.

The bandwidth (R’s bw.nrd0), densities, quantiles, ranks, and autocorrelations are computed in PHP and checked against R and bayesplot. Vega-Lite specs carry these values and use no Vega-Lite density, binning, or quantile transforms, so every rendering shows the same numbers. The ASCII form rounds positions to character cells; use the figure’s data or the numeric methods, such as summary(), when exact values matter.

Trace and scatter figures inline every draw. For large fits, maxRows keeps every k-th iteration of a trace, or every k-th draw of a scatter plus all divergent draws, so that about that many rows remain. Per-chain figures (rank histograms and autocorrelation) are faceted by chain, and their sizes apply to each chain’s panel.
