Evaluate a model’s log density and gradients, move between the constrained and unconstrained scales, and call the program’s Stan functions. The executable’s methods run CmdStan processes. The in-process methods and Stan functions load a compiled model library with PHP’s FFI extension and start no process.

Gradient checks and batch log density

diagnose() compares the model’s gradients with finite differences at the initial values, which finds errors in user-written gradients and numerical problems. logProb() evaluates the log density and its gradient at given parameter values in one CmdStan process. Both use examples/normal.stan, a model with one parameter mu.

$normal = CmdStan\cmdstan_model('examples/normal.stan');$gradientCheck = $normal->diagnose(init: 0);echo $gradientCheck->gradients();$logDensity = $normal->logProb(unconstrained_params: ['params_r' => [[0.0], [1.0]]]);print_r($logDensity->draws(format: 'draws_matrix'));

logProb() takes exactly one of unconstrained_params or constrained_params, using CmdStan’s input JSON format. This runs the executable’s batch log-density method. The in-process methods below evaluate one point at a time without starting a process.

In-process model methods

These methods need PHP’s FFI extension. $fit is a fit of the Bernoulli model from Getting started.

$fit->initModelMethods(seed: 1);$u = $fit->unconstrainVariables(['theta' => 0.3]);$lp = $fit->logProb($u);$gradient = $fit->gradLogProb($u, jacobian: false)['gradient'];$hessian = $fit->hessian($u)['hessian'];$values = $fit->constrainVariables($u);$unconstrained = $fit->unconstrainDraws(format: 'draws_matrix');
  • Log densities drop constant terms, and jacobian defaults to true, as in CmdStanR.
  • The methods are bound to the fit’s data and to a seed for the generated-quantities RNG. initModelMethods(data: $data) binds other data, for example after a saved fit’s data file is gone.
  • An imported CSV fit needs the model: $fit->initModelMethods(model: $model).
  • The first call compiles a library, which takes a few seconds. Later calls reuse it.

Unconstrained values are flat lists in Stan’s order, and unconstrainDraws() labels them with Stan’s unconstrained names. Constrained values are keyed by variable name, and unconstrainVariables() accepts the same structure:

Stan type PHP value
real, int A number
vector, row_vector, array A list, nested for multidimensional arrays
matrix A list of rows
complex [re, im]
tuple A list of its elements, so t.2 is $values['t'][1]

PHP indices are zero-based, so Stan’s beta[1] is $values['beta'][0].

Stan functions

$functions = $model->exposeFunctions();$functions->my_function(1.5, [1.0, 2.0]);$functions->call('normal_draw_rng', 0.0, 1.0, seed: 42);

exposeFunctions() compiles the model’s functions block. Arguments may be positional or named by their Stan names. Supported types are real, int, complex, vectors, matrices, arrays of these, and tuples. Functions ending in _rng take an optional seed. Density functions ending in _lpdf or _lpmf return the full density. Functions ending in _lp and overloaded functions cannot be called. functions() on the returned object lists each signature and whether it is supported.

FFI is enabled for the CLI by default. Under PHP-FPM or another web SAPI, set ffi.enable=true or preload the library.

Build details

Model methods and exposed functions compile a shared library from the model’s generated C++ with the selected CmdStan’s compiler settings. The library is cached beside the Stan source, with a fingerprint in its file name.
