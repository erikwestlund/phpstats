This package ports CmdStanR’s core model/executable/CSV workflow to PHP. It does not claim full CmdStanR compatibility. The reference is the CmdStanR API and CmdStan CLI, consulted during implementation. PHP interfaces preserve modern option names wherever their meaning transfers directly. Method names do not carry over: PSR-1 makes a PHP method name camelCase, so CmdStanR’s fit$output_files() is $fit->outputFiles() here. The method names table maps every one of them, and the package declares no snake_case alias beside the camelCase name.

Method names

The package named its methods after their CmdStanR, posterior, loo, and bayesplot counterparts, so fit$output_files() in R was $fit->output_files() here. PSR-1 makes a PHP method name camelCase, and this family declares no second spelling, so each R name now maps to one PHP name. Option names, CSV metadata keys, result-array keys, summary measure names, and the standalone functions are unchanged: sample(iter_warmup: 500) and Summary::summarise($draws, ['ess_bulk']) read as they always did. PHP adaptations

R named lists become associative PHP arrays; numeric arrays must be rectangular zero-indexed lists. R sparse matrices, complex numbers, NA, and automatic R object conversion have no PHP equivalent. Data frames and factors can come from phibble or any object with toModelData() or toColumns(), following the conventions in the API reference. code() returns one source string. Syntax errors throw exceptions rather than returning an R diagnostic list.

R posterior objects become PHP arrays with documented shapes. All array indices are zero-based; draw metadata is one-based. draws_array retains iteration/chain axes, draws_matrix concatenates chains, draws_df is associative rows, draws_list maps variables to values per chain, and draws_rvars nests each variable’s draws by its dimensions. R tibble, posterior, bayesplot, and ggplot2 classes are not emulated. The default draws format follows CmdStanR: draws_array for MCMC and generated quantities and draws_matrix for other methods.

Summary quantiles use linear interpolation (R’s default type 7). Scaled MAD uses 1.4826. The default MCMC summary delegates R-hat and bulk ESS to the installed CmdStan stansummary and computes tail ESS in PHP. Passing measures to summary() uses a PHP port of posterior’s summarise_draws(), including rank-normalized R-hat, bulk/tail ESS, and MCSE, so it does not need CmdStan. Results are checked against the installed reference R packages, but are not guaranteed bit-for-bit identical to every version of posterior. ADVI’s mean row is stored separately. ADVI and Laplace log_p__ columns are normalized to lp__ and their approximate densities to lp_approx__, matching CmdStanR. Non-MCMC convergence statistics are NAN.

metadata() returns one merged array with CmdStanR’s keys, such as iter_sampling, max_treedepth, and stan_variable_sizes, alongside CmdStan’s raw argument names. chainMetadata() returns the per-chain arrays. invMetric() returns matrices by default and reads metric JSON when every chain has one.

Model methods and exposed functions compile a shared library against the selected CmdStan and load it with PHP FFI. FFI is enabled for the CLI by default (ffi.enable=preload); web SAPIs need ffi.enable=true or preloading. Libraries are cached beside the Stan source with a fingerprint in the file name. Model methods drop constant terms and default to jacobian: true, as in CmdStanR. Unconstrained vectors are flat lists, and constrained variables are nested zero-based arrays with matrices as lists of rows. Fits serialize the library path, data, and seed, and reconnect on first use; the generated-quantities RNG then restarts from its seed.

Initialization from a fit follows CmdStanR’s process_init(). MCMC draws are resampled without replacement, an optimization estimate is repeated, and ADVI, Laplace, and Pathfinder draws are resampled with Pareto-smoothed importance weights. Resampling uses PHP’s seeded Mt19937 engine, so a given seed selects different draws than CmdStanR does.

Diagnostic checks are structured messages accessible with diagnosticWarnings(), rather than PHP runtime warnings. Console output is buffered; there is no R progress-bar or interrupt integration. show_messages controls stdout, show_exceptions controls stderr. Deprecated CmdStanR argument names raise E_USER_DEPRECATED and map to their replacements; conflicting old and new values throw. Output files persist after garbage collection, so callers manage cleanup explicitly. Saving moves files that a run created and copies imported CSVs and user-supplied data files; existing destinations are never overwritten. Saved fit objects use PHP serialization and embed parsed results; CSVs are still needed for downstream CmdStan commands.

options() and cmdstan_option() provide CmdStanR’s global options that have a PHP meaning: default output directory, Stan file directory, forced recompilation, draws format, initialization warnings, verbose compilation, printed rows, line numbers, and mc.cores. cmdstanr_no_ver_check is accepted and has no effect because this package never checks for updates.

Algorithm parameters left null use CmdStan’s defaults. PHP-level defaults include four sample chains, sequential execution unless requested, and one MPI chain. CmdStanR defaults for automatically saving metric/configuration JSON are not imposed; request save_metric or save_cmdstan_config explicitly. The installer defaults to one core where CmdStanR uses two. OpenCL and MPI require external toolchains/hardware. Windows has not been validated.

Moment matching follows loo::loo_moment_match() as CmdStanMCMC$loo() calls it, with corrections to the split step and relative efficiencies. loo’s development version adopted the split corrections in stan-dev/loo#405 on 2026-10-13; the differences below are from loo 2.10.1 and earlier development builds. The split uses the exact inverse of the accumulated affine map, where loo subtracts the shift after the inverse linear map. The split relative efficiency is the minimum over both halves, where loo uses the second half twice. Relative efficiencies use exp(log_lik − max), which avoids the NA that loo returns when every likelihood value is tiny. Without the split, and with the split when only shifts are accepted, elpd_loo and Pareto k match loo and CmdStanR. Accepted scale and covariance steps are composed in their original order, including cases where scaling follows a covariance map. A singular weighted covariance uses loo’s identity-map fallback while retaining the mean shift; its reason is recorded in covariance_fallbacks. Other numerical or model failures stop the observation at its last accepted state and record a reason. Covariances are never regularized. The inference guide describes the result.

Not implemented

The following CmdStanR features have no implementation:

  • expose_functions(global = TRUE). Functions are called as methods of the returned StanFunctions object. Functions ending in _lp and overloaded functions are listed but cannot be called.
  • bayesplot’s other plots, including pairs, areas, NUTS energy, and posterior predictive checks. Figures are not ggplot2 objects and cannot be extended with ggplot2 layers or themes.
  • Posterior rvar arithmetic and R session hooks beyond the options listed above.
  • Windows toolchain repair (check_cmdstan_toolchain(fix = TRUE)). The PHP toolchain check reports missing tools and does not install them.
  • Parity with every CmdStanR version’s error and warning messages.

No unsupported option is accepted silently. This repository’s tests validate the implemented contract against the installed CmdStanR, posterior, and loo packages; they are not the upstream CmdStanR test suite. Direct conformance tests run CmdStanR and PHP with the same seeds and compare draws, descriptive summaries, MCMC sampler diagnostics, CSV metadata, model methods, exposed functions, PSIS, LOO, WAIC, and posterior summary measures.
