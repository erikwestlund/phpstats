The package ships three example models from CmdStanR, with their data: logistic, a logistic regression, and schools and schools_ncp, the eight schools hierarchical model in its centered and non-centered forms. The repository’s examples/ directory has the small programs used in these docs.

Bundled models

cmdstanr_example() compiles an example, fits it with its bundled data, and returns the fit. The first argument names the example, and the second the method: sample (the default), optimize, laplace, variational, pathfinder, or diagnose. Other arguments are passed to the method. The executable is built in the directory set by the cmdstanphp_example_dir option, or in cmdstanphp-examples under the system temporary directory. print_example_program() prints the Stan program.

use function CmdStan\cmdstanr_example;use function CmdStan\print_example_program;print_example_program('schools_ncp');$fit = cmdstanr_example(    'schools_ncp',    seed: 123,    show_messages: false,);$rows = $fit->summary(    ['mu', 'tau'],    measures: ['mean', 'sd', 'rhat', 'ess_bulk'],);echo "variable   mean    sd   rhat  ess_bulk\n";foreach ($rows as $r) {    printf(        "%-8s %6.2f %5.2f %6.3f %9.0f\n",        $r['variable'],        $r['mean'],        $r['sd'],        $r['rhat'],        $r['ess_bulk'],    );}$warnings = $fit->diagnosticWarnings();echo $warnings ? implode("\n", $warnings) : 'No warnings';echo "\n";
data {  int<lower=1> J;  vector<lower=0>[J] sigma;  vector[J] y;}parameters {  real mu;  real<lower=0> tau;  vector[J] theta_raw;}transformed parameters {  vector[J] theta = mu + tau * theta_raw;}model {  target += normal_lpdf(tau | 0, 10);  target += normal_lpdf(mu | 0, 10);  target += normal_lpdf(theta_raw | 0, 1);  target += normal_lpdf(y | theta, sigma);}

The centered form, schools, samples the same posterior with theta as a parameter. With the same seed it produces divergent transitions in every chain:

$fit = cmdstanr_example(    'schools',    seed: 123,    show_messages: false,);echo implode("\n", $fit->diagnosticWarnings()), "\n";
Chain 1: 73 divergent transitions.
Chain 2: 74 divergent transitions.
Chain 2: E-BFMI below 0.3.
Chain 3: 25 divergent transitions.
Chain 4: 8 divergent transitions.

The MCMC guide explains these warnings. Outputs are from CmdStan 2.40.0 on macOS (arm64). Other CmdStan versions and platforms can give different draws for the same seed.

Programs in the repository

The examples/ directory of the repository holds:

  • bernoulli.stan and bernoulli.php, the model from Getting started and a script that samples it. Run php examples/bernoulli.php from a clone of the repository after composer install.
  • generated.stan, the Bernoulli model with a posterior prediction, used in Generated quantities.
  • normal.stan, a one-parameter normal model, used in Log density and model methods.
