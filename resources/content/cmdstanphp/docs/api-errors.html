Exceptions thrown by CmdStanPHP. StaleExecutableException and ProcessException are in the CmdStan namespace and extend RuntimeException.

InvalidArgumentException

Data or options are invalid. The message names the variable or option.

RuntimeException

Files or the toolchain are missing, a process times out, a CSV file is malformed, or an optional extension or package is not installed.

StaleExecutableException

The executable is out of date. Compiling models describes when this is thrown.

ProcessException

new ProcessException(array $command, int $exitCode, string $stdout, string $stderr)

A CmdStan process exited with a nonzero status. Its readonly properties are command, exitCode, stdout, and stderr.

A failing chain stops the other running chains, and its partial output files stay on disk for inspection. Partial output is never returned as a successful fit. CmdStan processes still running when PHP shuts down are terminated.
