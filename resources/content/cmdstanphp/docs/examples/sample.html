Fit the eight schools hierarchical model with four MCMC chains, then print a posterior summary, the sampler’s warnings, and draws of tau.

Compiling a model needs CmdStan and a C++ toolchain, as described in Installation. The data are the estimated coaching effects y and their standard errors sigma for eight schools (Rubin 1981), also available as schools.csv.

use function CmdStan\cmdstan_model;use function CmdStan\write_stan_file;$code = <<<'STAN'data {  int<lower=1> J;  vector[J] y;  vector<lower=0>[J] sigma;}parameters {  real mu;  real<lower=0> tau;  vector[J] theta_raw;}transformed parameters {  vector[J] theta = mu + tau * theta_raw;}model {  mu ~ normal(0, 10);  tau ~ normal(0, 10);  theta_raw ~ std_normal();  y ~ normal(theta, sigma);}STAN;$file = write_stan_file(    $code,    dir: __DIR__,    basename: 'schools',);$model = cmdstan_model($file);$data = [    'J' => 8,    'y' => [28, 8, -3, 7, -1, 1, 18, 12],    'sigma' => [15, 10, 16, 11, 9, 11, 10, 18],];$fit = $model->sample(    data: $data,    seed: 123,    chains: 4,    parallel_chains: 4,    adapt_delta: 0.95,    show_messages: false,);$rows = $fit->summary(['mu', 'tau', 'theta']);echo "variable   mean    sd     q5    q95  rhat ess_bulk\n";foreach ($rows as $r) {    printf(        "%-8s %6.2f %5.2f %6.2f %6.2f %5.3f %8.0f\n",        $r['variable'],        $r['mean'],        $r['sd'],        $r['q5'],        $r['q95'],        $r['rhat'],        $r['ess_bulk'],    );}$warnings = $fit->diagnosticWarnings();echo $warnings ? implode("\n", $warnings) : 'No warnings';echo "\n";$draws = $fit->draws('tau', 'draws_matrix');$tau = array_column($draws, 'tau');echo count($tau), " draws of tau, the first five:\n";$first = array_slice($tau, 0, 5);printf("%.2f, %.2f, %.2f, %.2f, %.2f\n", ...$first);

  • write_stan_file() rewrites schools.stan only when the program changes, so the model compiles on the first run and later runs reuse the executable.
  • Four chains of 1,000 sampling iterations, after 1,000 warmup iterations, give 4,000 draws per variable.
  • Partial pooling pulls each school’s theta toward mu. The pull is stronger when tau is small or a school’s sigma is large.
  • The non-centered form, theta = mu + tau * theta_raw, usually produces far fewer divergent transitions than sampling theta directly. It does not rule them out.
  • Use the estimates only when rhat is below 1.01, ess_bulk is at least 100 per chain, and there are no warnings.
  • A fixed seed reproduces the draws only with the same CmdStan version, compiler, and machine.
