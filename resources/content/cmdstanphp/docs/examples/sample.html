Fit the eight schools hierarchical model with four MCMC chains, then print a posterior summary, the sampler’s warnings, and draws of tau.

Compiling a model needs CmdStan and a C++ toolchain, as described in Installation. The data are the estimated coaching effects y and their standard errors sigma for eight schools (Rubin 1981), also available as schools.csv.

use function CmdStan\cmdstan_model;
use function CmdStan\write_stan_file;

$code = <<<'STAN'
data {
  int<lower=1> J;
  vector[J] y;
  vector<lower=0>[J] sigma;
}
parameters {
  real mu;
  real<lower=0> tau;
  vector[J] theta_raw;
}
transformed parameters {
  vector[J] theta = mu + tau * theta_raw;
}
model {
  mu ~ normal(0, 10);
  tau ~ normal(0, 10);
  theta_raw ~ std_normal();
  y ~ normal(theta, sigma);
}
STAN;

$model = cmdstan_model(write_stan_file($code, dir: __DIR__, basename: 'schools'));

$data = [
    'J' => 8,
    'y' => [28, 8, -3, 7, -1, 1, 18, 12],
    'sigma' => [15, 10, 16, 11, 9, 11, 10, 18],
];

$fit = $model->sample(
    data: $data,
    seed: 123,
    chains: 4,
    parallel_chains: 4,
    adapt_delta: 0.95,
    show_messages: false,
);

printf("%-10s %7s %7s %7s %7s %6s %8s\n", 'variable', 'mean', 'sd', 'q5', 'q95', 'rhat', 'ess_bulk');
foreach ($fit->summary(['mu', 'tau', 'theta']) as $row) {
    printf(
        "%-10s %7.2f %7.2f %7.2f %7.2f %6.3f %8.0f\n",
        $row['variable'], $row['mean'], $row['sd'], $row['q5'], $row['q95'], $row['rhat'], $row['ess_bulk'],
    );
}

print_r($fit->diagnosticWarnings());

$tau = array_column($fit->draws('tau', 'draws_matrix'), 'tau');
echo count($tau), " draws of tau\n";
echo implode(', ', array_map(fn($x) => round($x, 2), array_slice($tau, 0, 5))), "\n";

  • write_stan_file() writes schools.stan beside the script and leaves it untouched when the program is unchanged. cmdstan_model() compiles it on the first run and reuses the executable until the program changes.
  • Each variable has 4,000 draws: four chains of 1,000 sampling iterations after 1,000 warmup iterations. draws_matrix lists them chain after chain.
  • Partial pooling: each school’s theta is pulled toward the overall mean mu. The pull is stronger when the between-school standard deviation tau is small and for schools whose sigma is large.
  • The program samples theta_raw and computes theta = mu + tau * theta_raw (the non-centered parameterization). When tau is near zero, this form usually produces far fewer divergent transitions than sampling theta directly, but it does not rule them out. adapt_delta: 0.95 makes the sampler take smaller steps, which also reduces divergences at some cost in speed.
  • Check the diagnostics before using the estimates. rhat should be below 1.01, and ess_bulk should be at least 100 per chain (400 here). diagnosticWarnings() reports divergent transitions, iterations that hit the maximum tree depth, and low E-BFMI, and an empty list means none occurred.
  • A fixed seed reproduces the draws with the same CmdStan version, compiler, and machine. A different CmdStan or compiler version, operating system, or processor can give different draws.
