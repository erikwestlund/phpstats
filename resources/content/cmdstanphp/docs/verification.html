CmdStanPHP has three test suites:

  • Unit tests, which need no CmdStan.
  • Integration tests, which compile and run real models.
  • Compatibility tests, which run CmdStanR, posterior, loo, and bayesplot in R on the same inputs and compare the results.

Contributing explains how to run them.

What CI runs

GitHub Actions runs on Linux (Ubuntu) for every push to main and every pull request:

Job Platform Scope
Unit PHP 8.2, 8.3, 8.4, and 8.5 Unit suite
Integration PHP 8.4, CmdStan 2.37.0 and 2.40.0, with FFI and the phit extension Integration suite. Every figure kind is rendered to SVG and one to PNG with vl-convert 1.9.0.
Compatibility The CmdStan 2.40.0 integration job CmdStanR 1.0 (commit 0a54123 of its v1.0 branch, version 0.99.0, a release candidate), and posterior, loo, and bayesplot from stan-dev’s R-universe and CRAN

The integration and compatibility jobs fail on skipped tests. The integration suite also passes on macOS (Apple silicon, PHP 8.4, CmdStan 2.40.0).

Comparisons with R

Each comparison runs the same input through CmdStanPHP and the R reference. In the method comparisons, CmdStanR runs CmdStanPHP’s compiled executable through cmdstan_model(exe_file = ...), so both use the same build, data, seed, and output precision. A relative tolerance t means |PHP − R| ≤ t × max(1, |R|).

R, CmdStanR 1.0, posterior, loo, bayesplot, jsonlite, Rcpp, and RcppEigen are needed. The tests skip when these are missing.

Other interfaces

The eight schools model, run through CmdStanPHP, cmdstanr 0.9.0, and CmdStanPy 1.3.0 with the same CmdStan 2.40.0, data, seed, chain IDs, and initialization, gives identical draws. Each interface’s own summary agrees with CmdStanPHP’s to 1e-9 + 1e-9 × |cmdstanr’s value|, with CmdStanPy’s summary at 12 significant figures. verification/interfaces/run.sh reproduces it.

Unit and integration tests

The unit suite covers JSON shapes and invalid data, CSV comments, warmup, and special numbers, draw layouts, summaries, diagnostics, serialization, option validation, process argument isolation, pipe draining, timeouts, cancellation, and bounded execution. Process behavior is tested with real PHP subprocesses. Data frames are tested with stand-in tables and a stand-in Phibble\DataFrame. Without phit, StanData::fromFormula() is tested with a stand-in Phit\model_matrix(), and with phit, against the real function. The moment-matching tests need phit and skip without it.

The integration suite compiles the bundled models and runs real CmdStan methods:

  • Bernoulli posterior estimates against the analytic mean, R-hat and ESS, seeded parallel chains, modes, and draw counts.
  • Generated quantities, fixed parameters, syntax checking and formatting, gradient checking, log density, input errors, metrics, and auxiliary files.
  • A hierarchical regression from StanData::fromColumns(), a model on table data, and, with phit, score ~ study_hours + (1 | school) from StanData::fromFormula(), compared with Phit\fit_lmer().
  • FFI model methods and exposed functions, initialization from fits, the example models, and LOO with and without moment matching.

Tests that need FFI skip without it, and the suite skips without CmdStan.

Limits

  • Tests use small models and modest numbers of draws, and they are not CmdStanR’s own test suite.
  • macOS is tested locally, not in CI. Native Windows, MPI clusters, and OpenCL hardware are not tested.
  • Compatibility lists the features that are not implemented.
