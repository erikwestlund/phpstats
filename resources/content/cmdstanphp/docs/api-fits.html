Every fitting method returns a fit object. These methods read its draws, summaries, diagnostics, and files.

Draws, summaries, and saving fits explains formats, summaries, and saving.

Draws and summaries

Method Result
draws(variables: null, format: null, incWarmup: false) Draws in draws_array, draws_matrix, draws_df, draws_list, or draws_rvars format
samplerDiagnostics(format: null, incWarmup: false) Sampler columns ending in __, except lp__
summary(variables: null, probs: [0.05, 0.95], measures: []) One row per variable
drawsColumns(variables: null, incWarmup: false), summaryColumns(...) The same as column arrays. See data frames.
drawsTable(...), summaryTable(...) The same as a Phibble\DataFrame
print(variables: null, maxRows: null) Prints summary JSON for at most cmdstanr_max_rows variables
lp() lp__ by iteration and chain
cmdstanSummary() CmdStan’s stansummary text

A fit reads its CSV metadata and checks every row when it is created, then reads only the columns that draws(), summary(), and the diagnostics use, as packed doubles. Each read of new columns passes over the files again, so request variables together. Until materialize(), the fit needs its CSV files.

Diagnostics and run information

Method Result
diagnosticSummary() Per-chain num_divergent, num_max_treedepth, and ebfmi

cmdstanDiagnose() The text from CmdStan’s diagnose utility

init() The initial values each process used
output(), returnCodes(), command() Console output, exit status, and command line of each process. Imported fits have none of these. command() leaves out STAN_NUM_THREADS and an MPI launcher.

Method Result

Model methods

These need PHP’s FFI extension. The first call compiles a shared library for the fit’s model and data, and initModelMethods(data: null, seed: 1, verbose: false, quiet: false, model: null) does this explicitly. data binds other data, for example when a reloaded fit’s data file is gone, and dataFile() then points to it. Imported CSV fits must pass model:, and a model from exeFile alone has no program to build them from. See Log density and model methods.

Method Result
logProb(unconstrainedVariables, jacobian: true) The log density, with constants dropped
gradLogProb(...) ['log_prob' => float, 'gradient' => list]
hessian(...) ['log_prob' => float, 'grad_log_prob' => list, 'hessian' => rows]
unconstrainVariables(variables) A flat unconstrained list from parameter values keyed by name, shaped as constrainVariables() returns them
unconstrainDraws(files: null, draws: null, format: null, incWarmup: false) The fit’s draws, other CSV files, or draws_df rows on the unconstrained scale
constrainVariables(unconstrainedVariables, transformedParameters: true, generatedQuantities: true) Variables keyed by name as nested arrays, with tuples as lists and complex values as [re, im]
exposeFunctions(timeout: null), functions() The model’s user-defined functions

CmdStan\ModelMethods and CmdStan\StanFunctions can also be used directly with a Stan file.
